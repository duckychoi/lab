# OpenClaw Foundation

> [!insight] 핵심
> [[openclaw]](★391,087 · fork 82,233)의 **LICENSE 저작권자로 명시된 조직**: *"Copyright (c) 2026 OpenClaw Foundation"*. 🎯 **볼트가 이 조직을 오늘 처음 기록한다 — ★391K 저장소의 소유 주체가 1,191개 페이지 어디에도 없었다**([[선발창-누락]]).

> [!note] 확인된 사실
> - LICENSE 전문(1,170B) 1행 `MIT License` · 3행 저작권자 **OpenClaw Foundation** · 연도 **2026**
> - 말미에 제3자 고지 참조: *"Third-party notices for incorporated or adapted code are recorded in THIRD_PARTY_NOTICES.md."* → 이 2행 때문에 GitHub 탐지기가 `NOASSERTION`/`Other` 로 분류
> - GitHub org 이름은 `openclaw`(저장소 `openclaw/openclaw`), 저작권 주체 표기는 **Foundation** — 🔴 **둘의 법적 동일성은 미확인**

> [!question] 미해결
> - 재단 설립 시점·소재지·거버넌스 **전부 미확인**(웹 조회 0회)
> - 저장소 생성 2025-11-24 vs 저작권 연도 2026 **불일치** — 재단이 저장소보다 늦게 설립됐을 가능성
> - `THIRD_PARTY_NOTICES.md` **미열람** → 실제 의존 라이선스 구성 불명
