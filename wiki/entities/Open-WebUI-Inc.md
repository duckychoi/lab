# Open WebUI Inc.

> [!insight] 한 줄
> **[[open-webui]] 의 저작권자.** 🏆 **볼트가 `/license` 원문(2,819자)에서 확정했다** — GitHub 은 `NOASSERTION` 으로만 표기한다.

**저작권 표기**: `Copyright (c) 2023- Open WebUI Inc. [Created by **Timothy Jaeryang Baek**]`
**프로젝트 규모**(볼트 2026-10-13 API 실측): ★**155,432** · 포크 **22,666** · watchers **676** · open_issues **197** · Python · created 2023-10-06

> [!insight] 🏆 **라이선스 설계가 이 조직의 전략이다 — BSD-3 외형 + 브랜딩 게이트**
> `Open WebUI License` 는 **1~3항이 BSD 3-Clause 와 동일**하고 **4항이 추가**돼 있다:
> > *"strictly prohibited from altering, removing, obscuring, or replacing any **"Open WebUI" branding** … **except** (i) … end users … **does not exceed fifty (50) within any rolling thirty (30) day period**; (ii) **specific prior written permission**; or (iii) a **duly executed enterprise license**."*
> 🎯 ⇒ **코드는 BSD 처럼 풀어 주고, 수익화는 "브랜딩 제거권"에 걸었다.**
> 📌 **50명이 상업 전환 임계다**: 50명 이하 = 자유롭게 화이트라벨 / 초과 = **enterprise license 협상 대상**.
> ⚖️ **이것은 오픈코어(open-core)와 다른 모델이다** — 기능을 가두지 않고 **정체성 표시를 가둔다.** 🆕 **볼트가 처음 관측한 유형이다.**
> 🔴 **부수 조건 2건**: ① *"Materials governed by **prior licenses** retain those original license terms, as specified in **LICENSE_HISTORY**"* ⇒ **파일별 라이선스 혼재 가능** ② 기여 시 **CLA 동의 필수**(저작권 집중 장치).

> [!insight] 📌 **같은 배치의 [[mksglu]] 와 전략이 대비된다**
> | | 라이선스 | 막는 것 | 임계 |
> |---|---|---|---|
> | **Open WebUI Inc.** | Open WebUI License(BSD-3+4항) | **브랜딩 제거** | 50명/30일 |
> | [[mksglu]] | **Elastic License 2.0** | **호스팅·관리형 서비스 제공** | 없음(전면) |
> 🎯 ⇒ **둘 다 GitHub 표기가 `NOASSERTION` 인데 막는 대상이 완전히 다르다.** ⚖️ ELv2 가 더 강하다(서비스 제공 자체 금지 vs 브랜딩만 금지).
> 📌 **금일 GitHub 5건 중 2건(40%)이 이 상태였다** ⇒ `NOASSERTION` 을 "미확인"으로 넘기면 안 된다는 [[메타데이터-부재-추론]] 규약의 근거가 강화됐다.

> [!question] 미해결
> - `LICENSE_HISTORY` 내용 — **미열람**(파일별 선행 라이선스 미상).
> - 4항의 *"end users … individual natural persons with **direct access**"* 정의 모호 — 계정 수인지 동시접속인지.
> - 법인 설립지·규모 미확인(라이선스 문구 외 정보 없음).
> - enterprise license 가격·조건 공개 여부 미조사.
