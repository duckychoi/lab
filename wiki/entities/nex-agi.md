# nex-agi

> [!insight] 한 줄
> [[Nex-N2.5-mini]](35B) · [[Nex-N2.5-Pro]](397B) · Nex-N2.5-Max(1.6T) **3티어 에이전트 모델 패밀리**를 Apache-2.0으로 공개한 조직. 아키텍처는 `qwen3_5_moe` 계열 — [[Alibaba]] Qwen 생태계 위에 지었다.

> [!insight] 이 조직의 설계 사상 — **비전은 입력이 아니라 검증 인터페이스**
> 모델카드 본문: *"비전은 더 이상 입력 양식이 아니라 **에이전트가 환경을 인지·검증하는 인터페이스**"*
> → 컴퓨터·브라우저 조작 에이전트에게 화면을 **피드백 루프**로 쓴다. [[검사가능성-공사]] 의 아키텍처 층위 구현.
> → 그리고 이 사상이 **벤치마크에 실제로 나타난다**: 멀티모달 기반 [[Nex-N2.5-Pro]](397B)가 텍스트 전용 기반 Max(1.6T)를 **OSWorld-2에서 34.1점 앞선다**(56.4 vs 22.3). **기반이 크기를 이겼다.**

> [!warning] 🔴 이 조직의 문서화 관행 두 가지 결함
> 1. **패밀리 공용 모델카드** — mini·Pro의 `README.md` md5가 **바이트 단위 동일**(`f706fcb33c93`). 카드를 열고 "이 모델의 성능"을 읽으면 **다른 모델 숫자를 집는다** → [[단위-불일치]]
> 2. **모달리티 표기 자기모순** — `cardData.pipeline_tag` = `text-generation` 인데 HF 태그에는 `image-text-to-text` 가 있고 본문은 멀티모달로 기술 → [[파생표기-함정]] 의 신종 변형
> 3. **활성 파라미터 미기재** — MoE인데 총 파라미터만 있다. **추론 비용 계산 불가.**
> → 가중치는 열었는데(Apache-2.0·gated=False) **문서는 정밀하지 않다.** 벤치 수치를 인용하려면 볼트가 열 매핑을 직접 확인해야 한다.

> [!warning] 조직 실체 — 미확인
> HF 조직 계정 외에 **법인·연구진·논문 확인 없음**. 벤치마크는 전부 **자체보고**(arXiv 논문 미확인).
> → [[IFM]](2026-09-09, 실체 전혀 미확인 → reliability low)보다는 낫다 — **가중치가 실제로 공개돼 있고 mini는 다운로드 2,444로 실사용 흔적이 있다**. 그래서 **medium**.
> → 판정 기준: **가중치 공개 + 실사용 흔적 = medium** / 가중치 공개 + 실사용 없음 = low 후보 / 예고만 = low.
