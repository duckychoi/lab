# YOLO-PEFT — Parameter-Efficient Fine-Tuning for YOLO (2608.07051)

> [!insight] 핵심 인사이트
> **YOLO 패밀리(실시간 객체 탐지 모델)에 파라미터 효율적 파인튜닝(PEFT, 예: LoRA류)을 적용하는 방법 제안**(제목·raw 기반). LLM에서 표준이 된 PEFT를 비전 탐지 백본으로 이식해, 전체 가중치 재학습 없이 소량 파라미터만 갱신해 새 도메인/클래스에 적응시키려는 시도로 읽힌다. LLM 중심의 08월 위키에서 드물게 **비전 실용 효율화** 축의 소스로, "적은 자원으로 모델을 내 도메인에 맞추기"라는 실무 관심에 직접 닿는다. 나에겐 로컬/온디바이스 비전 태스크가 생길 때 "전체 재학습 대신 PEFT"라는 옵션을 상기시키는 참조점.
