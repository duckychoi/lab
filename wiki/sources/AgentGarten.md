# AgentGarten — 2,500만 에피소드 vs 4라운드, 그런데 단위가 다르다

**HF/arXiv**: https://huggingface.co/papers/2610.12374 · arXiv **2610.12374**
**업보트 135**(HF 데일리 **1위**) · 저자 14명 · published 2026-10-08
**독립 검증**: 🆕 `arxiv.org/html/2610.12374` **HTTP 200 · 321,099B 본문 열람**

> [!insight] 핵심 인사이트
> **시뮬레이터·게임엔진에 공유 뉴럴 렌더러를 결합해 실시간 상호작용 환경을 만든다.** 시뮬레이션 백엔드가 영속 월드 상태와 프로그램 정의 규칙을 담당하고, 렌더러가 공통 인터페이스로 내보낸 **구조화 조건**에서 시각 관측을 생성한다. 사전학습 비디오 모델을 기하 조건에 적응시킨 뒤 **Adversarial Forcing** 으로 증류해 **과거 관측 인코딩까지 역전파로 갱신**한다.
> 🔗 볼트 [[하네스-설계-축]] · [[측정도구-먼저-반증]] 연결 — 환경을 하네스로 보는 관점이다.

> [!insight] 🏆 Table 3 — 숨바꼭질 물리적 도구 사용 마일스톤, 2 패러다임 대조
> - 쉼터 건설: **self-play RL ≈2,500만 에피소드 vs 본 방식 4라운드**
> - 램프로 쉼터 진입: **≈1억 에피소드 vs 10라운드**
>
> ⚖️ **"4 vs 2,500만"을 배수로 환산하지 않는다 — 단위가 다르다**(에피소드 vs 라운드).
> 🎯 **1라운드가 몇 에피소드인지 본문에서 확정하지 못했다 = 볼트 확인 필요 항목**이고, **확정 없이는 학습효율 비교가 성립하지 않는다.** → [[복합지표-분해]] · [[단위-불일치]]

> [!insight] 🏆 Table 1 — 자기 기법의 비용까지 세 축 모두 적는다
> SGF 식 FlexAttention 리플레이는 상대 L2 오차 **3.99%** 인데, 본 방식 블록별 SDPA 리플레이는 **비트 단위 동일(0)**.
> - 순방향 시간 2.95s → **2.79s (−5.4%)**
> - 피크 메모리 50.83 → **50.92GiB (+0.2%)**
>
> 📌 **"정확도 개선 + 시간 감소 + 메모리 소폭 증가"를 세 축 모두 적은 드문 사례.** 메모리가 늘었다는 불리한 축을 지우지 않았다 → [[숨김유인-부호]] 반례 후보.

> [!warning] 목표로 선언한 것의 측정값이 미확인이다
> **환경 충실도(faithful)·현실성(realistic)을 목표로 선언했는데 그 자체의 측정값을 못 찾았다.** FVD/PSNR 류 수치를 본문 추출에서 발견하지 못했다.
> ⚖️ **없다고 단정하지 않는다. 미확인이다.**
> 🎯 이것이 중요한 이유: 같은 배치 [[Trace2Env]] 가 *"높은 시뮬 성공률이 충실한 월드모델을 뜻하지 않는다"* 를 실측했다 — **본 논문의 미측정 항목이 바로 그 함정이 사는 자리다.**

- **즉시 활용**: **NO** — 비디오 모델 증류와 시뮬레이터 결합은 볼트 자원 범위 밖이다. **단 설계 원칙 1개는 이전 가능**: *"렌더러를 공통 인터페이스로 두고 백엔드가 상태·규칙을 소유한다"* = [[reat]] 의 `Scene DSL → 렌더러` 분리와 동형이다.
- **6개월 영향력**: 에이전트 학습의 병목이 **데이터에서 환경으로** 이동한다. "환경을 생성한다"가 가능해지면 self-play 비용 구조가 바뀐다 — 단 그 주장의 분모(라운드 정의)가 확정돼야 한다.
- **대체 관계**: self-play RL 의 에피소드 대량 소비를 대체한다고 주장한다(단위 불일치로 **배수 확정 불가**).
- **허와 실**: ⚖️ **유리한 표면은 "2,500만 vs 4"다.** 라운드당 에피소드 수를 모르면 이 대비는 **수사이고 측정이 아니다.** 반면 Table 1 의 비용 보고는 정직하다 — **같은 논문 안에서 보고 품질이 갈린다.**
- **액션**: 본문에서 **"라운드" 정의**를 찾아 1라운드 = N에피소드를 확정한다.

> [!question] 미해결
> - **1라운드 = 몇 에피소드인가** — 확정 전까지 학습효율 비교 인용 금지.
> - 환경 충실도·현실성의 **정량 측정 존재 여부**(미확인, 부재 아님).
> - Adversarial Forcing 의 **구현 세부**와 공개 코드 유무 미확인.
