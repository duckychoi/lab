## 아키텍처 (raw 기재 · 모델 카드 기준)

- **Stacked Mixing Transformer** + **Variate Attention** + **CPM Iterative RevIN**
- **20층** · model dim **1280** · 헤드 **16** · 컨텍스트 패치 **32** / 예측 호라이즌 패치 **64**
- 사전학습 데이터: **fev-bench와 겹치는 셋을 제외한** GiftEvalPretrain · Wikipedia Pageviews(**2023-11 컷오프**) · Google Trends 상위 쿼리(**2022년말 컷오프**) · 합성·증강 데이터

> [!note] 데이터 오염 회피를 명시한 것은 가점, 그러나 벤치 수치는 없다
> **"fev-bench와 겹치는 셋을 제외"** 는 평가 오염(contamination)을 의식한 서술이다. [[검사가능성-공사]] 축에서 긍정적.
> **⚠️ 그럼에도 모델 카드 자체에는 벤치마크 수치가 없다**(raw 기재 정확). 09-03에 남긴 *"정확도 벤치 수치는 이번에도 미확인"* 이 **09-07에도 미해소**다. 오염 회피를 신경 쓴 팀이 **성능 수치는 카드에 안 실었다** — 별도 리포트나 논문에 있을 가능성이 높으나 **미확인**.
> 데이터 컷오프(2023-11 / 2022년말)는 **최근 시계열 예측 시 도메인 드리프트 위험**으로 읽어야 한다.
