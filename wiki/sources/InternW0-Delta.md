# InternW0-Δ (arXiv/HF 2609.31394)

**정식 제목**: *InternW0-Δ: A World Action Model Bridging Predictive Dynamics and Actions with 20K+ Hours of Open Data*

> [!insight] 핵심 인사이트 — **"미래를 그리지 않고 미래를 쓴다"**
> 기존 World Model 기반 로봇 정책은 추론 시 **미래 영상을 롤아웃**해야 해서 느렸다. InternW0-Δ 는 **Causal Imprint** 로 *"미래에 관련된 장면 변화"* 를 학습 단계에 흡수시키고, **추론 시에는 롤아웃 없이** 예측 표현을 액션 전문가에 직접 공급한다.
> 구조: 사전학습 **비디오 전문가 + 액션 전문가**를 **Mixture-of-Transformers** 안에서 **동결 VLM** 의 의미 지도 아래 상호작용시킨다. 4D 파운데이션 모델의 **기하·모션 prior 는 학습 시에만 증류**해 넣는다.
> 🎯 **"학습 때만 비싸고 추론 때는 싸다" 가 이 논문의 전체 요지다.** 4D prior 도, 미래 예측도 전부 학습으로 밀어 넣었다.

> [!warning] 🔴 정량 벤치마크 수치가 초록에 **0개**다
> *"시뮬레이션 벤치마크와 실제 로봇 플랫폼에서 강한 성능"* — **벤치 이름도, 수치도, 대조군도 없다.**
> **검증 가능한 것은 규모 수치뿐이다**: 2만 시간 초과 코퍼스 · 저자 48명. 볼트 독립 검증으로 **저자 48명 · 업보트 17 · publishedAt 2026-09-25 는 확인**했다. **성능은 확인할 방법이 초록 안에 없다.**
> 🎯 **오늘 5건 중 "규모는 검증되는데 성능은 검증 불가" 의 가장 선명한 사례다.** 규모는 셀 수 있고 성능은 재야 하는데, 재는 도구를 안 줬다.

> [!question] 🟡 공개가 전부 미래시제다 — 접지 말고 추적하라
> *"will open source"* + **"라이선스가 허용하는 범위에서"** 라는 조건이 붙었다. 2만 시간 코퍼스는 로봇 시연·UMI·1인칭 인간 시연·**Ego2Robot** 을 모아 정렬한 것이라 **출처별 라이선스가 제각각**이다 — 조건절이 붙은 이유가 이것일 가능성이 높다(볼트 추론).
> 📌 **[[검사가능성-공사]] 의 "미검증" 칸에 접어 넣지 말고 그대로 남겨 둔다.** 그래야 **이행 여부를 추적**할 수 있다. 09-18 [[MiMo-V2.6-RL-Livestream]] 의 *"몇 주 내 공개"* 가 9일 뒤 해소된 것과 같은 형태다. **약속의 시제를 기록하면 약속이 지표가 된다.**

## 도메인별 추출 (slam-3dgs)

> [!note] 🔀 도메인 재판정 — 수집기 `ai-news` → 볼트 **`slam-3dgs`**
> 로봇 조작 + **4D 파운데이션 모델의 기하·모션 prior** 가 핵심 재료다. 볼트의 `slam-3dgs` 도메인(로봇·카메라·기하) 정의에 직접 들어온다.
> 🔴 **다만 선례와 충돌한다**: [[Xiaomi-Robotics-VLA-Scaling]]·[[Xiaomi-Robotics-U0]] 는 `ai-news` 에 있다. **같은 계열이 두 도메인에 흩어져 있다** — lint 항목으로 등록한다. 볼트는 이번 건을 기하 prior 근거로 `slam-3dgs` 에 두되, **선례 3건을 한 번에 재판정할지는 별도 결정**으로 미룬다.

- **현재 SOTA**: ⬜ **판정 불가.** 수치가 없어 SOTA 주장도 하지 않았고 볼트도 할 수 없다.
- **실시간 가능성**: 🎯 **구조적으로는 유리하다** — 추론 시 미래 롤아웃을 제거한 것이 정확히 지연시간 설계다. 🔴 **단 fps·지연 수치가 초록에 없다.** "빨라야 하는 설계"와 "빠르다는 측정"은 다르다.
- **카메라 파이프라인**: 입력은 **로봇 시연 · UMI · 1인칭 인간 시연 · Ego2Robot** 을 **공통 state-action 표현으로 정렬**한 것. 🎯 **이종 소스 정렬이 이 논문의 실제 노동**이고 2만 시간의 정체다.
- **응용 가능성**: ⬜ 볼트에 로봇 하드웨어가 없다. **읽을 가치는 데이터 정렬 방법론** 쪽이다.
- **필수 레퍼런스**: 프로젝트 페이지 `internrobotics.github.io/InternW0-Delta/` — ⬜ **미열람**.
