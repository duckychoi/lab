## 도메인별 추출 (local-llm 템플릿)

- **실용성 판단**: MAYBE — 26M은 CPU·모바일 NPU에서 초저지연·초저전력 실행권. 단 26M 모델의 도구 라우팅 정확도(오호출률)가 실사용 임계치를 넘는지 실측 필수.
- **메모리 아키텍처**: 초소형 전용 분류·슬롯필링에 가까운 구조로 추정. 범용 지식이 아닌 "도구 스키마 → 인자 추출" 특화.
- **Hermes 적용**: 가능성 있음 — 상위 모델 앞단 라우터로 두면 토큰·지연·비용을 줄이는 게이트 역할. ChinameBot류 봇의 도구 호출 판단을 로컬에서 선처리.
- **트레이드오프**: 크기↓↓·속도↑↑ but 복잡한 다단계 도구 계획·모호한 발화 처리는 상위 모델 위임 불가피. 단일 턴 함수 호출에 국한.
- **오픈소스 구현체**: https://github.com/cactus-compute/needle — 온디바이스 배포 파이프라인 동반 예상.
- **액션**: 도구 스키마 5~10개로 오호출률·지연 벤치 → "로컬 라우터 + 클라우드 추론" 2단 분업 실현성 판단.
