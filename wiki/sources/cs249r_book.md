# harvard-edge/cs249r_book — Machine Learning Systems (하버드 cs249r)

> [!insight] 핵심 인사이트
> GitHub ⭐**26,336 (+793 당일)**. 하버드 cs249r "Machine Learning Systems" 강의의 **오픈 교재** — 모델 학습에서 그치지 않고 **배포·엣지 최적화·MLOps까지 "시스템 관점"**으로 정리. 이 위키의 [[local-llm]]·엣지 AI 도메인이 파편적 모델 뉴스로 채워져 있는데, 이 교재는 그것들을 **하나의 배포 파이프라인 관점(데이터→학습→양자화→온디바이스 서빙)**으로 꿰는 레퍼런스 축이 된다. 도구가 아니라 **읽고 내 멘탈모델을 정렬하는 자료**로서의 가치.

## 도메인별 추출 (ai-news 템플릿)

- **신뢰도**: ⭐⭐⭐⭐⭐ — 하버드 공식 강의 교재, ⭐26K, 학술 기반. 마케팅 클레임 없음.
- **즉시 활용**: 간접 YES — [[Ornith-1.0-9B]]·GGUF 양자화판을 "왜/언제 엣지에 올리나"를 시스템 관점에서 판단할 기준 제공. 도구처럼 설치하는 게 아니라 **선택 참고서**.
- **6개월 영향력**: 개별 모델은 빠르게 낡지만 시스템 설계 원칙은 오래 감. 엣지·온디바이스 배포를 실제로 할 때 반복 참조할 상수 자료.
- **대체 관계**: 단편 블로그·트윗 학습을 체계적 교재로 대체. [[AI-For-Beginners]](입문)보다 상위 레이어(시스템/배포).
- **허와 실**: 과장 없음. 다만 "읽을 것" 부채가 쌓이는 유형 — 실제 배포 과제와 묶어야 소화됨.
- **액션**: 엣지 최적화·양자화 챕터만 선별 정독 → 로컬 LLM 배포 결정 체크리스트로 요약.
