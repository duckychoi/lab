# SuperNav — 백본을 건드리지 않고 하네스만으로 베이스라인 2배

**HF/arXiv**: https://huggingface.co/papers/2610.12126 · arXiv **2610.12126**
**업보트 65**(HF 데일리 **5위**) · 저자 8명 · published 2026-10-08
**독립 검증**: 🆕 `arxiv.org/html/2610.12126` **HTTP 200 · 269,005B 본문 열람**
프로젝트 페이지 `zju3dv.github.io/SuperNav/` — **미조회**

> [!insight] 핵심 인사이트
> MLLM 을 내비게이션 전용으로 **파인튜닝하지 않고** 전용 에이전트 하네스(Navigation Skills · 물리 상호작용 Tools · 과제진행·컨텍스트 관리)를 붙여 **요청 해석·장면 이해·결정만** 맡기고 동작 실행은 내비게이션 도구에 위임한다. **이미지 위에 목적지를 직접 지정하는 통합 시각-점 인터페이스**로 결정과 모션을 잇고 실행 피드백으로 결정을 수정한다.

> [!insight] 🏆🏆 Table 1 — 하네스만으로 2배
> - 단일객체 내비 성공률 **78.00%** (최강 베이스라인 UniNaVid **34.00%**) ⇒ **+44.00pt · 2.29배**
> - 수요기반 내비 **59.50%** (최강 베이스라인 OmniNav Action Former **37.50%**) ⇒ **+22.00pt · 1.59배**
>
> 🎯 **"점수 = 모델 × 하네스"에 로보틱스가 2배치 연속 진입했다** — 10-05 [[MotorMind]] 는 **백본 교체**로 83.3% 를 냈고, 금일 SuperNav 는 **백본을 건드리지 않고 하네스만으로** 베이스라인 2배를 낸다.
> ⇒ **[[하네스-설계-축]] 가 금일 3건에서 동시 확인된다**([[Learn2Play]] 하네스 비용 절감 · 본 소스 하네스만으로 2배 · [[knowledge-work-plugins]] 직무 묶음) = **배치 내부 교차 2**.

> [!insight] 🆕 Table 2 — 성공률이 "얼마나 가까이 가야 성공인가"에 민감하다
> HM3D-OVON val-unseen **120 에피소드 부분집합**(OVON 전용 학습·적응 없이):
> - **1m 임계**: SR **73.33%** / SPL **0.4105**
> - **0.25m 임계**: SR **68.33%** / SPL **0.3837**
>
> ⇒ 임계를 1m → 0.25m 로 좁히면 **SR −5.00pt · SPL −0.0268**.
> 📌 🆕 신설: [[임계-의존-성공률]] — **성공률은 임계 명시 없이 인용 불가.**

> [!warning] "배치했다"는 실행이고 "성공률"은 시뮬레이션 수치다
> 실제 **4족 로봇에 배치**했다고 명시한다(Habitat-Sim RGB-D 640×480 · FOV 90° · 카메라 높이 1.25m · MLLM 입력은 InteriorGS 평가에서 256×192).
> ⚖️ **실기 성공률은 미확인이다.** 위 78.00% / 59.50% / 73.33% 는 **전부 시뮬 수치**이고, 실기는 "배치 사실"만 있다.
> 📌 10-06 [[RobotUse]] 와 같은 보고 공백이고, 10-05 [[MotorMind]] 는 xArm6 95% 로 기종을 적었다 ⇒ **같은 도메인에서 보고 수준이 갈린다.**
