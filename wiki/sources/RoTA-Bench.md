# RoTA-Bench: Evaluating 3D Spatial Reasoning through Interactive Projection Alignment

**HF 논문**: https://huggingface.co/papers/2610.17665
**업보트**: **75** (수집기 68 → 볼트 재조회 **+7**) · HF 데일리 5위 — 🔴 **현재 [[Dynamic-Band-Splitting]](75)과 동률**이라 수집기 보고 순위(4위/5위)는 이미 유효하지 않다 → [[캐시된-지표-신선도]]
**게시일**: **2026-10-14** · **31페이지 · 그림 2개**(arXiv `comments`)

> [!insight] 핵심 인사이트 — "본다"와 "정확히 돌린다" 사이가 끊어져 있다
> 목표 실루엣을 주고, 회전된 물체를 관찰하며 **제한된 행동 예산 안에서 연속적인 회전을 선택**해 목표 투영을 복원하게 한다. 🏆 **자동 파이프라인이 2D 아이콘에서 실루엣 보존 3D 객체를 만들고, 가역 초기화로 가해성(solvability)을 보장**한다 ⇒ **"풀 수 없는 문제라서 못 푼 것"이라는 변명을 설계로 제거했다** → [[측정도구-먼저-반증]] 의 모범.

## ✅ 초록 수치 전건 확증 (볼트 초록 1,425자 전문 대조)

| 주장 | 수치 | 볼트 판정 |
|---|---|---|
| 과제 규모 | **674과제** → **층화 100과제** 테스트셋 | ✅ 일치 |
| 모델 성공률 | **GPT-5.6-Sol 17%** | ✅ 일치 |
| 인간 성공률 | 학부생 **20명**, 테스트셋 **4회 완주**, **100%** | 🔴 수집기는 *"4회"* 를 누락 → [[한정어-탈락]] (단, **인간 쪽을 과소 기술**한 방향) |
| 이미지↔포즈 분기 | 모델 **19.4%** vs 인간 **10.9%** | ✅ 일치 (방향도 정확) |
| 이력 제거 시 | 행동의 **96.8%** 가 **30도 고정 스텝** | ✅ 일치 |

> [!insight] 🏆 볼트 발견 ① — **96.8% / 30도**는 "연속 제어가 12지선다로 붕괴한다"는 뜻이다
> 360도 ÷ 30도 = **12개 이산 위치**. 📌 **상호작용 이력을 제거하면 모델 행동의 96.8%가 이 12칸 격자에 갇힌다.** ⇒ 🎯 **모델의 "연속 회전 선택" 능력은 이력이 떠받치고 있던 것이고, 이력이 없으면 기본값(coarse step)으로 되돌아간다** → [[임계-의존-성공률]] · [[하네스-설계-축]].
> 🔴 **이것은 [[Self-Evolving-Agent-Harness]] 감사에서 활성화 축 충족이 10.2%뿐이라는 결과와 같은 얼굴이다** — *"무엇이 작동하는가"* 를 떼어 보면 대개 **하네스(이력·스캐폴드)** 가 일하고 있다.

> [!insight] 🏆 볼트 발견 ② — **인간 100%는 천장이고, 그래서 이 벤치는 인간을 순위 매기지 못한다**
> 17% vs 100% = **5.88배 격차**. 📌 **인간 쪽이 포화됐다는 것은 "난이도가 인간 기준으로는 쉽다"는 의미이고, 따라서 이 벤치의 수명은 모델이 100%에 접근할 때가 아니라 모델이 인간 하한을 넘을 때까지다.** ⇒ [[캘리브레이션-붕괴]] 와 반대 방향 사례(상한 포화).

> [!warning] 🔴 간판 17% 는 **674과제가 아니라 층화 100과제** 기준이다
> 초록이 명시한다 — *"yielding **674 tasks** and a **stratified 100-task test set**"*. 📌 **평가는 100과제(14.8%)에서 수행됐다.** 674 와 17% 를 같은 문장에 놓으면 규모를 과대 읽게 된다 → [[표본순위-전수순위]] · [[선발창-누락]]. 🔴 **수집기는 674·100 둘 다 적었으나 17% 가 어느 쪽 분모인지 연결하지 않았다.**

> [!insight] 📌 이미지 공간 진전과 포즈 공간 진전의 분기 — 19.4% vs 10.9% 의 정확한 의미
> 원문: *"at matched states, **the model** more often improves silhouette overlap while worsening pose alignment **than humans** (19.4% vs. 10.9%)"*
> ⇒ **같은 상태에서 모델은 "보기에는 가까워지는데 실제 자세는 멀어지는" 수를 인간보다 1.78배 자주 둔다.** 🎯 **보상 신호(실루엣 겹침)가 목표(포즈 정합)의 대리변수일 뿐이고, 모델은 대리변수를 최적화한다** → [[복합지표-분해]] · [[측정도구-먼저-반증]].

> [!action] 당장 할 것
> 볼트 [[slam-3dgs]] 도메인의 3D 이해 소스들과 **"2D 증거 → 3D 제어" 단절**을 교차 대조한다. 🎯 **금일 크론 노트 `리서치-2026년-휴머노이드-로봇-SLAMVLA로컬LLM-제어-최신-동향` 와 같은 축이고 같은 날 입고됐다** — VLA 제어 주장이 RoTA 가 보인 단절을 어떻게 다루는지가 직접 질문이다.
