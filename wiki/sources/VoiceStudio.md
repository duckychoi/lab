# debpalash/VoiceStudio — 모델이 아니라 **하네스**다

**GitHub**: https://github.com/debpalash/VoiceStudio
**지표(2026-09-03)**: ⭐**15,454** · 포크 **2,157** · 이슈 **12** · 워치 **73** · **Python** · **AGPL-3.0** · 생성 **2026-04-09** · **당일 푸시**(2026-09-03T08:58Z) — GitHub API 실호출 검증(raw 15,440 대비 **+14 드리프트**) · 트렌딩 데일리 **4위**(raw 기준 당일 +832)
**자기 규정**: *"Clone voices, dub video, dictate, and produce long-form audio on your own hardware."* · **구 명칭 OmniVoice-Studio**(개명)

> [!insight] 핵심 인사이트 — **TTS 모델이 아니라 27개 엔진 위의 껍데기다**
> raw는 이것을 *"ElevenLabs 대체 스택"* 으로 기록했으나, **README 실물을 열자 성격이 달라진다**:
> **16개 TTS 엔진 · 11개 ASR 엔진**을 카탈로그에서 **단축키(Ctrl/Cmd+E)로 갈아 끼우는** 데스크톱 앱이다.
> → **이 레포의 자산은 음성 모델이 아니라 "27개 엔진을 하나의 워크플로로 통일한 통합층"** 이다. 볼트가 [[SolarWM]]에서 같은 날 기록한 *"백본 네이티브 표현을 보존한 채 공통 인터페이스로 묶는다"* 와 **구조적으로 같은 패턴**이다 — 하나는 비디오 월드모델, 하나는 음성 엔진.
> 실행 범위: **CUDA · Apple Silicon MPS/MLX · ROCm · CPU · 원격 워커 옵션**, macOS 13.3+/Windows 10·11/Linux(glibc 2.39+)/Docker.

> [!insight] ⭐ **MCP 서버와 OpenAI 호환 오디오 API를 내장한다 — 내 파이프라인에 바로 붙는다**
> 인터페이스가 넷이다: **데스크톱 앱 · 로컬 REST/SSE/WebSocket API · OpenAI 호환 오디오 API · MCP 서버.**
> 이게 이번 배치에서 **나에게 가장 직접적인 항목**이다. 내 [[reat-voice]] 워크플로(대본 → 음성 MP3 + 자막 SRT)는 현재 외부 TTS에 의존하는데, 이 레포는:
> - **OpenAI 호환 오디오 API** → 기존 호출 코드를 **엔드포인트만 바꿔** 로컬로 전환 가능
> - **MCP 서버** → 에이전트가 음성 생성을 **툴로 직접 호출**
> - **ASR 11종 내장** → 자막(SRT) 생성까지 같은 스택에서
> - *"로컬 워크플로에는 계정·API 키·구독·사용량 미터가 없다"*(README 원문)
> → **actionable 등재(우선순위 높음).** 이번 배치 13건 중 **내 기존 작업에 그대로 꽂히는 유일한 항목**이다.

> [!warning] ⚠️ **"646개 언어"는 레포 자신이 이미 한정하고 있다**
> raw는 *"646개 언어 지원 범위와 음질 비교는 근거 미확인"* 으로 적었다. **README를 열자 레포가 스스로 단서를 달아 뒀다**:
> > *"646 TTS languages; **actual coverage and quality depend on the selected engine**"*
>
> 즉 **646은 통합된 엔진들의 언어 카탈로그 합집합**이지 이 소프트웨어가 보증하는 품질 범위가 아니다. **과장 주장이 아니라 명시적으로 한정된 주장**이었다.
> → 볼트 규칙 확인: **자체 주장을 의심할 때 README 원문을 먼저 연다.** 이번 배치에서 [[GLM-5.3]]은 원문을 열어도 자체 표뿐이었지만, 여기서는 **원문이 raw의 의심을 해소**했다. 09-02의 *"배지를 근거로 쓰지 않는다"* 규칙의 **역방향 적용 사례** — 원문이 주장을 **약화시키는 쪽으로** 정확했다.
> 추가로 README가 스스로 붙인 경고: **`> [!WARNING] Active beta.`** — `main`은 릴리스 간 변경될 수 있으니 최신 릴리스를 쓰라고 명시.

> [!warning] 라이선스는 **두 층**이다 — AGPL-3.0은 앱에만 걸린다
> README 원문: *"**AGPL-3.0 application; downloaded models keep their upstream terms.**"*
> - **앱 층**: AGPL-3.0 → **네트워크 서비스로 제공하면 소스 공개 의무**가 걸린다. 개인 로컬 사용은 무관하나 **SaaS에 임베드하면 정면으로 걸린다.**
> - **모델 층**: 내려받는 16+11개 엔진은 **각자의 상위 라이선스를 유지**한다. 상업적 사용 가부는 **엔진마다 따로 확인**해야 한다.
> → 볼트 09-02 규칙(*NOASSERTION은 "정보 없음"이 아니다*)의 확장 케이스다. 여기는 SPDX가 깨끗한 `AGPL-3.0`인데도 **실질 조건은 2층**이다. **개인 워크플로 = 문제없음 / 제품 임베드 = 엔진별 심사 필요.**

- **액션**: **로컬 설치 후 [[reat-voice]] 대체 스팟체크**(높음). **엔진 목록 16+11종 확인 후 한국어 품질 상위 엔진 특정**(높음). 제품 임베드 검토 시 **엔진별 라이선스 심사**(보류 — 개인 사용에는 불필요).
