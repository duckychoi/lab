# Puro-2B: Poor Lab's Qwen2-1.5B Trained on RTX 5090 within $5090

**arXiv**: 2608.27370 · **HF**: https://huggingface.co/papers/2608.27370
**지표(2026-08-31)**: 업보트 **13** · 저자 **11인** · 공개 **2026-08-27** — HF API 실호출 + **초록 원문 대조 검증**
**공개 범위**: **데이터 · 코드 · 가중치 전량 Apache 2.0** — https://huggingface.co/collections/thu-pacman/puro-2b
**학습**: 최대 **1.4조 토큰** · **FP8** · 컨슈머 **RTX 5090**

> [!insight] 핵심 인사이트 — 빠져 있던 것은 오픈 모델이 아니라 **오픈 레시피**였다
> 논문의 문제 제기가 정확하다. 오픈 가중치 모델도 있고 오픈 학습 레시피도 있지만, **"비용 효율적 + 하드웨어 접근 가능 + 오픈소스"를 동시에 만족하는 사전학습 레시피는 없었다.** 이 셋의 교집합이 공백이었다는 지적이 이 논문의 자리다.
> 비교 기준선도 명시했다: Llama-3.2-3B 학습에 **$1.5M 초과**, SmolLM3-3B 재현에 **$700K 초과**. 여기에 대고 컨슈머 GPU 한 장을 들이민다.
> 비용 효율의 출처를 **하드웨어 선택 · 저정밀(FP8) 학습 · hyperball 최적화 · 커리큘럼 모델 평균화 · 데이터 레시피**의 조합으로 열거했다 — 단일 트릭이 아니라는 뜻이며, 그래서 **부분만 떼어 쓰면 재현되지 않을 가능성**이 있다.

> [!warning] ⚠️ 제목의 "$5090"과 실제 학습 비용은 다르다 — raw 요약이 이 지점에서 부정확했다
> 초록을 대조하면 **두 개의 서로 다른 수치**가 있고, 섞으면 안 된다.
> - **실제로 학습한 최고 모델**: 컴퓨트 비용 **$6.9K 미만**, 성능은 **Qwen2.5-1.5B에 근접**(approaches) — *저자들의 평가 프로토콜 하에서*
> - **스케일링 법칙의 외삽치**: 적합된 Puro Cost Scaling Law가 **약 $4.4K면 Qwen2-1.5B 성능에 충분**하다고 *시사(suggests)*
>
> 즉 **제목의 "$5090 이내"를 만족하는 것은 실측이 아니라 법칙에서 뽑은 예측값**이고, 그 예측의 목표도 Qwen2.5가 아니라 **한 세대 아래인 Qwen2**-1.5B다. raw 수집 메모는 *"$5,090 이하 예산으로 사전학습을 재현"* + *"약 $4.4K면 Qwen2-1.5B 성능"* 으로 적어 **실측 $6.9K를 누락**했다. **볼트는 실측 $6.9K(→Qwen2.5-1.5B 근접)와 외삽 $4.4K(→Qwen2-1.5B)를 분리해 기록한다.**
> 추가 미검증: "our evaluation protocol"이 **자체 프로토콜**이며 초록에 벤치명·점수가 없다. "approaches"의 격차 크기도 알 수 없다.

> [!insight] 진짜 가치는 비용이 아니라 **통제 실험이 가능해진다**는 두 번째 결과
> 논문이 스스로 꼽은 부가 결과가 더 중요하다: 사전학습 **데이터 커리큘럼이 사후학습(post-training) 이후 성능을 어떻게 형성하는가**를 end-to-end로 조사했다. 그리고 그 이유를 정확히 밝힌다 — **"가중치만이 아니라 전체 사전학습 파이프라인에 접근할 수 있어서"** 가능했다는 것이다.
> 이것이 [[actionable]]에 이미 있는 *"부분 공개 함정 — 오픈 가중치 모델은 빠진 모듈을 먼저 확인한다"* 원칙의 **양성 사례**다. 가중치만 공개된 모델로는 데이터 커리큘럼 효과를 물을 수 없다. Puro-2B는 **질문 가능한 대상 자체를 늘린다**.

> [!action] 즉시 확인할 것
> 컬렉션 https://huggingface.co/collections/thu-pacman/puro-2b 에서 **(1) 데이터 레시피가 정말 재배포 가능한 형태인지 (2) FP8 학습 코드가 RTX 5090 외 카드에서도 도는지 (3) hyperball optimization의 구현체가 포함됐는지** 세 가지를 확인한다. 셋 중 하나라도 빠지면 "전량 공개" 주장은 축소된다.

## 도메인별 추출 (local-llm)

- **신뢰도**: high(HF API 실호출 + 초록 대조 · Apache 2.0 명시 · 저자 11인 · THU-PACMAN). 단 **성능 주장은 자체 프로토콜**이고 벤치 수치 미기재.
- **즉시 활용**: **간접 YES**. 사전학습을 직접 할 일은 없지만, **FP8 + 컨슈머 GPU 조합의 실증 레퍼런스**로서 로컬 파인튜닝 비용 추정의 기준선이 된다. 1.4조 토큰을 5090 한 장으로 돌렸다는 사실 자체가 상한선 정보다.
- **6개월 영향력**: **크다.** "사전학습은 대기업 전용"이라는 전제가 학술·오픈소스 층에서 깨지는 구간. 다만 2B급이라는 점은 냉정히 볼 것 — 프론티어 재현이 아니라 **통제 실험 플랫폼**의 민주화다.
- **대체 관계**: 오픈 가중치 모델(가중치만)을 **오픈 파이프라인**으로 대체. [[Qwen3.8-27B]]처럼 쓰는 모델이 아니라 **연구하는 모델**이다.
- **허와 실**: 마케팅 걷어내면 = **컨슈머 GPU FP8 사전학습 레시피 + 비용-성능 적합 곡선 + 전량 공개**. 제목의 $5,090은 **마케팅 수치(외삽)** 이고 실측은 $6.9K다. 그럼에도 $700K~$1.5M 대비 **두 자릿수 배수의 절감**이라는 골자는 흔들리지 않는다.
- **액션**: 볼트의 비용 감각 갱신 — *"소형 모델 사전학습 = 수천 달러대"* 를 새 기준선으로 등재. 단 **$4.4K가 아니라 $6.9K(실측)** 로 적는다.
