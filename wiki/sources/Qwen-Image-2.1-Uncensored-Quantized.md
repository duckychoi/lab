## 도메인별 추출 (local-llm)

- **실용성 판단**: 🟡 **조건부 YES.** 권장 구성(Q4_K_M + int8 인코더 오프로드)이면 **VRAM 약 4.6GB + RAM 약 9.4GB** 로 **8GB VRAM 급 카드에서 가능**하다. 🔴 단 ① **총 디스크·메모리 14.63GB** ② `leejet` 포크 필요 ③ **품질 손실폭 미확인**(봉인) ④ **연구용 라이선스**.
- **메모리 아키텍처**: 🎯 **VRAM/RAM 역할 분리**가 설계의 핵심 — 샘플링은 GPU, 텍스트 인코딩은 CPU(프롬프트당 1회라 빈도가 낮다). 📌 **"한 번만 쓰는 큰 모듈을 느린 메모리에 둔다"** 는 패턴이고, [[Qwen3.8-Flash-Next-GSQ-RCO-GGUF]] 의 n-gram 테이블 디스크 mmap 과 **동일한 원리**다.
- **Hermes 적용**: ❌ **해당 없음** — 이미지 생성 모델이고 ChinameBot(텍스트/에이전트)과 직접 접점이 없다. 🎯 단 **[[video-saas]] 쪽에서는 후보다**: 로컬 이미지 생성으로 썸네일·키프레임을 만드는 경로.
- **트레이드오프**: 🔴 **정량화 불가(봉인).** 크기 축만 확정: BF16 14.23 → Q4_K_M 4.60 = **3.09배 축소**, NVFP4 4.20 = **3.39배 축소**. **품질 대가는 미지**다.
