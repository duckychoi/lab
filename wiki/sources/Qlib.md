# Microsoft Qlib — End-to-End 퀀트 AI 리서치 프레임워크

## 핵심 인사이트

> [!insight] 핵심 인사이트
> Microsoft가 개발한 금융 데이터 전용 ML/RL/GNN end-to-end 퀀트 리서치 플랫폼. ⭐43,714. Alpha 발굴부터 백테스팅·포트폴리오 관리까지 전 과정을 단일 프레임워크로. [[TradingAgents]], [[금융-AI]] 도메인의 견고한 인프라 레이어.

- **신뢰도**: ⭐⭐⭐⭐⭐ — GitHub ⭐43,714, Microsoft 공식 오픈소스, arXiv 논문 동반
- **즉시 활용**: YES (리서치 목적) — pip install pyqlib 후 A-share/US 시장 데이터로 바로 실험 가능
- **6개월 영향력**: LLM 에이전트 + 퀀트 리서치 결합 트렌드에서 핵심 인프라. [[TradingAgents]] 같은 멀티에이전트 시스템의 백엔드로 활용 가능
- **대체 관계**: QuantConnect/Zipline 대비 ML 파이프라인 네이티브 지원이 강점
- **허와 실**: 중국 시장(A-share) 데이터 중심 설계. 미국 시장 적용 시 데이터 파이프라인 커스터마이징 필요
- **액션**: star/fork 후 예제 노트북 실행. GNN 기반 종목 관계 모델링 실험

> [!note] 배경 정보
> Qlib은 단순 백테스터가 아니라 "데이터→피처→모델→시그널→포트폴리오→주문 실행" 전 과정을 커버하는 연구 인프라. LLM 기반 Alpha 생성과 결합 시 강력한 파이프라인 구성 가능.

## 주요 기능

- **ML 파이프라인**: LightGBM, LSTM, Transformer, GNN 등 다양한 모델 지원
- **RL 지원**: 강화학습 기반 포트폴리오 최적화
- **GNN**: 종목 간 관계 그래프 모델링 (섹터, 공급망 등)
- **백테스팅 엔진**: 트랜잭션 비용, 슬리피지 시뮬레이션 포함
- **데이터 레이어**: 주가, 펀더멘털, 뉴스 등 통합 데이터 인터페이스
