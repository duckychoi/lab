# MJev-Spatial: System One Spatial Intelligence via Native Attention Matching

**arXiv**: 2610.22276 · **HF**: https://huggingface.co/papers/2610.22276
**upvote**: **286** (2026-10-17 실측 · 🔴 수집기 **281** 대비 **+5** = 관측 시차 · HF 데일리페이퍼 10-16 목록 4위)
**저자**: 12인 · published 2026-10-15
**코드**: https://github.com/Fr0zenCrane/MJev-Spatial · **프로젝트**: https://fr0zencrane.github.io/mjev-spatial-project/
**신뢰도**: ⭐⭐⭐

> [!insight] 🏆 핵심 인사이트 — **출력공간이 작은데 자기회귀로 답하고 있었다는 지적**
> 저자 진단: 공간 질의의 답은 *"one of a few options, a scalar, or a 2D point"* 로 **출력공간이 작다**. 그런데 VLM 은 이걸 **자유형식 텍스트 생성**으로 답하므로 **자기회귀 디코딩 + 답변 파싱 비용을 매번 낸다**.
> 해법: 각 후보를 **클래스로 두고 백본의 사전학습된 query/key 투사로 점수화**한다 ⇒ **파라미터 추가 0** · **추론 시 답변 토큰 생성 0** · **포워드 1회**.
> ⇒ 🎯 **새 모델을 학습한 게 아니라 이미 있는 어텐션을 분류기로 재해석했다.** 이게 "파라미터 0 추가"의 정체다.
> ⇒ 📌 수치·점 예측은 **coarse-to-fine** 으로 처리한다(값 구간 bin · 이미지 영역) — 즉 **연속량도 분류로 환원**했다.

## 측정 (초록 전문 교차검증 완료)

- 기반 **Qwen3.5-4B** · 학습 **12.3M QA**(기존 공간 데이터셋 변환)
- **종합 1위 65.64%** (테스트 8개 모델 중)
- **12개 벤치마크 중 7개 1위**
- 🏆 **12개 전부에서 자기 베이스(미변형 자기회귀) 상회** ← 1위보다 이 수치가 강하다(전건 우위 = 특정 벤치 운이 아니다)
- 속도: **최속 자기회귀 베이스라인 대비 2.5배** · **자기 베이스 대비 5.6배**
- 학습 처리량 **+30.8%** (teacher forcing 1 포워드 공동 지도 + length-aware global batching + 크로스GPU 로드밸런싱)

> [!note] ⚖️ 수치 읽기 — "1위 65.64%" 보다 "12/12 자기베이스 상회"가 센 주장이다
> 8개 모델 중 1위는 **비교군 구성에 의존**한다(어떤 8개인지 초록에 없다).
> 반면 **자기 베이스 대비 12/12 상회**는 **동일 백본 통제 비교**이므로 기법 효과를 분리한다.
> 🔴 단 **절대 점수표·비교 모델 명단이 초록에 없다** — 레포/프로젝트 페이지 미열람(이월).

## 도메인별 추출 (slam-3dgs 템플릿)

- **현재 SOTA**: 공간 이해 과제 종합 **65.64%** 가 금일 확보한 최신 수치. 🔴 65.64% 는 **종합 점수**이고 12개 벤치의 가중·구성이 미공시다.
- **실시간 가능성**: 🏆 **구조적으로 유리하다** — 포워드 1회 · 답변 토큰 0 · 파라미터 추가 0 이므로 지연이 **백본 1패스로 상한**된다. 자기 베이스 대비 5.6배는 *"interaction rates"* 요구(저자 표현)에 맞춘 설계 의도의 결과다. 🔴 **단 fps·ms 수치가 초록에 없다** ⇒ "30fps+ 가능?"에 답할 수 없다.
- **카메라 파이프라인**: 입력은 VLM 표준(이미지 + 질의). 점 예측을 **이미지 영역 coarse-to-fine 분류**로 처리하므로 **출력이 픽셀 좌표 회귀가 아니라 영역 선택**이다 ⇒ 정밀도 상한이 bin 해상도에 묶인다(미공시).
- **응용 가능성**: 로봇 조작의 *"어디에 놓을까"*(2D point) · *"얼마나 먼가"*(scalar) · *"어떤 공간관계인가"*(choice) 세 유형을 **한 프레임워크로** 처리 ⇒ VLA 제어 스택의 공간 질의 레이어로 바로 대응된다.
- **필수 레퍼런스**: `Fr0zenCrane/MJev-Spatial` — **파라미터 0 추가**가 사실이면 기존 Qwen3.5-4B 체크포인트에 **추가 학습 없이 붙는 추론 경로**인지가 핵심이고, 레포가 그 답을 가진다.

> [!question] 미해결
> ① **"파라미터 추가 0"이 "추가 학습 0"을 의미하지 않는다** — 12.3M QA 로 **학습했다**고 초록에 있다. 즉 가중치는 변했고 *구조*만 안 늘었다. 기성 Qwen3.5-4B 에 바로 적용되는지는 **미확인**.
> ② bin 해상도 ↔ 점 예측 정밀도 트레이드오프 미공시.
> ③ 레포·프로젝트 페이지 미열람(규약 ⑨/⑫ 이월).
