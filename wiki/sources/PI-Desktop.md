# PI-Desktop

> [!insight] 핵심 인사이트
> Electron 프런트 + **Rust 호스트 코어**(권한·파일시스템·SQLite·시크릿) 구조의 에이전트 데스크톱. **계정·필수 릴레이·에디터 종속이 없고**, OpenAI·Anthropic·**로컬 모델**·OpenAI 호환 API를 **세션별로 교체**한다.
> 특권 동작은 반드시 권한 레이어를 경유하며, diff·명령 출력을 검토해 **세션별 자율성 수준**을 지정한다.
> → 에이전트 하네스의 신뢰 경계를 **UI가 아니라 별도 언어(Rust) 프로세스**에 둔 설계.

> [!insight] 🎯 이 배치 최고의 정직함 — 격리 주장에 상한을 명시했다
> README 자인:
> > *"플러그인 프로세스는 권한 게이트되고 렌더러와 격리되지만, **완전한 OS 샌드박스가 아니라 사용자가 신뢰하는 코드다**."*
> → **격리를 주장하면서 그 격리의 한계를 같은 문장에서 밝히는 사례는 드물다.** 대부분의 하네스는 "샌드박스"라는 단어를 검증 없이 쓴다.
> → [[Pascal-Editor]] 의 *"심사 준비됐음을 증명하지 않는다"* 와 함께 **이번 배치의 "자기제한 명시" 2건**. 볼트가 그동안 쌓아온 *"벤더의 자기규정 vs 자기측정"* 문제의 **반대 사례** — 여기서는 자기규정이 자기측정보다 **보수적**이다.

> [!note] raw의 검증 방식이 옳았다
> raw는 *"Rust 호스트 코어"* 를 **description이 아니라 README 351행 아키텍처 다이어그램**에서 확인했다고 기록했다. 볼트가 GitHub API description을 실측한 결과 — description에도 `Rust host core` 문구가 **실제로 있다**.
> → 즉 raw는 **description에도 있는 정보를 굳이 README 원문으로 재확인**했다. 09-08 규칙(*"description은 소스가 아니다"*)을 **과잉 준수**한 셈인데, 이 방향의 과잉은 비용이 없다. **유지할 습관.**

> [!warning] Early Preview 자인 + 레포 나이 함정
> - **API·확장 인터페이스·동작이 계속 변경될 수 있음**을 스스로 밝힘.
> - **생성일 2023-03-22** — 3년 반 된 레포다. 그런데 당일 **+417 스타**(총 1,971). **레포 나이와 스타 급증이 어긋난다** → 최근 **방향 전환(피벗)** 이거나 재공개일 가능성이 높다. 초기 커밋 이력이 현재 제품과 무관할 수 있으므로 **"3년 검증된 프로젝트"로 읽으면 안 된다.**
