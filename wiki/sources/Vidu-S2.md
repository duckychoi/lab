# HF논문: Vidu S2 — Real-Time Interactive, Editable, and Spatial Video Generation (arXiv 2609.11638)

**URL**: https://huggingface.co/papers/2609.11638
**지표(2026-09-15 API 실측)**: 업보트 **150**(raw 기록 147 · **+3**) · 저자 **35인** · arXiv 발행 2026-09-10
**데모**: https://vidu.com/vidu-stream

> [!note] 🔀 도메인 재판정: raw `ai-news` → **`video-saas`**
> 재판정 근거: **전작 [[Vidu-S1]] 이 이미 `video-saas` 에 있다.** 같은 계보의 후속작을 다른 도메인에 두면 도메인 누적 인사이트가 끊긴다. 09-14 [[LIT]]·09-13 [[FreeFlow]] 재판정과 동일 기준(내용이 도메인 템플릿에 답하는가).

> [!insight] 핵심 인사이트
> **S2-Avatar**(실시간 인터랙티브 디지털 캐릭터)와 **S2-Editing**(실시간 비디오 편집) 두 모델. 여기에 **실시간 공간(spatial) 비디오** 생성 가능성을 함께 탐색 — 제목에 `Spatial` 이 들어간 이유다.
>
> **[[Vidu-S1]] 대비 델타(초록 명시)**:
> - **540p → 720p** 실시간 생성
> - **언제든 갱신 가능한 동적 레퍼런스**(dynamic references updated at any moment)
> - **지시 따르기 강화** — 춤(dancing) 같은 동작
> - **S2-Editing 신설**: 스트림 상태에서 스타일 렌더링 · 의상 교체 · 인물 교체 · 배경 교체
>
> 🎯 **video-saas 관점의 핵심**: S1이 *"실시간 생성"* 을 열었다면 S2는 **"실시간 편집"** 을 연다. 배치형 파이프라인(프롬프트→렌더→클립→편집)에서 **편집이 렌더 뒤가 아니라 스트림 위에서 일어난다.** 내 reat-* 스택의 전제(렌더 후 후처리)와 정면으로 다른 축.

> [!warning] 🔴 성립 조건 **부재** — 이 배치 논문 5건 중 유일
> 초록 원문 전부: *"Experiments show that Vidu S2 **outperforms all baselines**."*
> **baseline 이름·벤치마크명·수치가 하나도 없다.** 초록 내에서 확인 가능한 비교 대상은 **자사 전작 Vidu S1뿐**이다.
> 검증 가능한 근거는 플레이 가능한 온라인 데모 링크가 전부.
> 📌 **수치 인용 시 반드시 이 부재를 함께 표기할 것.** [[한정어-탈락]] 을 일으키기 가장 쉬운 형태 — *"모든 베이스라인을 능가"* 는 인용하기 좋고 검증은 불가능하다.
> 🔴 **S1 대비 해상도 향상(540p→720p)조차 같은 GPU 조건인지 초록에 없다.** S1은 *"소비자 GPU 540p·42FPS"* 를 명시했는데 S2는 하드웨어 조건을 적지 않았다 → [[단위-불일치]] 위험.

## 도메인별 추출 (video-saas)

- **신뢰도**: ⭐ 초록 전문 대조 완료했으나 **정량 근거 0**. 데모는 존재하나 미실측 → low (S1은 medium이었다 — **후속작이 신뢰도가 더 낮다**)
- **기능 벤치마킹**: "스트림 위 실시간 편집"은 현재 스택과 근본적으로 다른 축. 구현 난이도 최상. **UX 지향점으로만 참고.**
- **크리에이터 인사이트**: 사용자는 "생성→수정" 왕복이 아니라 **"보면서 고치기"** 를 원한다. 의상/인물/배경 교체를 스트림에서 한다는 건 **프리뷰와 최종본의 구분이 사라진다**는 뜻.
- **워크플로우**: 캐릭터 업로드 → 실시간 스트림 → **스트림 위에서 직접 교체·스타일 변경**
- **경쟁 우위 빈틈**: 상용툴이 배치 렌더 중심인 지점에서 **실시간 편집**이 차별화 여지. 단 **검증 불가 상태의 주장**이므로 추종 판단은 데모 실측 후.
- **허와 실**: 마케팅을 걷어내면 **"데모가 있다"** 가 전부다. 그러나 데모가 실재한다는 점은 [[MiroFish]](데모조차 정성 사례)보다는 낫다.

> [!action] 당장 할 것
> **vidu.com/vidu-stream 데모 직접 실측** — 720p 실시간이 실제로 나오는지, 편집 지연이 얼마인지. 논문이 안 준 수치는 데모에서만 얻을 수 있다.
