# Stealing Reasoning Traces from Proprietary LLM APIs (2608.09867)

**HF 논문**: https://huggingface.co/papers/2608.09867
**업보트**: 4 (2026-08-11 자동수집)

> [!insight] 핵심 인사이트
> **독점 LLM API가 클라이언트로 반환하는 "암호화된 CoT(사고사슬) 블록"에서 실제 추론 트레이스를 복원할 수 있음을 보인 보안 분석**(제목·raw 기반). 최근 상용 추론 모델들은 내부 사고과정을 숨기려고 CoT를 은닉/암호화해 내보내는데, 이 논문은 그 방어가 취약할 수 있음 — 반환 블록만으로 은닉된 추론을 재구성 가능함 — 을 지적한다. 함의는 두 방향: ①**공급자 측** 추론 은닉이 생각만큼 안전하지 않다(모델 IP·안전 필터 로직 노출 위험), ②**이용자·연구 측** 블랙박스 모델의 실제 추론을 관찰·감사할 여지. [[Scaling-Interpretable-LLM]](설계된 해석성)·[[semantica]](감사가능성)와 함께 "AI의 사고를 숨길 것인가 드러낼 것인가" 축의 반대편 데이터 포인트 — 은닉을 뚫는 쪽. 내 사실확인·근거 추적 기조에서 "모델이 무엇을 근거로 답했는지"의 관측가능성 논의로 연결.
