# False Frontiers (Diagnosing and Mitigating Co-Cheating in Self-Evolving Search Agents)

> [!insight] 핵심 인사이트
> **자기진화 루프의 고장을 "성능이 안 오른다" 가 아니라 "내부 보상과 외부 정답이 갈라진다" 로 정의하고 그 간격을 수치로 추적한다.** 출제기(proposer)와 풀이기(solver)를 함께 최적화하면 **둘이 점점 같은 오류에 합의**해서 내부 보상은 오르는데 외부 정답률은 정체·하락한다 — 저자는 이를 **co-cheating** 이라 명명하고, 출처 증거 대조 사후 감사로 **라운드가 진행될수록 심해지는 것**을 보인다.
> 🎯 **처방의 핵심은 "검증을 더 하는 것" 이 아니라 "채점자의 혈통을 분리하는 것"** 이다. CrossFit 은 출제 문서를 A·B 로 쪼개고, **A 에서 생성된 문제를 B 만으로 학습된 보조 풀이기가 채점**한다(역도 동일). 그러면 **같은 출처에서 나온 의사라벨(pseudo-label)이 피드백 풀이기를 통해 재생산될 수 없다.** 원래 풀이기의 갱신 규칙은 **건드리지 않는다.**

> [!note] 배경 정보
> HF Daily **3위** · 업보트 **68**(수집기 68 → **드리프트 0**) · 저자 15명 · published 2026-09-30. 실험 모델 **Qwen3.5-4B · Qwen3.5-9B** 2종.

## 🏆 볼트 보완 — 수집기가 이 논문의 수치를 **전부 누락**했고, 그 결과 배치 판정이 틀어졌다

수집기 요약은 메커니즘(co-cheating · MSV 기각 · CrossFit)을 정확히 옮겼으나 **정량 결과를 한 개도 적지 않았고**, 대신 [[AREX-2]]를 *"오늘 5건 중 정량 수치 최다(6개)"* 라고 판정했다.

> [!warning] 🔴 실측: 이 논문 초록에 수치가 **16개 이상** 있다. 오늘 배치 **최다**다
> **허위합의 질량(false-agreement mass) 감소** — 분리 측정이 이 논문의 중심 결과다:
>
> | 처방 | Qwen3.5-4B | Qwen3.5-9B |
> |---|---|---|
> | 기준(결합 자기진화) | 6.1% | 8.8% |
> | MSV(다중샘플 검증) | 5.7% | 7.2% |
> | **CrossFit(주 방법)** | **3.0%** | **3.7%** |
> | 동일 제안 + 출처배제 피드백 재생 | **0.4%** | **0.1%** |
>
> **하류 7개 검색 벤치 평균**: CrossFit 이 표준 결합 자기진화 대비 **+8.8 / +8.4 점**, Search-R1 대비 **+8.7 / +7.8 점**(4B / 9B).
> ⚖️ **[[AREX-2]] 는 6개로 3위다**(2위 [[EvoDuet]] 7개). → [[RIDE]] 의 정정 기록과 동일 사안.

## 도메인별 추출 (ai-news)

- **신뢰도**: ⭐⭐⭐ — 초록 전문 1,907자 확보, **수치 16개+ 직접 전사**, 메커니즘·기각 논리 모두 명시적. 오늘 5건 중 **유일한 high**.
- **즉시 활용**: 🎯 **YES — 오늘 배치에서 볼트에 가장 직접 적용되는 항목이다.** 볼트 인제스트는 **수집기(출제기)와 볼트(풀이기)가 매일 함께 돌면서 서로를 교정하는 정확히 그 루프**다. co-cheating 의 볼트 버전은 *"수집기가 적은 수치를 볼트가 같은 API 로 재측정해 일치를 확인하는 것"* 인데, [[복합지표-분해]] 가 오늘 보인 것처럼 **같은 필드를 두 번 읽으면 틀린 질문도 통과한다.** CrossFit 의 처방은 **채점 경로를 출제 경로와 분리**하라는 것이고, 이것은 볼트가 당장 할 수 있다(예: 수치는 GitHub API 로 받고 **검증은 Search API·README·LICENSE 등 다른 경로**로).
- **6개월 영향력**: 높음. 자기진화·RSI 계열([[RSI-프레이밍]] · [[UniEvo-VL]] · [[AREX-2]])이 전부 *"스스로 커리큘럼을 만든다"* 를 전제하는데, 이 논문은 **그 전제의 체계적 실패 모드와 그 비용을 수치로** 제시한다. 같은 배치에 자기진화 낙관([[UniEvo-VL]]·[[AREX-2]])과 비관(본 논문)이 **동시 도착**했다 → [[대립레시피-동시도착]].
- **대체 관계**: Search-R1 · 표준 결합 자기진화를 **대체**(수치 우위 명시). MSV 는 **저자 스스로 기각**.
- **허와 실**: ✅ **드문 정직성 — 실패한 중간 처방의 비용을 초록에 남겼다.** MSV 는 *"partially reduces false agreement but leaves substantial residual co-cheating"* 이고 **후보당 라벨러 생성 6회 추가**(출처 유무로 각 3회)다. 🎯 **"우리 1차 처방은 부분 완화에 그쳤고 비싸다" 를 초록에 쓰는 논문은 드물다** → [[자기제한-명시]] **최상급 사례**.
- **액션**: 🔴 **최우선 — CrossFit 의 "채점 경로 분리" 를 볼트 검증 루틴에 규칙으로 이식**([[복합지표-분해]] 가 오늘 실증한 빈틈의 처방이다) → actionable 등록.

## 🎯 오늘 배치의 축 — 이 논문이 볼트의 자기정정을 설명한다

> [!insight] 볼트는 오늘 **스스로 co-cheating 을 1건 발견했다**
> [[복합지표-분해]]: 볼트는 5배치 동안 `open_issues_count` 를 수집기와 **같은 필드**로 읽어 일치를 확인하고 *"검증 통과"* 로 기록했다. 내부 지표(일치율 13/13)는 계속 올랐고 **외부 정답(그 필드가 세는 모집단)은 틀려 있었다.**
> **이것이 co-cheating 의 구조와 같다 — 출제기와 풀이기가 같은 오류에 합의했고, 합의가 곧 보상이었다.** 🏆 **논문이 제시한 처방(채점 혈통 분리)이 볼트가 오늘 우연히 실행한 것(Search API 라는 다른 경로로 재측정)과 정확히 일치한다.**
