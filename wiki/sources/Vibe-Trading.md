# Vibe-Trading (HKUDS/Vibe-Trading)

> [!insight] 핵심 인사이트
> **⭐23,216 (2026-07-15, 당일 +1,256) ← ⭐21,022 (07-13, +768, 트렌딩 1위).** 이틀 +2,194로 트렌딩 상위 유지·유입 재가속(당일 +1,256). 트렌딩 1위 재등극은 [[금융-AI]] 자동화에 대한 개인 개발자 수요가 여전히 강함을 방증하나, 아래 실거래 검증 부재 리스크는 그대로다. 시장 데이터 분석·전략 수립·주문 실행을 LLM 에이전트가 자동화하는 개인 트레이딩 프레임워크. 이름의 "Vibe"는 [[바이브코딩]]처럼 *자연어로 트레이딩 전략을 기술하면 에이전트가 실행*한다는 포지셔닝. HKUDS(홍콩대 데이터사이언스 랩, [[crewAI]]·다수 에이전트 레포 운영처)가 내놓은 것이라 코드 품질 기대치는 있으나, [[금융-AI]] 도메인 특유의 *실거래 성과 검증 부재* 문제를 그대로 안고 있다.

## 도메인별 추출 (ai-news)

- **신뢰도**: ⭐⭐ — ⭐14.7K + 신뢰성 있는 랩(HKUDS) 출처는 가점이나, **실거래 백테스트·수익 검증이 공개되지 않으면 본질은 "전략 자동화 골격"**. [[ai-berkshire]]·[[TradingAgents]]와 같은 한계.
- **즉시 활용**: NO(투자) / MAYBE(패턴) — 실제 매매보다 **시장 데이터 → LLM 분석 → 액션**의 파이프라인 구조가 재사용 가치. 동일 골격을 비금융 의사결정 자동화에 전용 가능.
- **6개월 영향력**: "개인이 LLM으로 트레이딩 봇을 조립"하는 흐름의 한 축. 단 규제·리스크 관리 없는 자동 매매는 실손실 위험이 커 확산 속도는 제한적.
- **대체 관계**: 상용 퀀트 플랫폼 대체 불가. [[TradingAgents]]·[[ai-hedge-fund]]와 같은 "교육·리서치용 멀티에이전트 트레이딩" 계보에 합류.
- **허와 실**: 백테스트 없는 전략 코드는 "그럴듯한 로직"일 뿐. 생존편향·과적합·슬리피지 미반영 시 실전 수익과 무관.
- **액션**: 코드의 데이터 파이프라인·에이전트 분업 구조만 추출. 실거래 연결은 페이퍼 트레이딩으로만 검증, 실자금 투입 금지.

> [!warning] 신뢰도 주의 — 금융 자동화
