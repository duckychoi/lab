# Block3D — 자기회귀의 "수정 불가"와 확산의 "매번 전체 처리" 사이를 쪼갠다

**논문**: https://huggingface.co/papers/2608.19567 (arXiv 2608.19567)
**지표**: HF 데일리 **3위** · 업보트 **20** · 게재 **2026-08-20** · 저자 **10인**
**검증**: 2026-08-25 HF API 실호출 — 제목·초록·업보트·저자수·**정량 수치 전량** 원문 대조 완료

> [!insight] 핵심 인사이트 — 두 방식의 병목은 정반대였고, 해법은 "입도(granularity)"였다
> 기존 text-to-3D는 두 갈래인데 **병목이 서로 반대**다.
> - **자기회귀 디코딩**: 순차적이라 느리고, 결정적으로 **한 번 뱉은 오류를 수정할 수 없다.**
> - **확산 / flow-matching**: **매 스텝 전체 표현을 반복 처리**하므로 품질을 올릴수록 비용이 가파르게 는다.
>
> Block3D는 이산 shape-token 시퀀스를 **연속된 블록으로 분할**해, **블록 사이는 자기회귀**로 진행하고 **블록 내부의 모든 토큰은 동시에 디노이즈**한다. 즉 순차성과 병렬성의 **입도를 재조정**한 것 — 전역 순차도, 전역 동시도 아닌 중간값.
>
> 자기회귀의 고질병인 **오류 누적**은 **신뢰도 유도 블록 내 교정(confidence-guided intra-block correction)** 으로 완화한다. 각 블록을 확정하기 **직전에 신뢰도 낮은 토큰을 되돌려 수정**한다 — 자기회귀가 구조적으로 못 하던 "취소"를 블록 경계 안에서 되살린 셈.

> [!insight] 정량 결과 — 5.15배, 품질 저하 없이
> **TRELLIS-500K 홀드아웃 세트**에서 **평균 종단간 생성시간 25.71초 → 4.99초**. **파인튜닝된 자기회귀 베이스라인 대비 5.15배 가속**이며, **기하학적 충실도(geometric fidelity) 희생 없음**을 주장한다. 25.71/4.99 ≈ 5.15로 **수치 자체가 내적 일관성**을 갖는다(실검증 확인).

> [!warning] "품질 저하 없음"의 근거가 초록에 없다
> 가속 수치는 구체적인데, **품질을 어떤 지표로 쟀는지가 전혀 없다.** Chamfer distance인지 F-score인지 사용자 평가인지 미기재이며, **베이스라인도 "파인튜닝된 자기회귀" 하나뿐**이라 확산/flow-matching 계열과의 **직접 비교 수치가 빠져 있다.** 논문이 문제 제기 단계에서 지목한 두 진영 중 **한 진영과만 겨룬 결과**다. 5.15배는 자기회귀 대비 숫자이지 SOTA 대비가 아니다.

## 도메인별 추출 (ai-news / 교차: [[AI-3D-생성]])

- **신뢰도**: ⭐⭐⭐⭐ — 초록·정량 수치 원문 실검증 완료(raw 메모의 업보트 19는 **20으로 정정**). 단 **품질 지표·확산 계열 비교는 부재**.
- **즉시 활용**: **NO(현재)** — 코드·가중치 언급이 초록에 없다. 다만 **5초대 생성**은 3D 자산 생성이 "배치 작업"에서 **대화형 반복**으로 넘어가는 문턱이라, 공개되면 실사용 가치가 급상승하는 종류의 개선이다.
- **6개월 영향력**: 중간~높음 — **블록 단위 자기회귀+내부 동시 디노이즈**라는 패턴은 3D에 국한되지 않는다. 이산 토큰 시퀀스를 다루는 모든 생성 도메인(오디오·비디오 토큰)에 이식 가능한 일반 레시피에 가깝다.
- **대체 관계**: [[Hunyuan3D-Buffalo]] 등 3D 생성 계열과 경쟁축. TRELLIS 계열 파이프라인의 **추론 최적화 레이어**로 얹히는 성격.
- **허와 실**: TRELLIS-500K **단일 데이터셋 홀드아웃**만으로 일반화를 주장하기엔 얇다. "신뢰도 유도 교정"의 신뢰도 산출 방식도 미기재인데, **이 부분이 오류 누적 완화 주장의 전부를 지탱**하므로 공백이 크다. 블록 크기라는 명백한 하이퍼파라미터의 민감도 분석 언급도 없다.
- **액션**: 코드 공개 추적. 공개 시 **블록 크기 ↔ 품질/속도 트레이드오프**를 1차 확인 포인트로.
