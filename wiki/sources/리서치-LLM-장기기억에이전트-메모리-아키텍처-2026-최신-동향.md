## LLM 장기기억·에이전트 메모리 아키텍처 2026 최신 동향

**핵심 3줄**
- 
생물학-영감 6가지 인지 메커니즘(수면-통합, 간섭 기반 망각, engram 성숙화, 재통합, 엔티티 그래프, 다중-신호 검색)이 SOTA 메모리 아키텍처 기반

- 
A-Mem은 RL(GRPO)로 메모리 작업(저장/검색/업데이트/요약/삭제)을 에이전트 정책 도구로 훈련, 5개 벤치마크 모두 SOTA 달성

- 
EverOS는 LoCoMo 벤치마크에서 93.05% 정확도로 기존 모든 메모리 시스템 및 풀 컨텍스트 모델 초과


**상세**
- 
에이전트 메모리 3가지 아키텍처 계통: (1) 큐레이션된 워킹 뷰(MemGPT 스타일 페이징), (2) 지식 그래프 기반 구조, (3) 레이어드 조합(TriMem, TierMem 등)

- 
외부 메모리 시스템은 대화/관찰/반성을 저장하고, 에이전트가 외부 메모리 관리 가능하며, 레코드 통합·강화·연결로 저장소 성장 지원

- 
메모리 관리: Ebbinghaus 망각 곡선 적용(MemoryBank, SAGE)과 계층적 트리 아키텍처(RAPTOR, Memwalker) 병행

- 
최근 에피소딕 메모리 도입으로 토큰 시퀀스를 검색 가능한 이벤트로 구조화, 검색 기반 모델 초과

- 
현재 최신 LLM 컨텍스트 윈도우 상한 약 1M 토큰(Anthropic, OpenAI, Google), 메타 Llama 4 Scout 10M 토큰

- 
Chroma 2025 연구: 18개 모델 모두 입력 증가 시 신뢰도 감소 — 긴 윈도우도 정확도 보장 불가

- 
인사이트: 대부분 에이전트 메모리 시스템에서 구성(construction) 에너지가 300개 쿼리 전체 에너지를 초과

- 
장기기억 보안 연구: 에이전트 메모리 생명주기 전반 공격·방어·거버넌스 평가 필요(2026)


**💡 인사이트/시사점**

컨텍스트 확장 단독으로는 불충분 — "Lost-in-the-Middle" 현상 지속되므로 구조화된 메모리 조직이 필수
. 대규모 에이전트는 메모리 저장 효율보다 "구성 비용"이 지배적이므로, 검색-통합-거버넌스 최적화가 실무 핵심.
