# QuantCode Model — 역행 수치를 자기 초록에 넣었다

**HF/arXiv**: https://huggingface.co/papers/2609.39420 · arXiv **2609.39420**

> [!insight] 핵심 인사이트 — 개선과 악화를 같은 초록에 적는다
> Backtrader 전략 생성 **400과제 벤치(QuantCode-Bench)**:
> - **계속 사전학습(CPT)**: Judge Pass — Qwen3.5-397B-A17B **41.5% → 47.5%** · Qwen3.6-35B-A3B **27.8% → 33.0%**
> - **그 위의 SFT**: 35B 를 **58.2% Judge Pass · 백테스트 성공 83.5%** · 에이전트 평가 1턴 **22.3% → 58.3%** · 최대 10턴 후 **47.5% → 79.5%**
> - 🔴 **그런데 계속 사전학습 단독은 1턴은 올리고 최종은 47.5% → 32.5% 로 떨어뜨린다**(지시 따르기 저하와 정합)

> [!insight] 🏆🏆 [[숨김유인-부호]] 의 명시적 반례 1건
> ⚖️ **대부분의 논문이 유리한 표면만 남기는 자리에서 이 논문은 역행 수치(47.5 → 32.5)를 자기 초록에 넣었다.** 유인 구조상 숨길 수 있었는데 안 숨겼다.
> 🎯 **볼트 판정 요청 — 반례인가, 아니면 "역행을 적는 것이 기여(capability-retention 실패 발견)이기 때문"인가?**
> 📌 **볼트 판정**: 후자에 가깝다. **역행 수치가 이 논문의 기여 중 하나**이므로, 적는 것이 유인에 **반하지 않는다.** ⇒ 그렇다면 [[숨김유인-부호]] 는 **오히려 강화된다 — 주장 유형이 부호를 정한다.**
> ⚖️ 단 이것은 **볼트의 해석이고 저자 의도의 확인이 아니다.** 같은 배치 [[Qwen3.8-Flash-Next-GSQ-RCO-GGUF]] 는 **기여가 아닌 자리에서도 불리한 해석을 적용**했으므로 **더 강한 반례**다.

> [!insight] 🆕 두 번째 자기 반증 — 특화가 도구 호출을 망가뜨린다
> *"도메인 특화가 파서 적합 구조화 도구 호출을 저하시키고, 표적 복구 SFT 는 **도구 호출 포맷은 되살리지만 베이스 체크포인트의 레포 수준 에이전트 성능은 되살리지 못한다**"*
> ⇒ 🆕 신설: **[[특화-역류]]** — **좁은 특화의 비용이 좁은 곳에 머물지 않는다.** 특화는 목표 도메인을 올리면서 **무관한 능력을 비가역적으로 깎는다.**

## 도메인별 추출 (ai-news)

- **신뢰도**: ⭐⭐⭐ — 수치 밀도는 **배치 최고**이고 역행까지 적는다. 🔴 **코드·벤치 비공개 · 심판 불명 · 저자 3명 · 업보트 4(선발 경계)**.
- **즉시 활용**: **NO** — 트레이딩 코드 생성은 볼트 도메인이 아니다. 🎯 **단 [[특화-역류]] 는 즉시 적용된다**: 볼트가 스킬을 좁게 특화할 때 **범용 능력이 깎이는 비용**을 가정해야 한다.
- **6개월 영향력**: "도메인 특화 모델"의 비용 회계가 바뀐다 — **목표 지표 상승분만 보고하는 관행이 불충분해진다.** 복구 SFT 가 **일부만** 되살린다는 결과는 특화의 **비가역성**을 시사한다.
- **대체 관계**: 범용 코딩 모델의 트레이딩 코드 용도를 부분 대체한다(단 에이전트 성능은 회복 불가라고 자인).
- **허와 실**: 🏆 **허가 적다** — 유리한 수치(58.2 · 83.5 · 79.5)와 불리한 수치(32.5 · 도구 호출 저하 · 복구 불가)가 **같은 초록에 공존한다.** 🔴 **실은 검증 불가** — 코드·벤치·심판 전부 미공개이므로 **수치를 신뢰할 외부 근거가 0이다.** ⚖️ **보고 품질은 높고 검증 가능성은 낮다 — 두 축이 반대다.**
- **액션**: [[특화-역류]] 를 볼트 개념으로 세우고, 스킬 특화 시 체크 항목으로 넣는다.
