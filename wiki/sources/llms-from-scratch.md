# rasbt/LLMs-from-scratch

> [!insight] 핵심 인사이트
> Sebastian Raschka의 책 《Build a Large Language Model From Scratch》 공식 코드 레포. ChatGPT급 LLM 아키텍처를 PyTorch로 단계별 구현하며 내부를 완전히 이해할 수 있는 가장 체계적인 오픈소스 교육 자료. ⭐94,100이라는 압도적 스타 수는 "블랙박스 사용이 아닌 내부 이해" 수요가 얼마나 강한지를 보여준다.

## 도메인별 추출 (ai-news)

- **신뢰도**: ⭐⭐⭐⭐⭐ — GitHub ⭐94,675 (오늘 +821), Sebastian Raschka(전 Apple ML) 저자, 출판사 연계 공식 레포
- **즉시 활용**: YES — LLM 아키텍처 이해, PyTorch 실습, 교육 목적 즉시 활용 가능
- **6개월 영향력**: LLM 아키텍처를 처음부터 이해하는 표준 레퍼런스로 자리 잡음. GPT→Llama 구조 이해 후 파인튜닝·최적화로 연결
