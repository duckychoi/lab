# EvolvingWorld: Co-Evolving Role-Play Agents and World Model in Interactive Literary World

> [!insight] 핵심 인사이트
> 인터랙티브 문학 세계에서 **캐릭터와 세계가 초기 설정을 넘어 함께 발전(공진화)** 하는 롱호라이즌 시뮬레이션 프레임. **다중 캐릭터 롤플레이 + 지속 프로필 진화를 관리하는 Character Agent** 와 **전역·장소별 상태를 추적하는 LLM 기반 World Model** 을 결합. 시뮬레이션을 **7개 학습 태스크**로 분해하고, 은닉 트래커가 달린 **오픈스키마 캐릭터 프로필**로 다중 시간척도 진화를 표현. 공개도서 **57권·138,596 학습샘플** 벤치마크와 20개 지표의 궤적 단위 평가를 함께 제공. [[월드모델]]·[[JEPA]]의 "세계 상태를 유지·예측" 철학이 **서사/롤플레이 도메인**으로 확장된 사례로, [[EvolvingWorld|월드모델]]이 물리 예측만이 아니라 **캐릭터·서사 상태 유지**로도 쓰인다는 방증.

- **신뢰도**: ⭐⭐⭐ — WebFetch로 초록·구조 실확인(57권·138,596샘플·7태스크·20지표 등 구체). 미래형 ID(2607.17250)로 원문·재현 미검증 → medium. 업보트 53.
- **즉시 활용**: NO — 연구 프레임. 다만 "캐릭터 프로필 + 월드 상태를 분리 추적"은 [[에이전트-메모리-레이어]]의 장기 상태 관리 설계에 참조 가치. 대화형 봇(ChinameBot)의 페르소나 지속성에 개념적 시사.
- **6개월 영향력**: 중간 — 롤플레이/서사 AI가 "정적 재현"에서 "**공진화 시뮬레이션**"으로 이동. 게임·인터랙티브 픽션·장기 대화 에이전트의 상태 관리 표준에 영향 가능.
- **대체 관계**: 순수 롤플레이 LLM 대비 **명시적 월드모델 + 프로필 진화 추적**을 더한 것이 차별점. [[월드모델]] 계열([[Diffusion-월드모델]] 등)의 서사판.
- **허와 실**: "캐릭터·세계 공진화"는 매력적이나 138,596샘플·57권은 공개도서 중심이라 도메인 편향 가능. 20지표 평가의 실효성·장기 일관성은 원문 검증 필요.
- **액션**: 원문 공개 시 "Character Agent ↔ World Model" 분리 구조와 7태스크 분해를 확인 → 장기 대화 봇의 상태 관리 설계 참고.
