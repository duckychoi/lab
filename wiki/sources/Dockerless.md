# Dockerless: Environment-Free Program Verifier for Coding Agents (HF papers 2606.28436)

> [!insight] 핵심 인사이트
> **HF 데일리 2위 (↑75, 2026-07-01).** 코딩 에이전트를 학습할 때 필수인 **프로그램 검증기(코드 패치가 맞는지 판정)**를, **컨테이너·유닛테스트 실행 없이** 돌리는 방법. 기존 방식은 레포별 Docker 이미지를 띄워 테스트를 실행해야 해서 환경 셋업 비용이 컸다. Dockerless는 패치를 레퍼런스와 단순 매칭하지 않고 **에이전트가 레포를 직접 탐색하며 모은 증거로 정오를 판단** — 검증기 벤치에서 최강 오픈소스 검증기 대비 **+14.3 AUC**. 이 검증기를 **SFT 궤적 필터 + RL 보상**으로 동시에 써서 **완전히 환경 없는 사후학습 파이프라인**을 구성하면, [[Qwen3.5-9B]] 계열 baseline 대비 SWE-bench Verified/Multilingual/Pro에서 **62.0 / 50.0 / 35.2%**(각 +2.4 / +8.7 / +2.9p)로, 실행 기반 사후학습과 맞먹는다. [[NatureBench]]·[[Beyond-NL2Code]]가 짚은 "코딩 에이전트 평가·학습" 축의 비용 병목을 정면으로 뚫는 연구.

## 도메인별 추출 (ai-news)

- **신뢰도**: ⭐⭐⭐ — HF 데일리 2위 + 구체 수치(+14.3 AUC, SWE-bench 62.0%)로 검증 가능한 형태. 다만 "실행 없이 판정"은 원리상 실행 검증의 근사이므로, 실행 기반이 잡아내는 미묘한 런타임 버그를 놓칠 가능성은 남음.
- **즉시 활용**: NO(직접) / YES(개념) — 내가 모델을 사후학습하진 않지만, "실행 없이 에이전트가 레포 탐색 증거로 패치 정오 판단"은 [[strix]]·코드리뷰 에이전트류 워크플로에 적용 가능한 판정 패턴.
- **6개월 영향력**: 높음 — 코딩 에이전트 RL의 최대 비용(레포별 Docker 실행)을 제거하면 오픈소스 진영의 에이전트 사후학습이 급가속. [[Ornith-1.0-9B]] 같은 "자기개선형 에이전틱 코딩 모델"의 학습 비용을 낮추는 방향과 맞물림.
- **대체 관계**: 실행 기반 검증(유닛테스트 in Docker)을 *보강/대체*. 검증기 자체가 에이전트라는 점에서 정적 매칭 검증기를 앞섬.
- **허와 실**: "environment-free ≠ 레포 접근 없음" — 저자도 명시. 레포는 읽되 실행만 안 하는 것. "실행 검증과 맞먹는다"는 벤치 범위 내 주장이며, 미묘한 상태 의존 버그에는 실행 검증 우위가 남을 것.
- **액션**: 코드 공개 시 "에이전트 탐색 기반 패치 판정" 로직을 내 코드리뷰/보안 점검 루프에 참고.
