## 핵심 인사이트
> [!insight] 로봇 학습 0 — 프롬프트 · 계획 · 행동 실행 · 도구 4축 절제로 "하네스만"의 상한을 측정했다
> 범용 멀티모달 모델(본문 실험 모델 GPT-6-Astra)을 **별도 로봇 학습 없이** 폐루프 정책으로 쓰는 하네스를 4축으로 절제 실험해 6개 발견을 레시피로 정리. **표 2(RoboLab-120)**: 성공률 83.3% vs 차순위 에이전트 SenseNova-RoboRSI 57.1, 정책 모델 최고 FLUX 3 Action 42.9 · π0.5 28.0 · GR00T N1.6 7.2. 표 3 실세계 20회 중 15회 성공(설거지 2/5 · 꽃꽂이 3/5). 학습이 아니라 **하네스 설계가 결과를 지배**한다는 점에서 [[하네스-설계-축]] 의 로봇 버전이자 [[동결-교정층]] 의 극단(층 0 — 본체 건드림 없음).

> [!note] 레시피 · 지는 선택지(본문 표 1 — 절제 수치)
> 액션 청크 **8**이 최적(4 → 40.0 · 8 → 58.3 · 30 → 21.7%), 단일 시점 카메라 30.0% vs 두 시점 65.0, 해상도 224×126 → 640×360에서 65.0 → 83.3%, 명시적 계획 61.7 < **암묵 계획 65.0**, 모델 교체 시 크게 하락(GPT-6.1-sol 40.0 · terra 38.3). 표 4: IK/FK 없이 관절 직접 출력 시 −23~−32%p — 모델은 저수준 궤적보다 **목표 위치 추정**에 의존(위치 오차 중앙값 7.04cm · 5cm 이내 28.1%). 시나리오 하나에 하네스 시간 10–15분.

## 도메인별 추출 (slam-3dgs)
- **실용성**: 특정 API 모델(GPT-6-Astra) 의존 결과지만 "VLA 학습 없이 상용 모델 + 하네스" 노선의 **설계 체크리스트**로 유효 — 청크 8 · 두 시점 · 640×360 · 암묵 계획 · 관절 출력 금지.
- **한계**: 백본을 바꾸면 83.3%가 유지되리라는 보장 없음(교체 시 38–40%로 하락) — 레시피가 모델 특화일 가능성.
- **액션**: 없음(관찰 — 실로봇 없음).
