# 4DAnyone — Create Anyone in 4D from a Casual Monocular Video (HF 데일리 3위·업39)

**HF Papers**: https://huggingface.co/papers/2608.20335
**지표**: 업보트 **67** (2026-08-23 HF API 실검증) ← 39(최초 수집) (HF 데일리 **3위**) · arxiv **2608.20335**(미래형 ID) · **도메인**: slam-3dgs (교차 video-saas)

> HF 업보트 **67** (2026-08-23 HF API 실호출) ← 61(08-22) ← 39(08-21). 이틀 **+6**으로 이번 논문 5건 중 [[EnvHarness]]와 함께 **유일하게 유입이 남아 있는 축**이다(나머지 3건은 +1~+2).
> 초록 원문 재대조로 확정한 기여: 보정 없는 단안 영상에서 **4DGS 재구성 등급의 다시점 일관 영상**을 생성해 4D 가우시안 스플래팅으로 끌어올린다. 저자들은 기존 카메라 제어 비디오 확산모델의 실패를 **bounded-attention-context 문제**로 규정한다 — 목표 뷰가 단일 DiT forward 용량을 넘으면 그룹으로 쪼개야 하고, 그 순간 두 병목이 결합해 터진다: **참조 컨텍스트 측**은 기존 생성 뷰 전부를 조건으로 삼아 **O(N)으로 증가**해 뷰 간 외형 가이드가 희석되고, **타깃 컨텍스트 측**은 분리된 그룹끼리 정보를 교환하지 못해 **전역 구조 드리프트**가 발생한다.
> 해법은 두 설계의 짝이다 — **RCP(Reference Context Packing)**가 늘어나는 참조 뷰를 **고정 길이 혼합 해상도 컨텍스트로 압축해 O(1)**로 낮추고, **TCR(Target Context Routing)**이 디노이징 중 타깃 뷰 그룹을 회전시켜 **고노이즈 구간에선 그룹 간 컨텍스트를 공유하고 저노이즈 구간에선 디테일을 안정화**한다. 자체 게임 엔진으로 **MVGameHuman 데이터셋**을 구축해 라이트스테이지·야외 영상과 결합 학습.
> ⚠️DNA-Rendering·DyMVHumans에서 기존 기법 상회를 주장하나 **초록에 정량 수치 미기재** — 08-22와 동일하게 성능 단정 금지. [[slam-3dgs]] 도메인 교차 축으로 유지.

> [!insight] 핵심 인사이트
> **평범한 단안(monocular) 비디오 한 개로 임의 인물의 4D(공간 3D + 시간)를 재구성** — 특수 장비·다중 카메라 없이 일상 영상으로 움직이는 사람을 시공간 볼륨으로 복원한다. 위키의 slam-3dgs·4D 재구성 축([[4D-Human-Scene-Reconstruction]]·[[Beyond-Pixels-4D]] 픽셀 넘어 4D)에 "**캐주얼 촬영본 하나로 누구든**"이라는 입력 문턱 최소화 각도를 더함. 재구성된 4D 인물은 [[video-saas]] 파이프라인의 자산(움직이는 캐릭터·아바타) 공급원이 될 수 있어, 단안 영상→3D/4D 에셋 워크플로우([[AI-3D-생성]])와 접목 지점이 생김. 입력이 "casual monocular"라는 점이 실용성의 핵심 주장이자 검증 포인트.
