# Agent Memory Distillation: Empowering Small LLM Agents with Hierarchical Teacher Memory (2608.07169)

**HF 논문**: https://huggingface.co/papers/2608.07169
**업보트**: 25 (2026-08-11 자동수집, **HF 데일리 페이퍼 1위**)

> [!insight] 핵심 인사이트
> **대형 "교사" 에이전트가 축적한 구조화된 계층적 메모리(hierarchical teacher memory)를, 학습 없이(training-free) 소형 "학생" 에이전트로 전이해 성능을 보강하는 프레임워크(AMD)**(제목·raw 기반). 통상 지식증류가 *가중치/로짓*을 옮기는 데 비해, AMD는 *에이전트의 메모리(경험·절차·컨텍스트)* 를 옮긴다는 점이 핵심 프레이밍 — 소형 로컬 LLM을 재학습 없이 큰 에이전트의 노하우로 끌어올리려는 접근. 위키의 [[에이전트-메모리-레이어]]·[[온폴리시-증류]] 계보와 직접 맞닿고, 무엇보다 **소형/로컬 에이전트([[local-llm]])의 실용성을 학습 비용 없이 높이는** 결이라 내 관심축(로컬·저비용 에이전트 메모리)과 정면 교차. training-free라는 점은 곧 "추론 시 메모리 주입"만으로 동작함을 시사 — 파인튜닝 인프라 없이 시도 가능한 잠재적 이식성이 매력.
