# ToolArtist — 통합 멀티모달 모델이 외부 도구를 호출해 이미지 생성

**HF Paper**: https://huggingface.co/papers/2608.04436 (HF Daily #1, 업보트 41)
**성격**: 에이전트형 이미지 생성 — 통합 멀티모달 모델 + 외부 도구 호출

> [!insight] 핵심 인사이트
> **통합 멀티모달 모델이 "혼자 그리는" 대신 외부 도구를 *에이전트처럼 호출*해 이미지를 생성**하는 접근. 한 번의 확산 패스로 끝내는 생성과 달리, 모델이 도구(예: 편집·합성·검색·검증 툴)를 계획적으로 쓰며 결과를 조립한다는 발상 — 텍스트 에이전트의 "도구 사용" 패러다임을 이미지 생성으로 옮긴 것이다. [[ToolArtist]]는 08월 "통합 멀티모달 + 에이전트화" 흐름(도구 사용·계획·검증을 생성에 편입)의 이미지 축 사례로, [[AI-에이전트-프레임워크]]의 도구 호출 개념이 생성 모델 내부로 들어오는 신호. 단, 미래형 arxiv ID(2608.04436)라 원문 초록·수치 재현 불가.
