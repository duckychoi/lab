# Qwythos-9B (empero-ai/Qwythos-9B-Claude-Mythos-5-1M-GGUF)

> [!note] 2026-07-17 갱신
> HF 다운로드 **2.1M (좋아요 2.25k)** ← 2.01M (07-15, 2.18k). 이틀 +약9만으로 210만 근접 — 200만 돌파 후에도 완만한 우상향이 멈추지 않음. 유입 속도는 안정기(하루 +4~5만대)이나 커뮤니티 롱컨텍스트 GGUF 최상위 채택 지위는 유지. "1M 컨텍스트=YaRN 확장" 검증 필요성은 그대로.

> [!insight] 핵심 인사이트
> HF 다운로드 **2.01M (2026-07-15, 좋아요 2.18k) ← 1.99M (07-13, 2.03k) ← 1.97M (07-12) ← 1.37M (07-03) ← 1.11M (07-01).** **200만 돌파**(트렌딩 1위 유지)로 커뮤니티 파인튜닝 GGUF 중 최상위 채택 지속. 단 이틀 +2만으로 유입 둔화는 계속 — 폭발기→포화 안정기 확정. 단 유입 증가율은 둔화(하루 +수십만 → +2만)되어 초기 폭발적 확산이 안정기에 진입하는 신호. 모델카드 확인 결과 **Qwen3.5-9B 기반**을 5억 토큰 규모 **Claude Mythos/Fable 트레이스(CoT)**로 파인튜닝(자체발표 +34 MMLU·+30 gsm8k-strict), Apache-2.0. 모델카드 확인 결과 Qwen3.5-9B 기반 풀파라미터 추론 모델을 5억 토큰 규모 트레이스로 포스트트레이닝한 것의 GGUF 양자화판(Q4_K_M~BF16, MTP·비전 프로젝터 mmproj 포함). **1M(1,048,576) 컨텍스트는 YaRN RoPE 스케일링을 기본 활성화해 "구현"한 것** — 즉 네이티브 학습 길이가 아니라 확장 트릭이므로, 실효 활용 범위는 여전히 별개 검증 대상. 비전 타워는 SFT 중 동결(base Qwen3.5-9B 그대로)이라 image-text-to-text 능력은 베이스와 동일. 100만 돌파 후에도 유입이 멈추지 않고 우상향한다는 점이 핵심 신호.

## 도메인별 추출 (ai-news)

- **신뢰도**: ⭐⭐ — 1.37M DL·트렌딩 1위로 관심도는 확정. 다만 출처(empero-ai 커뮤니티)·"1M 컨텍스트"가 YaRN 확장이라는 점·자체발표 벤치(+34 MMLU 등) 독립검증 불가.
- **즉시 활용**: MAYBE — 긴 위키 문서/소스를 로컬(llama.cpp/Ollama/LM Studio)에서 한 번에 요약·질의하는 용도 후보. Q4_K_M(5.6GB)이면 소비자 GPU/CPU로도 실행 가능. 단 9B 품질 한계 + 1M 실효성 검증 선행.
- **6개월 영향력**: "소형 + 초장문맥(YaRN)" 로컬 모델 수요 확인. 실효 컨텍스트가 주장에 못 미치면 단발 트렌딩에 그칠 것.
- **대체 관계**: 클라우드 롱컨텍스트 모델의 로컬 저비용 대안 *시도*. [[GLM-5.2]](753B·1M 컨텍스트)와 같은 초장문맥을 9B로 흉내내지만 품질·실효 길이 격차 예상.
- **허와 실**: "1M 컨텍스트"는 대표적 과장 포인트 — YaRN 확장은 입력은 받되 중간 정보 활용(needle-in-haystack)이 무너지는 경우 다수. 실측 필수.
- **액션**: 다운로드 후 long-context 검색 테스트(긴 문서 중간에 사실 심고 회수)로 실효 컨텍스트 확인. 통과 못 하면 폐기.

> [!warning] 신뢰도 낮음 — 검증 필요
> "1M 컨텍스트"는 모델카드상 **YaRN RoPE 스케일링 기본 활성화**로 구현된 값 — 네이티브 학습 길이가 아니다. 커뮤니티 파인튜닝 모델이라 학습 데이터·라이선스 불명확하고 +34 MMLU 등 향상 수치는 자체발표. 프로덕션 투입 전 needle-in-haystack 실측 필수.
