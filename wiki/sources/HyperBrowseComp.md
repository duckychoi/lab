# HyperBrowseComp — 13개 언어 423문항 웹브라우징 스트레스 테스트

**arXiv/HF**: https://huggingface.co/papers/2610.03574
**업보트 12** (HF 데일리 3위) · `publishedAt` **2026-10-02**
**독립 검증**: HF API 업보트 **12 일치** · 🆕 **arXiv HTML 전문 476,987B 열람 — 초록에 모델 점수 0개였고 본문 Table 2 에 있었다**

> [!insight] 핵심 인사이트
> **파라메트릭 지식으로 맞히는 경로를 사전에 제거한 벤치마크다.** 제출 문항을 **인터넷 없는 모델 7종**(Gemini 3.1 Pro Preview · Gemini 3.7 Flash · GLM-4.7 · GPT-OSS-120B · Kimi K2 Thinking · MiniMax-M2 · DeepSeek-V3.2)으로 먼저 풀려 **121문항이 최소 1개 모델에서 정답**(그중 **54문항은 2개 이상**)이었고, **조합 배제 규칙**으로 걸렀다.
> 📌 **"검색 없이 풀리는 문항"을 빼는 절차를 명시한 것이 이 벤치의 핵심 자산이다** → [[검사가능성-공사]].

> [!insight] 🏆 본문 Table 2 (초록에 없음) — 볼트가 직접 확보
> **Gemini 3.7 Flash 31.68%**(최고) · **Gemini 3.1 Pro Preview 25.53%**(2위). 평가 모델 5종: Gemini 3.1 Pro Preview · Gemini 3.7 Flash · **GPT-5.6 Terra · GPT-5.6 Luna · GPT-5.6 Sol**.
> 브라우징 설정 **3종**: `built-in search` · **Exa** · **OWL**(MM-BrowseComp 에서도 쓰인 것). ⚖️ **즉 점수는 모델만의 값이 아니라 모델×브라우징 하네스의 값이다** → [[하네스-설계-축]].
> 논문 표현: *"상당한 개선 여지"* · *"ChatGPT 의 더 큰 변종이 더 좋았다"*(당연한 쪽).

> [!insight] 🏆🏆 배치 최대 발견급 — 인간과 모델은 **같은 점수인데 다른 문항**을 맞혔다
> 본문: 인간 주석자 **30회 시도**(give-up 포함) 평균 **89.5분** · 중위 **54.6분**(문항당 1시간 제한 · AI 보조 금지 · 인터넷 허용).
> 🔴 **최고 모델 Gemini 3.7 Flash 와 같은 부분집합에서 "전체 성능은 비슷"한데 정답이 겹치지 않는다 — 양쪽 다 맞춘 것은 8문항뿐이다.**
> 🎯 **이것은 "모델이 인간 수준에 도달했다"의 반례 구조다.** 총점이 같아도 **능력 축이 다르면 같은 능력이 아니다.** 📌 **볼트가 벤치마크 점수를 읽는 방식에 직접 영향한다: 동점은 동일 능력을 함의하지 않는다** → [[복합지표-분해]] 의 가장 선명한 사례.

## 도메인별 추출 (ai-news)

- **신뢰도**: ⭐⭐⭐⭐ — 본문 전문 + Table 2 + 인간 대조 설계 + 사전 배제 절차 + 주석자 자격(플랫폼 테스트 **90점 초과** 통과) 명시. 🔴 **업보트 12 는 낮다**(배치 3위이나 절대값 소).
- **즉시 활용**: **YES — 측정 도구로 쓴다.** 볼트가 쓰는 웹 읽기 경로([[Agent-Reach]]·[[mark-clean]]·`defuddle`)의 한계를 재는 데 **문항 유형**이 그대로 쓰인다(희귀 근거 탐색 · 다단계 단서 추적 · 영상/스캔문서/지도 등 이질 소스).
- **6개월 영향력**: 브라우징 에이전트 평가가 **모델 축에서 하네스 축으로** 옮겨간다(설정 3종 비교가 기본 구성). 31.68% 라는 낮은 천장은 **1년 치 개선 여지**를 뜻한다.
- **대체 관계**: MM-BrowseComp 의 다국어·난이도 강화판 위치. BrowseComp 계열을 대체하지 않고 **상위 난이도로 확장**한다.
- **허와 실**: 🎯 **벤치마크 논문은 점수가 낮을수록 자기 주장에 유리하다** — 그래서 **초록이 수치를 뺀 것이 은폐 유인과 반대 방향**이다(→ [[숨김유인-부호]]). 🔴 **423문항은 작다.** 13개 언어로 나누면 언어당 평균 **32.5문항**이고, 언어별 점수는 표본이 얇다(본문 언어별 분해 미열람).
