> [!insight] 핵심 인사이트
> **"짧은 컨텍스트가 곧 삭제된 역사는 아니다(Shorter context is not deleted history)"** — README 원문의 이 한 문장이 이 프로젝트의 핵심이며, 이번 배치에서 가장 실질적인 설계 아이디어다. Maka는 **모델 메시지·툴 호출·툴 결과·턴 종료 방식**을 append-only 기록으로 남기고, **UI와 다음 모델 호출을 그 기록의 "뷰(view)"로 취급**한다. 그래서 다음 프롬프트에서 오래된 툴 출력을 빼더라도 **저장된 증거는 버리지 않는다.**
> 이것이 중요한 이유는 [[MemTrapBench]]와 정면으로 맞닿기 때문이다. MemTrapBench는 *충실히 저장되고 의미적으로 관련 있는 메모리조차 추론을 왜곡*하며 평가된 5개 메모리 프레임워크 전부가 no-memory보다 못했음을 보였다. Maka의 구조는 그 문제에 대한 **다른 층위의 답**이다 — *무엇을 모델에게 먹일지(컨텍스트)* 와 *무엇을 보존할지(기록)* 를 **분리**한다. 메모리를 "요약해서 다시 주입하는 것"으로 보면 오염이 누적되지만, **기록은 불변으로 두고 주입만 선택**하면 오염원을 줄이면서 사후 추적성을 잃지 않는다. 볼트가 [[에이전트-메모리-레이어]]에 쌓아 온 축에 **"이벤트 소싱" 계열의 대안**이 처음 들어온 셈이다.
> 두 번째 축은 **실행 경로 단일화**다 — 데스크톱·터미널·평가(eval)가 전부 **하나의 Runtime Host**를 통과한다. 즉 *"UI에서 되던 게 CLI에서 안 된다"* 류의 표류를 구조로 막고, **평가는 실험과 점수만 소유**한다. 에이전트 하네스를 직접 만들 때 흔히 새는 지점이라 설계 참조 가치가 높다.

> [!note] 권한 결정까지 기록 대상이다 — 감사 가능한 에이전트
> API 원문 설명이 명시하는 기록 항목은 **model messages · tool calls · tool results · permission decisions · termination events** 다. 여기서 **권한 결정(permission decisions)이 1급 기록 대상**이라는 점이 눈에 띈다 — 에이전트가 *무엇을 했는가*뿐 아니 *무엇이 허용/거부됐는가*까지 남으므로, 사후에 **"왜 이 파일이 수정됐나"를 재구성**할 수 있다. 툴은 **샌드박스 경계 아래서 실행**된다고 README가 밝힌다.
> 이 감사 구조는 [[openai-codex]]의 Rust 샌드박싱과 함께 **"에이전트 안전을 코드로 확인할 수 있는" 소수의 레퍼런스**에 속한다 — 둘 다 본체 소스가 열려 있다.

> [!warning] Linux 미지원 — 내 환경에서 지금 못 돌린다 (실용성 제약)
> README 배지 실측: **macOS arm64는 초기 공개 릴리스**, **Windows는 서명 없는 프리뷰**, **Linux는 "soon"(미지원)**. 내 작업 환경이 Linux이므로 **데스크톱 앱 즉시 사용은 불가**하며, 소스가 TypeScript로 열려 있으니 **CLI/TUI를 소스에서 빌드하는 경로**를 확인하는 것이 유일한 시도 방법이다(빌드 지원 여부 미확인).
> 또한 README가 **"활발한 개발 중이며 데이터 형식·CLI 명령·실험적 기능이 변경될 수 있다"** 고 직접 경고한다. ASF **인큐베이팅**은 인프라·커뮤니케이션·의사결정이 아직 ASF 기준으로 안정화되지 않았다는 뜻이며, DISCLAIMER-WIP에 알려진 이슈가 기록돼 있다. **프로덕션 채택 대상이 아니라 설계 참조 대상**이다.

> [!warning] 스타 2,497 — 이번 배치 최저이나 성격이 다르다
> 같은 배치 [[mattpocock-skills]](234,572)·[[free-claude-code]](48,309)와 비교하면 **약 1/94~1/19 규모**다. 다만 이 격차를 인기 열세로만 읽으면 오독이다 — 상위 레포들은 **복사해서 쓰는 텍스트 자산**이거나 **무료 접근 우회**인 반면, Maka는 **설치해서 돌리는 데스크톱 소프트웨어**이고 **macOS arm64 초기 릴리스뿐**이다. 도달 가능 사용자 풀 자체가 좁다. 생성 3개월·ASF 인큐베이팅·당일 푸시·이슈 239로 **활성도는 견조**하다.
