# WithEveryone — Unified Planning and Identity Grounding for Group Image Generation (HF 데일리 5위·업31)

**HF Papers**: https://huggingface.co/papers/2608.20336
**지표**: 업보트 **39** (2026-08-23 HF API 실검증) ← 31(최초 수집) (HF 데일리 **5위**) · arxiv **2608.20336**(미래형 ID) · **도메인**: video-saas (교차 image-gen)

> [!update] 2026-08-23 업보트 갱신 — 업 **39** (**HF API 실검증**·전일 38 대비 +1·데일리 5위 유지)
> HF 업보트 **39** (2026-08-23 HF API 실호출) ← 38(08-22). 이틀 **+1**로 이번 5건 중 최저 유입이나, **정량 근거는 가장 구체적**이다 — 08-22 배치의 [[FlashPrefill-V2]](데일리 최하위·최다 실측)와 같은 패턴으로, **업보트 순위와 검증 가능성이 역상관**하는 사례가 반복 관측된다.
> 초록 원문 재대조로 확정한 수치(전량 초록 명시): 얼굴 유사도 **GPT-Image-2의 0.462 → 0.499**, 복붙(copy-paste) 아티팩트 **0.169 → 0.055**(약 1/3로 감소), 요청 아이덴티티 **커버리지 97.3%**·**중복률 2.8%**. 벤치는 **아이덴티티 분리(identity-disjoint)** 조건.
> 기술 요체: 최대 **10인** 참조 아이덴티티를 다루며, 각 아이덴티티를 **주소 지정된 토큰(addressed token)**으로 주입하고 **구조화된 아이덴티티–레이아웃 플랜**을 예측해 이를 시각 조건으로 렌더링한다. 핵심 목적함수 **Layout-Grounded ID Loss**는 여러 노이즈 낀 예측 얼굴 사이에서 대응을 세우는 **불안정한 임베딩 기반 얼굴 매칭을 피하고**, 주석된 얼굴 영역으로 의도한 아이덴티티를 **직접 감독**한다. **ID Representation Forcing**이 이미지 합성 전에 각 아이덴티티 예측을 추가 학습.
> 함의: 아이덴티티 보존 생성이 **참조 얼굴을 직접 복사하지 않고도** 다인원으로 확장 가능함을 보인 사례 — [[video-saas]]의 인물 일관성 축과 교차하는 레퍼런스.

> *공통 유의(2026-08-23): HF 데일리 페이퍼는 **최신 배치가 2026-08-21에 멈춰 있어** 08-22·08-23 요청 시에도 동일 목록을 반환한다(주말 미갱신). 따라서 이번 배치 논문 5건은 **신규 발표가 아니라 기존 인제스트 항목의 업보트 재수집**이며, 순위 역시 08-21 배치 기준이 그대로 유지된 값이다.*

> [!insight] 핵심 인사이트
> **다인원(여러 사람) 그룹 이미지 생성에서 "계획 수립(planning)"과 "인물 정체성 그라운딩(identity grounding)"을 하나로 통합** — 여러 인물을 한 장면에 넣을 때 구도·배치를 계획하는 것과, 각 인물의 정체성(얼굴·특징)이 뭉개지지 않게 고정하는 것을 분리된 단계가 아니라 통합 파이프라인으로 다룬다. 단일 인물·객체 편집을 넘어 **"여러 정체성을 한 프레임에 일관되게"**가 생성형 이미지의 다음 난제임을 보여주는 항목으로, [[video-saas]]([[reat-scene]]) 다인물 씬·캐릭터 일관성 요구와 직결. 4D 인물 재구성 [[4DAnyone]](단안→개인 4D)과 함께 "**인물(정체성) 중심 생성·재구성**"이 이 배치의 비전 축을 이룸 — 전자는 재구성, 후자는 다인물 생성 계획.

## 도메인별 추출 (video-saas · 교차 image-gen)

- **기능 벤치마킹**: 다인물 씬 생성 시 "구도 계획 + 각 인물 정체성 고정"을 통합 처리 — 내 [[video-saas]] 캐릭터 일관성 파이프라인의 참조 각도.
- **크리에이터 인사이트**: 여러 인물이 등장하는 컷에서 정체성 붕괴(얼굴 뒤섞임)가 실사용 갭 — 이를 계획 단계에서 잡으려는 접근.
- **프롬프트 패턴**: 미기재 — 통합 계획·그라운딩 프롬프트 구조는 원문 대조 전 미확정.
- **디자인 레퍼런스**: 다인물 배치·정체성 앵커링을 [[reat-scene]] 다캐릭터 씬 설계에 개념 참고.
- **경쟁 우위 빈틈**: 단일 정체성 편집은 성숙, **다인물 동시 정체성 일관성**은 아직 빈틈 — 차별화 포인트 후보.
