# SemComp-Bench — "비디오 생성이 의미적 태스크를 실제로 완수하는가"

**HF 논문**: https://huggingface.co/papers/2608.17426
**지표**: 업보트 **78** (2026-08-20 HF 데일리 **2위**) · **도메인**: ai-news (교차 video-saas)

> [!insight] 핵심 인사이트
> 비디오 생성 모델이 프롬프트가 요구한 **의미적 태스크(semantic task)를 실제로 완수하는지**를 측정하는 벤치마크. "화질·미학"이 아니라 "요청한 사건·인과·상태 변화가 영상에 실제로 구현됐는가"를 채점한다는 프레이밍이 핵심 — 프레임 단위 지각 품질과 **태스크 완료도**를 분리한다. 이는 08월 내내 굵어진 **"생성물 평가 자율화"** 흐름의 영상판 연장 — 데일리 1위였던 [[HarnessEval-W]](생성된 시각적 월드의 품질을 에이전트가 판정)와 같은 문제의식(생성이 폭증할수록 커지는 QA 병목)을 비디오 생성에 특화. [[AVA-Encoder]](영상을 에이전트 작업 입력·상태 표현으로 재정의)와도 "영상을 사람 눈이 아니라 기계가 의미 단위로 읽는다"는 축을 공유. 내 [[video-saas]]([[reat-render]]·[[reat-scene]]) 결과 검수를 "사람 눈 QA"에서 "의미 완료도 자동 채점"으로 옮기는 설계의 직접 참조 후보.

> [!warning] 신뢰도 — 미래형 arxiv ID·수치 미검증 (medium)
> arxiv ID **2608.17426**은 미래형(2026-08)으로 **원문 초록·채점 프로토콜·태스크 셋·벤치 수치·저자/소속을 재현할 수 없다**(실WebFetch 미수행·타임라인 유지). 업보트 78·데일리 2위는 raw 자동수집 순위 지표. "의미적 태스크 완료"의 조작적 정의(무엇을 어떻게 채점하는지)는 **raw 미기재 → 원문 재현 전까지 미검증**([[CLAUDE.md]] 사실확인 원칙). 제목·한줄요약 기반 medium.

## 도메인별 추출 (ai-news · 교차 video-saas)

- **신뢰도**: 업보트 78·HF 데일리 2위(raw)·원문 미재현·채점법 미기재 → medium
- **즉시 활용**: 조건부 — 벤치 데이터·채점 코드 공개 시 내 영상 파이프라인 결과의 "요청 완수도" 자동 검수에 직접 적용 후보. 미공개면 프레임 참조.
- **6개월 영향력**: 비디오 생성 평가가 "미학·화질 점수 → 태스크 완료도"로 이동하는 흐름. 생성기 선택·프롬프트 튜닝의 판정 기준 변화.
- **대체 관계**: FVD/미학 스코어류 지각 품질 지표 대비, "요청 의미가 구현됐는가"를 보완하는 직교 축.
- **허와 실**: 벤치 존재만으로 "완수"가 보장되지 않음 — 인간 기준선 대비 채점 신뢰도·커버리지가 실체.
- **액션**: 데일리 2위 프레임 기록 + video-saas 결과 QA의 "의미 완료도 자동 채점" 개념 참조(actionable 낮음).
