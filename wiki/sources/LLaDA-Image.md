# LLaDA-Image: Building Strong Image Generators with Fully Open Training Recipes

**HF 논문**: https://huggingface.co/papers/2609.03796
**지표(2026-09-06 API 실측)**: 업보트 **226** · 저자 **30인**(배치 최다) · 공개 2026-09-03 · 데일리 2026-09-04
**raw 수집값(09-05)**: 업보트 204 → **+22**.

> [!insight] 핵심 인사이트 — **페어 데이터 의존을 학습 순서로 끊는다**
> 통상 이미지 생성기는 처음부터 **이미지-텍스트 쌍**에 크게 의존한다. LLaDA-Image는 순서를 바꾼다 — **이미지 단독 사전학습·중간학습으로 시각 생성 사전지식을 먼저 세우고**, 그다음에 언어를 붙인다.
> 이유가 경제적이다. 페어 데이터는 비싸고 편향되며 캡션 품질이 상한을 만든다. **이미지만 있는 데이터는 훨씬 많다.** 파이프라인 규모가 **220M 샘플**이다.
> 구성도 특이하다: **6B DiT는 처음부터 학습**하되 이해 모듈은 **동결(frozen)** — [[LLaDA2.0-Uni]] 계열의 **LLaDA2.0-Mini 확산 언어모델 백본** 위에 얹었다. 볼트에 이미 있는 LLaDA 계보가 **이미지 축으로 뻗은 첫 사례**다.

> [!insight] 최적화 선택 두 가지가 명시적이다 — **파라미터 없는 RMSNorm + Muon**
> 초록이 *"효율적이고 확장 가능한 최적화를 위해"* DiT 전체에 **parameter-free RMSNorm**과 **Muon 옵티마이저**를 썼다고 적는다. 레시피 전체 공개를 표방하는 논문이 **옵티마이저 선택까지 초록에 올린다**는 건, 이 논문의 상품이 모델이 아니라 **재현 가능한 절차**라는 뜻이다.
> [[SolarWM]]이 *"모델이 아니라 데이터 계약을 공개"* 한 것과 같은 노선 — **무엇을 공개하는가로 차별화**한다. [[MiniMax-H3]]의 *"오픈 가중치 ≠ 오픈 시스템"* 과는 정반대 축에 선다.

> [!insight] Qwen-Image-Bench 영문 **53.53** / 중문 **53.38** — 오픈소스 최고 주장
> 그리고 **Turbo 증류본은 2~4스텝 추론**. 가중치·학습코드·레시피 전부 공개.

> [!warning] ⚠️ 벤치마크 해석에 두 겹의 유보가 필요하다
> 1. **자체 공표 표이며 제3자 재현이 없다** — 볼트 반복 규칙.
> 2. **Qwen-Image-Bench는 [[Alibaba]] 계열 벤치**다. 여기서 "오픈소스 최고"가 다른 벤치에서 유지되는지는 별개 문제다.
> 3. **53.53이라는 절대값의 의미가 불명** — 상한이 100인지, 폐쇄형 모델은 몇 점인지 초록 범위 밖. [[Repo-To-Skill]] 때 세운 규칙(*분모를 모르면 크기를 모른다*)이 여기선 **분모가 아니라 척도**에 걸린다.
> ⚠️ 초록 API 텍스트에 *"220M samples, 98 of which are real images"* 라는 구절이 있는데 **98%의 오식으로 보이나 확정 불가** — 수치 인용 시 원문 확인 필요.

## 도메인별 추출 (ai-news)

- **신뢰도**: ⭐⭐⭐ medium — HF API 실검증(업보트·저자 30인·날짜). 성능은 자체 공표.
- **즉시 활용**: **NO(생성 용도).** 6B DiT 학습은 물론 추론도 이 기계 기준 부담. 단 **Turbo 2~4스텝**이면 로컬 추론 가능성이 열린다 — 가중치 확인 후 재판정.
- **6개월 영향력**: **중간.** [[video-saas]] 축에 직접 닿는다 — 오픈 이미지 생성기의 품질 상한이 올라가면 영상 파이프라인의 프레임 소스 선택지가 넓어진다.
- **대체 관계**: 폐쇄형 이미지 API를 **부분 대체 후보**. 다만 53.53의 의미가 확정돼야 판단 가능.
- **허와 실**: 실은 **레시피 전면 공개와 학습 순서의 재설계**. 허는 **"오픈소스 최고"의 벤치 종속성**.
- **액션**: **Turbo 증류본 가중치 URL·라이선스 확인**(중간). 2~4스텝이 사실이면 [[AI-영상-생성-2026]] 파이프라인 실험 대상.

> [!question] 미해결 질문
> - **Qwen-Image-Bench 53.53의 척도와 폐쇄형 대비 위치** — 이것 없이는 "최고"가 무의미.
> - **동결된 이해 모듈이 상한을 만들지 않는가** — 생성기는 새로 학습하는데 이해는 동결이면, 프롬프트 해석 능력이 백본에 고정된다.
