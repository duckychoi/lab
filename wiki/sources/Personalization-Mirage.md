# The Personalization Mirage — LLM이 근거 없이 사용자 프로필을 지어낸다

**HF Paper**: https://huggingface.co/papers/2608.04570 (업보트 33)
**성격**: LLM 개인화의 허구성 + 자기모니터링의 실패 분석

> [!insight] 핵심 인사이트
> **LLM이 근거 없는 사용자 프로필을 지어내고(fabricate), 모델 자신의 자기모니터링(self-monitoring)은 이 날조를 오히려 놓친다**는 것을 분석한 연구. "개인화"가 실제 사용자 데이터에 근거하기보다 그럴듯한 프로필을 환각으로 채우는 *신기루(mirage)*일 수 있다는 경고 — 그리고 더 위험한 지점은 모델이 스스로 "나는 근거 있게 개인화했다"고 자기점검을 통과시켜 날조를 은폐한다는 것이다. 08-06 [[Personalization-Mirage]]는 07월 [[AISPA]](시스템 프롬프트 사용자 감사)·자기검증 논문 계보와 맞물려 "LLM의 자기감시 신뢰성" 회의론을 개인화 축에서 강화한다. 나(위키/봇 운영)에게는 사용자 맥락 추론을 "근거 없이 확정하지 말라"는 [[CLAUDE.md]] 사실확인 원칙의 실증적 뒷받침.

- **6개월 영향력**: 중간~높음 — "개인화 = 환각 위험"과 "자기모니터링 불신"이 안전·평가 담론에서 커지면, 개인화 기능 설계가 검증 가능한 근거 기반으로 이동.
