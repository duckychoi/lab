# M³Eval — 인지심리학 기반 MLLM 기억 능력 종합 평가

**논문**: https://huggingface.co/papers/2606.05008  
**저자**: PKU (베이징대)

## 핵심 인사이트

> [!insight] 핵심 인사이트
> 인지심리학 기반으로 MLLM의 **기억 유지·정확성·간섭 내성**을 측정하는 최초 종합 평가 프레임워크. 핵심 발견: **공간 메모리 > 시간 메모리**, **멀티스트림 분리 표현은 전반적으로 취약**. "멀티모달 모델이 기억을 얼마나 잘하는가"를 처음으로 체계적으로 측정.

## 도메인별 추출 (ai-news 템플릿)

- **신뢰도**: ⭐⭐⭐⭐ — PKU, arXiv, HF Papers
- **즉시 활용**: YES (벤치마크로) — MLLM 에이전트 선택 시 메모리 능력 기준으로 활용
- **6개월 영향력**: 에이전트 메모리 레이어 설계에 직접 기준 제공. "모델이 기억을 못 한다"는 막연한 문제를 **공간/시간/간섭** 세 차원으로 구체화 — 어디를 보완해야 할지 명확
- **대체 관계**: MemLens, MemEye 등 기존 메모리 벤치마크 대비 인지심리학 이론 기반 체계성
- **허와 실**: 인지심리학 개념을 AI에 직접 매핑하는 것이 타당한가에 대한 이론적 논란 가능

## 기술 요약

**평가 3축**:
1. **기억 유지(Retention)**: 정보를 얼마나 오래 유지하는가
2. **정확성(Accuracy)**: 기억한 정보가 얼마나 정확한가
3. **간섭 내성(Interference Resistance)**: 새 정보가 기존 기억을 방해하는 정도

**핵심 발견**:
- 공간 메모리 (어디에 있었나) > 시간 메모리 (언제였나)
- 멀티스트림 분리 표현 (이미지+텍스트 분리 처리) → 메모리 취약
