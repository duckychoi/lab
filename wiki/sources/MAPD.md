# MAPD (From Proprietary to Open-Source, 논문 2607.24280)

> [!insight] 핵심 인사이트
> 독점(proprietary) 검색 에이전트의 역량을 **작은 오픈소스 모델로 이전**하는 다중 에이전트 프로토콜 증류(Multi-Agent Protocol Distillation). HF 논문 2607.24280·업보트 **51**. 저자 Jiangwang Chen 외(**베이징이공대(BIT)·화둥사범대·칭화·USTC·중국과학원**). 핵심 트릭: 교사의 출력을 그대로 흉내내면 **스타일 드리프트·토크나이저 불일치**가 생기므로, **구조화된 JSON 프로토콜을 중간표현**으로 써서 *"핵심 인지 전략을 특유의 언어적 껍데기에서 분리"*. 다중 에이전트가 고품질 프로토콜을 **오프라인 합성**(추론 오버헤드 제거) → **온라인 자기증류 + RL**로 학습. 결과: **Qwen3-1.7B 39.4%·Qwen3-4B 44.4%** 평균 성공률(7개 QA, 5개 완전 OOD), 멀티홉에서 상대개선 5.1~7.9%. 교사(Claude·GPT-5.5·Gemini) 무관하게 일반화. 07-25 [[AREX]]·[[온폴리시-증류]] "값싼 검증/증류로 비싼 역량 이전" 계보의 **검색 에이전트판** — [[MAPD]]는 그 이전 매개를 **JSON 프로토콜**로 표준화.

> [!warning] 자체발표 수치 · 미래형 ID
> 성공률·비용($1,454/25,600 인스턴스, ~$0.057/건, Gemini-3.1-Pro 사용)은 초록 WebFetch 실확인이나 **저자 자체 리포트**로 독립 재현 전. 논문 ID(2607.24280)가 미래형이라 원문 검증 불가 medium. 절대 성공률(39~44%)은 소형 오픈모델 기준으로 아직 낮음 — "격차 축소"지 "동등"이 아님.

## 도메인별 추출 (ai-news)

- **신뢰도**: ⭐⭐ — 초록·수치·비용 WebFetch 실확인, 자체발표·미래형 ID로 medium.
- **즉시 활용**: 조건부 — 내 위키 인제스트가 사실상 에이전틱 검색이라, **"독점 교사 → JSON 프로토콜 → 소형 오픈모델 증류"** 레시피는 로컬 검색 에이전트 저비용화 참고. 단 절대 성능이 아직 낮아 프로덕션보다 실험.
- **6개월 영향력**: 독점 프런티어의 **에이전틱 능력을 저비용으로 오픈·소형에 이식**하는 증류 파이프라인 성숙 신호. "JSON 프로토콜=스타일 독립 중간표현"은 교사 교체 자유도를 줌.
- **대체 관계**: 원시 궤적 모방 SFT 대비 **프로토콜 매개 증류**로 토크나이저·스타일 의존 제거. [[AREX]] 자기개선·[[Skill-Self-Play]] 자가학습과 "값싼 신호로 비싼 역량" 문제의식 공유.
- **허와 실**: 39~44%는 소형모델 한계 — "독점 근접"이 아니라 "무증류 대비 3~5%p 개선". 진짜 가치는 **저비용($0.057/건)·교사 무관 일반화·OOD 유지**.
- **액션**: JSON 프로토콜 중간표현 아이디어를 내 인제스트 에이전트의 "판단 로그 구조화"에 참고(스타일과 전략 분리 기록).
