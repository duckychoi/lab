## Neural Beamforming: 임베디드·다중사용자 최적화 중심

**핵심 3줄**
- 
Transformer 기반 신경 빔포밍이 MCU급 저전력 청취 기기에 실시간 배포
된 첫 사례 등장
- 
그래프 신경망(GNN)이 6G 초광대역 하이브리드 빔포밍 최적화에서 빔 스콰인팅 강건성 입증

- 
CNN 기반 희소 배열 설계로 동적 환경에서 90% 이상의 테스트 정확도 달성


**상세**
- **저전력 임베디드 배포**: 
STOI 97.65%, SI-SNR 20.26dB 성능으로 100mAh 배터리 기준 20시간 동작 달성
 (9월 2026 논문)
- **GNN 기반 멀티캐리어 빔포밍**: 
완전 디지털 빔포밍보다 우수한 강건성과 불완전 채널정보(CSI) 대응 능력, 재학습 없이 다중사용자 시나리오 확장 가능

- **mm파 학습 기반 빔 선택**: 
측정값 기반 DNN이 파일럿 빔만으로 최적 빔 예측, 기존 전체 스캔 대비 오버헤드 대폭 감소
 (6월 2026)
- **연속 개구 배열 에너지 효율**: 
함수 기반 그래디언트 바탕 암묵적 신경표현(FGB-INR)으로 추론 지연 감소 및 EE 개선, 샘플 복잡도 절감
 (7월 2026)
- **평탄 광학 위상 설계**: 
물리정보 신경망(PINN)이 평면 광학에서 사건 빔을 목표 강도 분포로 재형성하는 위상 프로파일 설계

## Neural Operator: 위상공간 확장·적응형 구조화

**핵심 3줄**
- 
위상신경연산자(TNO)가 점/모서리를 넘어 고차원 셀 복합체로 확장, 외미분 기하학으로 차원간 상호작용 명시화

- 
시간-주파수 게이트 스펙트럼 신경연산자(TF-SNO)로 비정상 PDE 학습 가능
 (6월 2026)
- 
신경연산자 합성 학습으로 도메인 변화에 강인한 물리 기초 모델(foundation model) 설계 원칙 제시


**상세**
- **위상신경연산자(TNO)**: 
계층적 TNO가 학습된 조대 복합체로 장거리·위상의존 정보 전파, 불규칙 기하학 유동 문제에서 정확도 개선
 (6월 2026)
- **적응형 공간 신경연산자**: 
TF-SNO는 시간-주파수 게이트로 비정상 PDE의 다중스케일 동적 분리 가능

- **신경연산자 합성(Learnable Composition)**: 
도메인 변화 시 정확도 저하 문제를 감독 적응으로 해결하되, 소규모 목표 데이터셋으로 고충실 시뮬레이션 비용 절감

- **함수공간 보간**: 
신경연산자를 기저공간 합성으로 작용하는 유한차원 함수로 재정의, MLP·KAN 대비 정확도 동등 이상 달성
 (5월 2026)
- **위상/동역학 검출**: 
신경연산자 프레임워크로 물리계 안정성·수용성의 데이터 기반 발견 지원

## Spectral Diffusion: 주파수 제어·동역학 모델링

**핵심 3줄**
- 
푸리에/웨이블릿 도메인 손실로 확산 모델 학습 증강, 아키텍처 변경 없이 빈도 의존 구조 유도

- 
단백질 동역학에 푸리에 변환 귀납편향 적용, 느린 구조 모드와 빠른 원자 진동 분리
 (7월 2026)
- 
적응형 스펙트럼 특징 예측이 FLUX.1 기준 4.79배, Wan2.1-14B 기준 4.67배 가속
 (3월 2026)

**상세**
- **스펙트럼 정규화**: 
DDPM/DDIM/EDM 모두 지원, 주파수 균형과 다중스케일 구조 조화로 고해상도·비조건부 데이터셋에서 최대 개선
