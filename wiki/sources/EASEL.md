# Paint What You See: Benchmarking Dexterous Visual Tool Use in Multimodal Agents

**arXiv**: 2608.25417 · **HF**: https://huggingface.co/papers/2608.25417
**지표(2026-08-31)**: 업보트 **13** · 저자 **6인** · 공개 **2026-08-26** — HF API 실호출 + **초록 원문 대조 검증**
**규모**: 모델 **25종** 평가 · **EASEL-Data 44만(440k) 샘플** 2단계 커리큘럼 · **EASEL-9B** 학습
**결과**: 재현 유사도 **0.40–0.54 정체** · EASEL-9B는 베이스 대비 **상대 +6.3%**, 전체 **3위**

> [!insight] 핵심 인사이트 — 빠져 있던 능력 축: "시각 증거 → 도구 파라미터"
> 기존 에이전트 벤치는 웹 내비게이션·GUI 조작·소프트웨어 엔지니어링을 다루지만, 이 논문이 짚는 **dexterous visual tool use**는 거의 비어 있다. 정의는 이렇다 — **시각 증거로부터 도구 파라미터를 추론하고, 그 파라미터가 최종 결과를 직접 좌우하는, 세밀한 폐루프 매개변수화 시각 행동**.
> 결정적인 차이는 **결합의 강도**다. 웹 클릭은 파라미터가 이산적이고 틀리면 티가 난다. 붓질은 좌표·굵기·색이 **연속값**이고, 조금씩 틀린 것이 **누적**된다. 그래서 프록시 과제로 **레퍼런스 이미지를 보고 캔버스에 점진적으로 그려 맞추는 재현 과제**를 골랐다 — 폐루프 정밀도를 측정하기 위한 통제된 인스턴스다. 여기에 영역 주석·손글씨·경로 계획 같은 의미 과제를 추가했다.

> [!insight] ⚠️ 진짜 발견은 점수가 아니라 **궤적의 모양**이다
> 재현 유사도가 **0.40~0.54에서 병목**이라는 것도 뼈아프지만, 궤적 진단이 드러낸 것이 더 중요하다 — **심각한 폐루프 불안정성**, 구체적으로 **모델들이 대체로 조기에 포화하거나(saturate early) 정점을 찍은 뒤 열화한다(degrade post-peak)**.
> **정점 후 열화**는 단순한 성능 부족이 아니다. 모델이 **자기가 이미 잘한 상태를 알아보지 못하고 계속 손대서 망친다**는 뜻이다. 이는 [[Agentic-Artifact-Creation]]이 같은 날 정리한 *"실패가 수리 가능한 동안 보이는가"* 와 *"학습된 심판이 생성기와 맹점을 공유하면 독립 증거가 못 된다"* 두 원칙이 **동시에 실측된 사례**다 — 모델이 자기 결과물을 보고 판단하는데, 그 판단이 틀려서 되레 나빠진다.
> 25개 모델에서 **공통 관측**됐다는 점에서 특정 모델의 결함이 아니라 **현 세대 멀티모달 에이전트의 구조적 한계**로 읽어야 한다.

> [!warning] EASEL-9B의 "3위"는 생각보다 약한 주장이다
> 44만 샘플 커리큘럼으로 학습한 EASEL-9B가 **베이스 대비 상대 6.3% 향상, 25개 중 3위**. 두 가지를 분리해야 한다.
> - **상대 6.3%** — 절대 개선폭이 아니다. 베이스 점수가 0.40이면 약 0.425 수준이며, 여전히 **0.40~0.54 병목 구간 안**이다. 즉 **데이터로 밀어붙여도 병목을 못 벗어났다**.
> - **3위** — 44만 샘플 전용 학습으로 1위를 못 했다는 뜻이기도 하다. 초록에 1·2위가 누구인지, 절대 점수가 얼마인지 **미기재**다.
>
> 미검증 항목: 유사도 지표의 **구체적 정의**, 25개 모델 **개별 점수**, EASEL-Data의 **생성 방식**, 코드·데이터 **공개 여부**(초록 언급 없음).

## 도메인별 추출 (ai-news)

- **신뢰도**: high(HF API 실호출 + 초록 대조 · 25모델 규모 · 정량치 다수). 벤치 논문답게 **수치가 있는 편**이나 개별 점수·채점 규칙은 미공개.
- **즉시 활용**: **YES(판별 규칙)**. *"에이전트가 자기 결과를 보고 계속 고치게 두면 정점 후 열화한다"* 는 25모델 실측 결과다 → **반복 개선 루프에는 반드시 정지 조건(최고점 스냅샷 보존)을 붙인다.** 볼트의 [[reat]] 이미지·영상 반복 생성, 위키 문서 반복 수정에 그대로 적용된다.
- **6개월 영향력**: 멀티모달 에이전트 평가가 *"맞췄나"*에서 ***"고쳐가는 과정이 안정적인가"*** 로 이동. 궤적 진단(trajectory diagnostics)이 표준 리포팅 항목이 될 가능성.
- **대체 관계**: 웹/GUI/SWE 벤치와 **경쟁이 아니라 보완**. 연속 파라미터 정밀도라는 빈칸을 채운다.
- **허와 실**: 마케팅 걷어내면 = **그림 따라 그리기 벤치 + 25모델 실패 패턴 분석 + 44만 샘플 학습 시도(3위)**. 화려한 건 EASEL-9B지만 **가치 있는 건 실패 패턴 쪽**이다.
- **액션**: 볼트 반복 생성 워크플로에 **"N회 시도 중 최고점 보존, 이후 개선 실패 시 롤백"** 규칙 추가 → [[actionable]] 등재.
