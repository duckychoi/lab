## 핵심 인사이트
> [!insight] 에이전트는 "짧은 파라메트릭 프로그램"을 쓰고, 실행은 결정적 코드가 한다
> 인간 · 동물 외 6개 형태(휴머노이드 · 다족 · 축형 · 날개 · 혼합 사지 · 기계)에 타이밍 · 각도 · 반복 · 궤적 제약이 붙은 지시 850건 벤치마크 **DivDynBench**를 만들고, ① LLM + 전용 모션 모델 ② 영상 생성 후 모션 복원 ③ LLM 직접 생성 3경로를 비교. 제안법: 에이전트가 **파라메트릭 골격 · 모션 프로그램**을 쓰고 **결정적 실행기**가 리깅 · IK · 기하 보정을 담당. [[gepa]] 와 같은 축 — LLM은 텍스트(프로그램)만 만들고 수치적 정확도는 결정론이 보장([[동결-교정층]] 표본 — 생성은 LLM, 교정은 코드).

> [!warning] 강한 모델 위에선 개선 폭 +1.9점에 그친다 — 약한 모델을 끌어올리는 방법이지 상한을 올리는 방법이 아니다
> 본문 표 3(리깅 49개 에셋): 원본 충실도 Claude Opus 5.5 단독 66.29% → +제안법 **100%**, 관절 유효성 0.59 → 0.92. 표 4(850건): 영상 경로 Seedance 2.5 + LLM 22.55–27.14(비용 0.39–0.42달러/건) vs 직접 생성 Claude 48.19 → +제안법 50.07(0.065 → 0.047달러), GPT-6.1-sol 30.19 → 35.99(0.024 → 0.0087달러). **지는 행**: Aesthetics 52.52 → 51.44 하락, Quality 최고는 GPT-6-Astra 단독 57.76(제안법 52.35), 리깅 Rigid RMS 최저는 SkinTokens 0.0168(제안법 0.0209).

## 도메인별 추출 (slam-3dgs)
- **정량 근거 1**: "영상 생성 → 모션 복원" 경로가 비싸고(0.4달러/건) 부정확하다(22–27점) — 3D 에셋 애니메이션에 영상 모델을 쓰면 안 된다는 수치.
- **정량 근거 2**: 프로그램 방식은 **비용을 낮추면서** 점수를 올린다(0.065 → 0.047달러 · +1.9점) — API 비용이 지배하는 워크플로우에서 프로그램화의 경제성 입증.
- **활용**: 3D 에셋 리깅 전처리 — 레포 ★1,352로 코드 접근성 있음. 볼트 3D 관련 작업 시 참조.
