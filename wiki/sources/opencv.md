# opencv/opencv

## 핵심 인사이트

> [!insight] CV 인프라의 상징적 존재, 여전히 트렌딩
> 30년 이상 역사를 가진 컴퓨터 비전 기반 라이브러리가 ⭐88,800으로 GitHub 트렌딩에 재등장. AI 붐 이후 Python 생태계에서 여전히 가장 많이 쓰이는 CV 진입점 — 딥러닝 프레임워크들이 자체 CV 기능을 내장해도 대체되지 않는 견고함.
