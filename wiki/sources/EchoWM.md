# EchoWM — 월드모델에 "소리"를 붙이고, 카메라 의도로 상호작용을 통일한다

**논문**: https://huggingface.co/papers/2608.23189 (arXiv 2608.23189)
**지표**: HF 데일리 **1위** · 업보트 **48** · 게재 **2026-08-24** · 저자 **22인**
**검증**: 2026-08-25 HF API 실호출 — 제목·초록·업보트·저자수·게재일 **원문 대조 완료**

> [!insight] 핵심 인사이트 — 월드모델의 경쟁축이 "화면"에서 "화면+소리+진입성"으로 이동했다
> 기존 월드모델 경쟁은 사실상 **영상 품질과 궤적 추종** 두 축이었다. EchoWM은 여기에 **오디오를 1급 출력으로 편입**한다 — 720p 영상과 **환경음·음악·음성**을 *동시에* 생성하며, 장기 생성 구간에서도 환경음·음성의 **동기(synchronization)를 유지**한다고 주장한다.
>
> 설계상 더 중요한 결정은 **상호작용을 "카메라 의도(camera intent)"로 통일**한 것이다. 1인칭 장면에서 카메라 의도는 **관찰자의 이동**을 뜻하고, 3인칭 장면에서는 **카메라–캐릭터 역학**을 뜻하는데, 후자를 **뷰 전용 컨트롤러 없이 데이터로부터 학습**시켰다. 이산 명령(discrete commands)과 연속 포즈(continuous poses)는 **공통의 metric-scale 상대 6-DoF 궤적**으로 매핑되고, **데이터셋 수준 캘리브레이션**으로 이질적 데이터 사이에서 모션 크기(motion magnitude)를 보존한다.
>
> 학습은 **상보적 데이터 엔진 + 점진 학습(progressive training) → 자기회귀 사후학습(autoregressive post-training)** 순서로, 장기 지평 생성을 겨냥한다.

> [!warning] 정량 수치가 초록에 하나도 없다
> "공개 월드모델 벤치마크에서 **강한 궤적 추종과 높은 시각 품질**"이라고만 서술하고 **벤치 이름·점수·베이스라인·비교 대상이 전부 미기재**다. 오디오 동기화 역시 "유지한다"는 서술뿐 정량 지표가 없다. 저자 22인·데일리 1위·업48이라는 **관심 지표는 최상위권이지만, 그것이 성능 근거는 아니다.** 초록 서술 자체는 원문 대조로 확정했으므로 reliability는 high로 두되, **성능 주장은 별건으로 미검증** 취급한다.

> [!note] "enterable"이라는 단어의 무게
> 제목의 *Open and **Enterable***는 관전용 영상 생성이 아니라 **사용자가 연속 내비게이션 입력으로 들어가는 매체**를 겨냥한다는 선언이다. [[ForgeWM]]이 few-step 액션조건부로 **지연시간**을 공략했다면, EchoWM은 **모달리티 폭**과 **1인칭/3인칭 통합**을 공략한다 — 같은 "진입 가능한 생성 매체" 목표의 서로 다른 병목 선택.

## 도메인별 추출 (ai-news / 교차: [[월드모델]] · [[AI-영상-생성-2026]])

- **신뢰도**: ⭐⭐⭐⭐ — 초록 원문 실검증 완료. 단 **정량 근거 부재**로 성능 자체는 판단 보류.
- **즉시 활용**: **NO** — 가중치·코드·데모 링크가 초록에 없다. 다만 **설계 아이디어는 즉시 참조 가능**: 이산 명령과 연속 포즈를 *하나의 6-DoF 궤적 표현으로 정규화*하는 방식은 [[video-saas]] 쪽 카메라 컨트롤 UI를 설계할 때 그대로 빌려올 수 있다(프리셋 버튼과 자유 드래그를 같은 내부 표현으로 환원).
- **6개월 영향력**: 높음 — 오디오 동반 생성이 월드모델 표준 요구사항으로 굳으면 **영상만 내놓는 모델은 반쪽**이 된다. 현재 오픈 i2v 상위([[LTX-2.5]]·[[MiniMax-H3]])는 **무음 출력**이 기본이라 격차가 벌어질 수 있는 지점.
- **대체 관계**: [[HY-World-2.0]]·[[AlayaWorld]]·[[EvolvingWorld]]와 같은 "진입 가능한 월드" 계보. [[ForgeWM]]과는 상보(모달리티 폭 ↔ 추론 지연).
- **허와 실**: 22인 저자·데일리 1위는 **대형 랩의 화력**을 시사하지만 초록에 **소속·모델 공개 여부·파라미터 규모·추론 비용이 전부 없다.** 720p·장기 생성·4모달리티 동시 생성이면 **추론 비용이 매우 클 가능성**이 높은데 이에 대한 언급이 없다는 점이 가장 큰 공백.
- **액션**: 코드/가중치 공개 여부 추적. 공개 시 **오디오 동기화 품질**을 1차 검증 포인트로.
