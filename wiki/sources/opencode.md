# opencode: The open source coding agent

**raw 수집값(09-05)**: ⭐204,347 → 하루 만에 **+512**. 절대값만 채택.

> [!insight] 핵심 인사이트 — **에이전트 층에서 "모델 중립"이 스타를 모은다**
> 이 레포의 단 한 문장짜리 설명(*"The open source coding agent"*)이 포지션 전부다. **특정 모델 벤더에 묶이지 않는다**는 것이 유일한 차별점이고, ⭐20만은 그 포지션에 대한 표다.
> 볼트가 09-04~09-06에 걸쳐 관측한 상위 레포들([[mattpocock-skills]] ⭐25.3만 · [[ECC]] ⭐25.0만 · [[hermes-agent]] ⭐24.2만 · [[anthropics-skills]] ⭐17.5만)과 **같은 대역**인데, 저 넷이 전부 *"에이전트 위에 얹는 층"*(스킬·하네스·메모리)인 반면 **이것은 에이전트 본체**다. 즉 이 배치에서 **본체 하나에 상부구조 넷**이라는 구도가 보인다.

> [!warning] ⚠️ **오픈이슈 5,704건 — 배치 내 최대 마찰 지표**
> fork/star = 0.130, **issue/star = 0.0278**. [[hermes-agent]](오픈이슈 38,696)만큼은 아니지만 절대량이 크다. 기본 브랜치가 `main`이 아니라 **`dev`** 라는 점도 함께 읽어야 한다 — **안정 릴리스가 아니라 개발선이 기본**이라는 뜻이고, 이는 이슈 밀도와 정합적이다.
> ⚠️ 벤치마크·성공률 수치는 레포 메타데이터에 **없다**. "코딩 에이전트로서 얼마나 잘하는가"는 이 페이지로 판정 불가.

> [!insight] 소유자가 `sst`가 아니라 `anomalyco`다
> 널리 알려진 opencode는 SST 팀 계열로 회자돼 왔으나, 이 레포의 owner는 **organization `anomalyco`(id 66570915)** 다. npm 배포명은 `opencode-ai`. **인용 시 레포 경로를 `anomalyco/opencode`로 고정**한다 — 볼트가 벤더/소유자를 잘못 적으면 이후 대조가 전부 어긋난다.

## 도메인별 추출 (ai-news)

- **신뢰도**: ⭐⭐⭐⭐ high — GitHub API 실측(스타·포크·이슈·라이선스·브랜치 전부 확인). 단 **성능 근거는 0**이므로 "좋은 에이전트"가 아니라 "많이 별 받은 에이전트"까지만 확정.
- **즉시 활용**: **YES(조건부).** MIT + npm 배포라 설치 마찰이 낮다. 다만 지금 작업 환경이 [[Claude-Code-워크플로우]]에 정착돼 있으므로 **교체가 아니라 대조군**으로 쓴다 — 같은 과제를 양쪽에 던져 하네스 차이를 관측하는 용도.
- **6개월 영향력**: **중간~높음.** 모델 중립 에이전트가 ⭐20만을 유지하면, 스킬·하네스 자산([[에이전트-스킬]])이 **어느 본체 위에서도 돌아야 한다**는 압력이 커진다. 이는 [[anthropics-skills]]가 표준을 자기 레포 밖(agentskills.io)에 둔 설계와 같은 방향이다.
- **대체 관계**: Claude Code / Codex CLI의 **직접 경쟁재**. 단 볼트 관점에서는 대체보다 **하네스 변수 통제용 제2 환경**의 가치가 크다.
- **허와 실**: 실은 **MIT·TypeScript·활발한 push(당일)**. 허는 **품질 주장 부재** — ⭐20만은 관심 지표이지 성공률이 아니다(볼트 규칙: *다운로드·스타는 접근성 지표이지 품질 근거가 아니다*).
- **액션**: [[Claude-Code-워크플로우]]와 **동일 과제 1건 대조 실행**(중간). `dev` 브랜치 기본이라는 점을 감안해 **버전 고정 후** 실험.
