### Qwen3.8-27B 계열 — 실행 환경별 3분화 (2026-08-27 실측)
같은 베이스에서 갈라진 파생들이 **용도별로 분화**했고, 다운로드 규모가 그 수요 지도를 보여준다.

- **가드레일 제거 축** — [[Qwen3.8-27B-Uncensored-Aggressive-MTP-GGUF]] DL **911,795**(현 선두) · [[Qwen3.8-27B-OBLITERATED]] **468,746** · [[Qwen3.8-27B-Uncensored-GGUF]]

**구조**: 양자화 ≫ 원본 ≫ 가드레일 제거. 원본/GGUF 비율이 **0.402 → 0.432**로 2회 연속 상승해 격차는 축소 중.
> [!warning] 가드레일 제거 축은 전량 low
> 이 축 세 모델 모두 **제거 방식·능력 손실 벤치·명칭("Aggressive"·"MTP") 의미가 전량 미검증**이다. DL 91만은 수요의 크기이지 품질·안전성의 근거가 아니다. **실배포 후보가 아니라 생태계 관측 대상**으로만 추적한다.
> ⚠️ **HF 다운로드 수치는 격일 갱신**(4회 연속 확인) — 증분은 최소 2일 단위로 해석하고 좋아요 축을 교차 확인한다.

## 에이전트 메모리 아키텍처 패턴

### 이원 분리형 — VoiceMem (2026-08-27 추가)
[[VoiceMem]](HF 데일리 2위·업82)이 제시한 **정보(좌뇌) ∥ 감정(우뇌) 병렬 분리 + 스트리밍 I/O**.
- **핵심 수치**: **top-5 검색으로 Mem0의 top-200보다 약 30점 우위** — 후보를 **40배 적게** 가져오면서 더 정확
- **지연**: 검색 **134ms**로 표준 VAD 지연 안쪽 → **대화 지연 추가 없음**
- **페르소나**: 단·장기 정서 귀인 + 이중 노드 모델링, 벤치 3종 SOTA·종합 **+4.29점**
- **배포**: 메모리 백엔드 **교체형 분리 배포**

**설계 교훈**: 검색량을 늘리는 방향이 아니라 **무엇을 색인하고 어떻게 경로를 나눌 것인가**가 정확도를 만든다. [[MemTrapBench]](메모리 5종이 no-memory보다 못함)와 함께 읽으면 정식화는 이것 — **성패는 메모리 도입 여부가 아니라 경로 분리 방식에 달렸다.**
⚠️ 절대 점수·벤치 3종 이름·134ms 측정 조건 미기재. 코드 ★28로 재현 보고 부재.

## [2026-09-03] 자동수집 배치 — 희소 어텐션 3중 관측 · 프런티어 3종 크기 확정

### [[Declarative-Attention]] — **학습 없이 KV 캐시 절반을 건너뛴다**
모델이 사고사슬 안에서 `<global>`/`<focus>`/`<local>` 로 **참조 범위를 스스로 선언**하고, 추론 엔진이 이를 **툴콜처럼 파싱**해 KV 캐시 읽기를 건너뛴다.
**15개 롱컨텍스트 과제 제로샷 · 기성 모델**: Gemma-4-31B **참조 토큰 -52.0%**(정확도 -1.27%p) · Qwen-3.6-27B **-31.1%**(-2.75%p). **손실이 모델이 커질수록 줄어든다.**
- **실용성**: 27~31B는 내 로컬 범위 상단. **학습 불필요**는 강력하나 ⚠️**추론 엔진 수정이 전제** — vLLM/llama.cpp에 바로 안 얹힌다. 구현체 공개 여부 **미확인**.
- **트레이드오프**: ⚠️**-52.0%는 참조 토큰이지 wall-clock이 아니다.** 실제 속도 이득 미보고.
- **Hermes 적용**: 엔진 없이 **프롬프트 층 모방 가능** — 답변 전 *"최근 대화만 보면 되나, 전체를 봐야 하나"* 를 선언시키고 컨텍스트 주입량을 조절. 이득은 작지만 **비용 0**.
- **메모리 분류 확장**: [[에이전트-메모리-레이어]]에 **"선택적 비독해"** 항목 신설 — 외부에 두지도 압축하지도 않고 **읽지 않기로 선택**한다. 관련성 판단 주체가 검색기/스코어러가 아닌 **모델 자신**이다.

### 프런티어 오픈 모델 3종 크기 확정 (HF API 실검증)
- [[GLM-5.3]] **753B** · `glm_moe_dsa` · fp8 · **독자 라이선스** → **로컬 범위 밖**
- [[GLM-5.3-Flash]] **321B**(활성 18B 주장) · `glm5_next` · fp8 · **MIT** · **멀티모달** → DL **517,902**로 계열 실사용 축
- [[Qwen3.8-Flash-Next]] **180B** · `qwen4_exp` · **`qwen-community-1.0`** · 멀티모달 → **배치 내 최소 프런티어급**
⚠️ **셋 다 단일 소비자 GPU 범위 밖**이다. fp8이어도 마찬가지. 로컬 관점에서 이번 배치의 실질 수확은 모델이 아니라 **[[Declarative-Attention]]의 기법**과 **[[TimesFM]] 3.0의 331M**이다.

### 🚨 규칙 정정 — 공개 직후 HF DL은 사용량이 아니다
[[GLM-5.3-Flash]] 34→**517,902** · [[Qwen3.8-Flash-Next]] 4,810→**263,287** · `timesfm-3.0` 0→**46,862**. 서로 다른 벤더·모달리티·규모에서 동일 → **생성 10일 이내 모델의 DL을 로컬 채택 판단 근거로 쓰지 않는다.** 상세는 `domains/ai-news.md` 09-03 항목.

## [2026-09-04] 배치 — 로컬 추론의 세 층: 서빙 · 캐시 · 함수화

### 🖥️ [[magnitude]] — "에이전트가 추측하지 않게" 만드는 서빙 층 (⭐2,106, Apache-2.0)
Ollama와의 차이를 레포가 FAQ로 직접 답했다 — *"에이전트에게 Ollama를 깔라고 시키면 **에이전트는 추측한다.** 네 하드웨어도, 어떤 양자화가 맞는지도, 얼마나 빠를지도 모른다."* Magnitude는 칩·메모리·대역폭을 **프로파일링**해 **예상 tok/s가 계산된 카탈로그**를 준다.
- **파는 것은 추론 속도가 아니라 모델 선택의 근거**다. 볼트가 5개월간 *"어떤 모델이 좋은가"* 를 물어온 데 반해, **"내 기계에서 무엇이 도는가"를 자동으로 답하는 첫 도구**
- **Hermes를 지원 하네스에 명시** (Pi·OpenCode·Hermes·OpenClaw·Codex·Claude Code·Oh My Pi·Cline) → 오래된 *"hermes-agent 검토"* 항목에 **경로가 생겼다**
- ⚠️ **medium**: 생성 3개월·워치 13·포크 150 · **벤치마크·tok/s·지원 모델 목록·양자화 정책 전부 없음.** *"best models"* 의 **"best"를 무엇으로 정하는지가 미공개** — 유일한 판매점이 그 선택 로직인데도. **설치는 하되 파이프라인 의존 금지**
- ⭐ **볼트 효과**: 로컬 실행 대기 actionable **5건 이상**([[Gemma-4-31B]]·[[Gemma-4-26B]]·[[Gemma-4-E4B]]·[[Qwen3.8-27B]]·[[VoxCPM]])이 전부 **이 기계에서 도는지 모른 채** 쌓여 있다. `magnitude setup` **한 번이면 한꺼번에 판정**된다

### 🎲 [[Random-Attention]] — 캐시 층, 점수 매기기가 순손실이었다 (HF 1위, [[Salesforce]])
*"선택 신호는 거의 기여하지 않는다."* 프롬프트만 지키고 헤드별 **균일 무작위 축출**, 점수 계산 **없음**. 4모델·6추론태스크에서 최강 기존 축출기와 **동급**, vLLM **처리량 32~43%↑**. 코드 공개.
- **왜 되는가**: ①격차의 대부분은 *"그 신호가 우연히 프롬프트를 지켰는가"* 였다 ②추론 트레이스는 **텍스트 층(모델이 필요한 걸 계속 재진술)** 과 **헤드 층(각 헤드가 사본 보유)** 의 **2층 중복으로 자기를 방어**한다 → 프롬프트만 안전하면 무작위로도 사본이 충분히 남는다
- **구현 부담이 음수**다 — 점수 함수를 **삭제**하는 방향
- ⚠️ 논문이 **`reasoning` 으로 범위를 스스로 한정**했다. 추론 트레이스가 없는 워크로드(짧은 응답·요약)엔 자기방어 중복이 성립하지 않으므로 **일반화 금지**. 모델명·태스크명·절대 점수 미공개 → *"동급"* 까지만 인용

### 🔧 [[Compile-by-Training]] — 함수 층, 명세를 가중치로 굽는다 ([[University-of-Waterloo]])
[[Program-as-Weights]]의 **직접 후속**. 컴파일 시점에 교사 모델이 예제를 생성 → **작은 어댑터** 학습 → **공유 0.6B 로컬 인터프리터** 위에서 도는 재사용 가능 신경 함수. 교사 없이 실행되고 **저장·버전관리·합성이 보통 소프트웨어처럼** 된다.
- **FuzzyBench-Hard**(PAW fast compiler가 **정확 일치 0건**)에서 **의미 정확도 83.6%**, 대가는 컴파일 **수 초 → 약 1분**
- **전통 컴파일러의 `-O0` vs `-O2` 구조가 신경 함수에 동형으로 재현**됐다 — 두 컴파일러는 공존하고 같은 PAW 프로그램을 낸다
- **교환비가 명확히 유리**: 컴파일은 1회, 실행은 무한
- ⚠️ **코드·가중치 미공개**(웹 서비스만) · **"의미 정확도"의 채점 주체 미상** — 교사가 데이터도 만들고 채점도 했다면 순환([[검사가능성-공사]]) · 83.6%는 **6건 중 1건은 틀린다**는 뜻 → 무인 파이프라인 투입 금지

### 🚦 [[BCIT]] — 학습 경험도 조건부로만 재사용한다
자율 사후학습에서 *"이후 학습으로 부모 모델이 바뀐 뒤에도 과거의 그 성공 증거가 유효한가"* 를 **conditional experience transfer** 로 정식화. `Reject / Validate / Train` 정책으로 **가중치를 바꾸기 전에** 승인. Qwen3-4B·금융추론/text-to-SQL/함수호출에서 **등예산 최종 품질 최고**, Flat-Additive 대비 **+2.63점(95% CI [2.10, 3.16])**.
- **설계 원칙 하나가 [[에이전트-메모리-레이어]]에 직접 이식 가능**: ***"관측된 사건만이 메모리를 확장한다"*** — 추론·가정은 메모리에 못 들어간다
- ⚠️ 모델 1종·태스크 3종. 비교군 중 이름 확인된 건 Flat-Additive 하나. **코드 없음 → 재현 불가**

### 이 배치가 local-llm에 남긴 것
서빙([[magnitude]]) → 캐시([[Random-Attention]]) → 함수화([[Compile-by-Training]]) 가 **한 스택의 세 층**으로 맞물린다. 그리고 [[Random-Attention]]과 [[BCIT]]가 **선택을 없애서 / 더해서** 각각 이긴 것이 새 개념 [[선택비용과-중복성]]을 낳았다.

# [2026-09-06] 09-05·09-06 배치 — **압축·양자화 축에서 "중복성" 개념이 두 번 확인됐다**

신규 3건이 이 도메인에 들어왔다: [[LatentPress]] · [[Minima]] · [[Qwen3.8-27B-GSQ-RCO-GGUF]] (+ [[Qwen3.8-Flash-Next-GGUF]]).

## 1. 🆕 [[에이전트-메모리-레이어]]에 **여섯 번째 축** — 연속 잠재 메모리 ([[LatentPress]])
지적의 핵심이 기술이 아니라 **설계 관성**이다: *"압축된 컨텍스트는 보통 **사람이 읽을 수 있는 텍스트**나 렌더링된 이미지로 운반된다 — **그 소비자가 언어모델일 때조차도.**"*
**동결된 디코더가 입력 임베딩 인터페이스로 직접 읽는 연속 메모리 토큰**, 추론 시 텍스트 복원 없음.
- LongMemEval **0.504 @ 7.70배 압축** vs **무압축 원문 0.490** — **압축본이 원문을 이겼다**
- 텍스트 요약 **0.184** · OCR **0.426~0.312** 대비 큰 격차
- 어댑터만 학습 **4.2M~26.2M(디코더의 ~0.1%)** · 쓰기 **43ms/대화** · 읽기 **5~9배**

## 3. [[선택비용과-중복성]] 근거 보강 — **양자화 층에서 같은 원리**
