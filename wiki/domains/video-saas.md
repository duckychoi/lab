# 영상 AI SaaS 누적 인사이트

## 결과 QA — "최종 컷"이 아니라 "전개"를 본다 (2026-08-27 추가)

### VGI-BENCH가 바꾸는 재시도 전략
[[VGI-BENCH]](HF 데일리 4위·27과제 810인스턴스·초록 원문 대조)의 디노이징 내부 분석에서 **후반 스텝은 초기 가설을 다듬을 뿐 추론 오류를 교정하지 못한다**(limited self-correction)는 것이 관측됐다.

> [!action] 파이프라인 재시도 규칙 분리
> **스텝/해상도를 올리는 재시도는 화질을 올리지 추론을 고치지 않는다.** 구도·물리·인과가 틀린 샷은 더 오래 돌려도 안 고쳐진다.
> → 재시도 분기를 둘로 나눈다: **품질 불만 → 스텝·해상도 증가** / **구도·인과 오류 → 프롬프트·입력 조건 변경**(재생성).

### 생성 품질과 시각 추론은 별개다
최강 모델 **[[Seedance]] 2.0도 자체 기준 51.0%**. VFX 품질로 위키에 등록된 모델이 시각 추론에서는 절반 수준이다 — **"영상이 예쁘다"와 "말이 된다"는 다른 능력**임을 보여주는 수치. ⚠️ 다른 모델 개별 점수·채점 규칙 미공개, 코드/데이터 "공개 예정" 상태라 제3자 재현 불가.

### 경쟁 우위 빈틈 — 과정 기준 자동 검수
[[SemComp-Bench]](의미적 완료도 채점)와 [[VGI-BENCH]](전개 타당성)를 합치면 **생성 영상 자동 검수 렌즈**의 밑그림이 된다. 현행 툴들이 최종 프레임 품질만 보는 상황에서 **중간 프레임의 인과 일관성을 검사하는 QA**는 비어 있는 차별화 지점이다. [[HarnessEval-W]](생성물 평가의 에이전트화)가 같은 축.

## 기능 벤치마킹## 기능 벤치마킹

### 캐릭터 + 씬 + 샷 통합 (Higgsfield Cinema Studio 2.5)
- 단일 인터페이스에서 캐릭터 생성 → 씬 구성 → 샷 편집
- 기존: 여러 툴 연결 파이프라인 필요 → 현재: 단일 플랫폼

### VFX 특화 (Seedance 2.0)
- 할리우드급 VFX를 소형 스튜디오가 직접 제작
- invideo AI와 통합하여 엔드투엔드 파이프라인 구성 가능

### 오픈소스 Higgsfield 대안 (2026-04-09 등장)
- 유료 장벽 없이 Higgsfield 유사 기능 제공
- → 자체 SaaS에 오픈소스 엔진 활용 가능성 검토 필요

### 완전 자동화 파이프라인 (Claude Code + Higgsfield)
- 트렌드 감지 → 스크립트 → 영상 생성 → 배포까지 무인 자동화 가능

## 크리에이터가 실제로 원하는 것

1. **얼굴 없이 채널 운영**: "촬영 없음, 얼굴 공개 없음, 경험 없어도 가능" — AI 아바타 콘텐츠 수요 높음
2. **광고 제작 비용 절감**: 에이전시 수수료 없이 직접 시네마틱 광고 제작
3. **일관된 캐릭터**: 시리즈 제작 시 동일 캐릭터 유지 (Higgsfield/Kling 강점)
4. **1인 영화 제작**: 단편영화, 숏드라마를 팀 없이 혼자 완성

## 경쟁 우위 빈틈

1. **한국어 특화 영상 AI 부재**: 모든 주요 도구가 영어 중심. 한국 브랜드/크리에이터용 특화 도구 시장 존재.

## [2026-09-03] 자동수집 배치 — 데이터 계약(SolarWM)과 음성 하네스(VoiceStudio)

### [[SolarWM]] — 월드모델의 **데이터 계약**이 공개된다
10개 데이터셋 **143만 클립**을 **프레임 정렬 단일 계약**으로 통합: 시각 관측 · **미터법 카메라 기하** · 캡션 · **품질 메타데이터** · **선별 결정** · **출처**.
[[LTX-2.5]] · [[MiniMax-H3]] · Wan2.2 백본 위 **5B~33B 4종**을 각자 표현 보존한 채 학습. **5초 시퀀스만 학습해 분~시간 롤아웃**을 실시간 상호작용으로 주장.
- **디자인/파이프라인 레퍼런스**: ⭐ **계약 6개 필드 구조는 내 영상 파이프라인에 즉시 이식 가능**하다. 특히 *선별 결정*과 *출처*를 씬 메타데이터의 **1급 필드로 승격**시키는 발상 — 지금 내 [[reat-chunk]]/[[reat-scene]] 산출물은 *무엇을 골랐는지*는 남기지만 ***왜 뺐는지***를 안 남긴다.
- **경쟁 우위 빈틈**: 월드모델 논문 대부분이 **비교 불가능한 자체 세팅**에 갇혀 있었다. 공용 계약이 실제로 공개되면 그 파편화가 풀린다.
- ⚠️ **초록에 벤치 수치 0.** *"실시간"* 의 fps·해상도·GPU 미상, 장기 롤아웃에서 **무엇이 먼저 무너지는지** 미기술.

### [[VoiceStudio]] — ⭐ **[[reat-voice]] 로컬 대체 후보 (배치 유일 즉시 활용)**
⭐15,454 · **AGPL-3.0** · 당일 푸시. **모델이 아니라 16 TTS + 11 ASR 엔진 위의 하네스**다.
- **인터페이스 4종**: 데스크톱 앱 · 로컬 REST/SSE/WebSocket · **OpenAI 호환 오디오 API** · **MCP 서버**
- → 기존 TTS 호출을 **엔드포인트만 바꿔 로컬 전환** 가능하고, ASR 11종으로 **자막(SRT)까지 같은 스택**에서 처리된다. 계정·API 키·구독·사용량 미터 **없음**(로컬 워크플로).
- **워크플로 함의**: 음성 스택이 *"어느 모델을 쓸까"* 에서 ***"어느 껍데기에 꽂을까"*** 로 이동. [[SolarWM]]이 비디오 백본에 한 것과 **같은 패턴의 음성판**이다.
- ⚠️ **"646개 언어"는 레포가 스스로 한정**한다(*"actual coverage and quality depend on the selected engine"*). **엔진별 한국어 품질은 미측정** — 실측이 유일한 경로.
- ⚠️ **라이선스 2층**: 앱 AGPL-3.0(네트워크 서비스 제공 시 소스 공개 의무) / 다운로드 모델은 **각자 상위 조건 유지**. **개인 워크플로 = 문제없음 / 제품 임베드 = 엔진별 심사 필요.**
