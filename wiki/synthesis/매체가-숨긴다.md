# 매체가 숨긴다

> [!insight] 명제
> **같은 주체가 같은 사실을 서술할 때, 어떤 매체에 쓰느냐가 숨기는 양을 결정한다.**
> 그러므로 *"이 저자는 정직한가"* · *"이 벤더는 믿을 만한가"* 는 **판정 단위가 틀린 질문**이다. 판정 단위는 **매체**다 — 초록 / 본문 / README / 모델카드 / 트렌딩 요약 / API 필드.

## 사례 1 — 논문: **저자는 적었고 초록이 뭉갰다**

[[HC-DLM]] 초록: *"HC-DLM improves over discrete and continuous diffusion baselines at matched model size, **in puzzle accuracy on Sudoku and Countdown** and in generative perplexity on LM1B."*

볼트가 PDF(617KB·24p)를 열어 표와 1:1 대조한 결과:

| 주장 | 실측 | 판정 |
|---|---|---|
| Countdown | 6M 급 CCDD 81.18→**84.41** · 25.35→**37.52** | ✅ 정확 |
| LM1B | 디퓨전 중 최저 **75.5**(🔴 AR 66.7 이 더 좋음) | ✅ 정확 — *"among the evaluated **diffusion** models"* 한정 |
| **Sudoku** | 🔴 **Easy: CCDD 94.65 > HC-DLM 94.21 패배** · Hard 만 승리 | 🔴 **부정확 — 2 split 중 1개에서만 참** |

✅ **본문은 숨기지 않는다**: *"the matched CCDD implementation attains comparable and **marginally higher** accuracy (**94.65 vs. 94.21**)"* — **수치까지 적어 자기 패배를 명시한다.**

⚖️ **같은 저자가 같은 논문에서 한쪽은 [[자기제한-명시]] 를 실행하고 한쪽은 실행하지 않았다.**

같은 배치 [[Sharpening-Tax]] 는 **비용**을 같은 방식으로 숨겼다 — 초록 *"given a sufficient test-time budget"* ↔ 본문 **`pass@128`**(37회 언급 · 주 설정). 🔴 **초록만 읽으면 *"base 모델이 더 낫다"* 로 오독하고, 그 결론에는 128배 샘플링 비용이 붙어 있다.**

## 사례 2 — 레포/모델: **빈 칸과 그림이 같은 일을 한다**

- **그림 매장**: [[Sharpening-Tax]] 의 tax 수치는 **Figure 6·7·26** 에 있다(*"Figure 26 provides the full results"*). 🔴 **PDF 를 열어도 안 풀린다** ⇒ [[벤치마크-이미지-봉인]] **2종 분해: 미열람형(열면 풀림) · 그림매장형(열어도 안 풀림)**.
- **빈 칸**: [[impeccable]] 은 ★74,563 · `npx impeccable install` 1줄 배포인데 **`topics` 0** 이다. 같은 배치 [[Agent-Reach]] 는 **17**. ⇒ ⚖️ **`topics` 는 배포 의도도 규모도 반영하지 않는다 — 메인테이너가 그 칸을 채웠는지만 반영한다.**
- **라이선스 칸**: [[Sharpening-Tax]] 구현체 `license` = `NOASSERTION` ↔ 실체 **CC BY-NC(상업 금지)**. 🔴 **앞선 2사례([[openclaw]]·[[TileLang]])가 실체 MIT 였기 때문에 "서식 문제"로 일반화될 뻔했다.** ⚖️ **`NOASSERTION` 은 라이선스 성격에 대한 정보가 0이다.**

📌 **공통 구조**: 그림·빈 칸·탐지기 라벨은 모두 **"읽을 수 있는 자리에 값이 없다"** 를 만든다. 그리고 **그 자리가 비었다는 사실은 대상의 속성이 아니다.**

## 사례 3 — API: **가장 조용한 층**

- **[[무응답-오귀속]] 요청 미지정형(10-03 신설)**: [[Qwen3.8-27B]] 기본 조회 `trendingScore`=`None` → `?expand[]=` 재조회 **352**. ⚖️ **응답이 비지 않았다(200·JSON·다른 필드 정상). 특정 칸만 비었다** ⇒ 📌 **"무응답"이 아니라 "무필드"다.** 🔴 **신호도 구제 경로도 없고 서버는 값을 갖고 있다.**
- **[[복합지표-분해]] `organization`**: [[Sharpening-Tax]] API **Meta**(1개) ↔ PDF **Meta SI Labs · UW–Madison · NYU · Stanford(4개)** · [[HC-DLM]] API **UIUC-CS**(1개) ↔ PDF **UIUC · Amazon(2개)**. 🏆 **[[Amazon]] 엔티티는 API 에 나타나지 않았고 PDF 저자 각주에서만 발견됐다.**

⚖️ **API 층이 가장 위험하다 — 그림은 "여기 그림이 있다"는 신호를 주고, 빈 칸은 "비었다"는 신호를 주지만, `None` 은 아무 신호도 주지 않는다.**

## ⚖️ 그래서 볼트가 바꾸는 것

1. **판정 단위를 매체로 내린다.** 10-02 결론 *"신뢰도는 벤더 단위가 아니라 **소스 단위**로 매긴다"* 의 한 단계 아래: **같은 소스 안에서도 매체별로 매긴다.** 📌 10-02 에 NVIDIA 내부에서 [[OpenShell]](위협모델 0) ↔ [[Nemotron-3-Diarization]](DER 9개)로 갈린 것이 **벤더 → 소스** 하강이었고, 오늘 [[HC-DLM]] 초록 ↔ 본문이 **소스 → 매체** 하강이다.
2. **"인용 검증 통과"와 "주장 검증 통과"를 분리해 적는다.** 🔴 **오늘 수집기는 초록을 옳게 인용했고 초록이 과대했다** — 볼트가 15배치 동안 쌓은 *"초록 전수 대조 N/N 통과"* 는 **전자만 검증한다.** 📌 10-02 로그가 이미 그 한계를 **알고 적어 뒀고**, 오늘 그 문장의 비용이 수치로 나타났다.
3. **봉인을 기록할 때 유형을 적는다.** 미열람형은 **actionable**(읽으면 끝난다), 그림매장형은 **우회 경로**가 필요하다(구현체 코드·저자 문의·OCR).
4. **빈 값을 기록할 때 "어떤 요청/어떤 매체에서 받은 빈 값인지"를 함께 적는다** → [[암묵을-명시로]].

> [!warning] 🔴 이 명제가 주장하지 않는 것
> **"초록은 믿을 수 없다"가 아니다.** [[HC-DLM]] 초록 3개 주장 중 **2개는 정확**했고, 한정어(*"at matched model size"* · *"among the evaluated diffusion models"*)가 **정확히 필요한 자리에 붙어 있었다**. ⇒ ⚖️ **초록은 압축이고, 압축은 손실이 있고, 손실은 불리한 쪽에 몰린다. 그것이 전부다.**
> 🔴 **그리고 정직성은 성능의 증거가 아니다** — HC-DLM 은 본문에서 정직하게 적고도 Sudoku Easy 를 졌다.

> [!question] 미해결 질문
> - **손실이 정말 불리한 쪽에 몰리는가?** 🔴 **n=1 이다**(HC-DLM 1건). 📌 검증 절차: 앞으로 PDF 를 열 때마다 **초록 주장 ↔ 표 실측을 1:1 대조하고 어긋난 방향을 기록**한다. 유리한 쪽으로 어긋난 사례가 나오면 이 명제는 약해진다.
> - **볼트 자신의 매체는 어떤가?** `index.md` frontmatter 는 극도로 압축된 매체이고 `log.md` 는 긴 매체다. 🔴 **index 가 log 의 불리한 부분을 뭉개고 있는지 볼트가 점검한 적이 없다** → lint 항목 후보.
