# 포맷 불일치 오염 *(잠정 · 표본 1)*

> [!insight] 한 줄
> **테스트셋이 다른 포맷으로 학습에 섞이면 표준 프롬프트 점수가 오히려 떨어진다 — 오염이 점수를 부풀리지 않고 깎아서, 오염 탐지 신호(비정상 고점)가 사라진다.**

## 사례 — [[marin]] 32B의 GSM8K
회고 문서 기준 오염 데이터가 점수를 **약 22점 깎았다**. 저점 + 프롬프트 취약성이 같이 나타났다(저자 기록).

## 볼트 판정 규칙 제안
- 오염은 "고점"만 의심하지 않는다. **비정상적 저점 + 프롬프트 형식에 따른 급변 = 오염 의심** 신호로 추가
- 표본 2 이상 쌓이면 [[측정도구-먼저-반증]] 하위 규칙으로 승격

## 관련 페이지
- [[marin]] · [[Stanford-CRFM]] · [[측정도구-먼저-반증]] · [[분포내-우위]]

> [!insight] 🔴 2026-09-29 — **손상의 원인을 전송 계층에 귀속하기 전에 2경로를 대조하라**
> 수집기가 [[Post-Training-Behavioral-Shadows]](2609.29233)에 대해 *"**HF API 가 반환한** 초록 본문이 부분 손상돼 있다"* 고 표기했다. **귀속이 틀렸다.**
> **볼트 대조**: HF papers API 와 **arXiv API 원문**이 **글자 단위로 같은 손상**을 반환했다.
> ```
> 양 경로 공통: "...Qwen2.5-1.5B, 5,664nses yield a 5.34 pp gain on HumanEval+ over an
>                exact nuisance-matched control thadisrupts prompt-resperiments showtransfer
>                in scientific knowledge, commonsense reasoning, and reading comprehensins..."
> ```
> 📌 **⇒ 손상은 저자 제출본에 있다.** 중간 계층(HF)을 의심할 근거가 없었다.
> 🎯 **규칙**: *"X가 깨진 데이터를 줬다"* 는 **X 를 거치지 않는 경로에서 멀쩡한 데이터를 받아야만** 할 수 있는 말이다. 그 대조 없이는 **"데이터가 깨져 있다"** 까지만 쓴다(주어 없이).
> ✅ **부수 효과**: 대조 과정에서 **판독 가능 범위가 수집기 판정보다 넓다**는 것도 확인됐다 — *"an exact nuisance-matched control"* 은 손상 이전 구간이라 **인용 가능**하다. 손상 구간을 과대 추정하면 **쓸 수 있는 정보를 버리게 된다.**
