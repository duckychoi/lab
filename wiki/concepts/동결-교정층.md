# 동결-교정층 (Frozen Body + Correction Layer)

> [!insight] 정의
> **판단(생성)을 담당하는 본체를 동결하거나 거의 건드리지 않고, 판별·교정·증명·제약 같은 "생성 뒤 단계"를 새 파라미터나 외부 조건의 얇은 층으로 붙인다.** 학습·수정의 단위가 "모델 전체"에서 "층"으로 내려온다. 11-24 배치에서 하루에 4표본, 11-25 배치에서 8표본이 더 모인 축 — 이틀 연속 관찰.

## 표본 (n=12)

1. **[[NoPeWorld]]** (arXiv 2611.27963, 업보트 56) — 사전학습 DiT 를 **동결**, 궤적 조건 **prediction head 만 새로 학습**. 진입(침투) 방지 책임을 head 쪽에 둔다.
2. **[[TAISR]]** (arXiv 2611.15449, 업보트 22) — SR 모델 **재학습 0**. 외부 MLLM(Gemma 4)이 뭉개진 글자를 추론해 **캡션으로 갈아끼움** — 본체는 그대로, 입력 조건이 교정층. 대가(PSNR 소폭 하락)까지 자기보고.
3. **[[gepa]]** (★7,558) — **가중치 0**: 텍스트 파라미터(프롬프트)만 반성적 진화로 최적화. 교정층이 전부 텍스트인 가장 순수한 형태.
4. **[[Inkling-2-Mini-Uncensored-GGUF]]** — 원본 동결 + **rank-1 LoRA 49지점**(24층 attention 출력 · routed experts · 토큰 임베딩)으로 층별 거부 방향 제거. 12 looped 층 가중치 공유 → 1편집 = 48패스. 실패 게이트(MMLU −1.5%p p=0.006 · KL 미달)를 카드가 스스로 공개.

**2026-11-25 추가 (n=4 → n=12) — 층의 유형별로 확산:**

5. **[[Embo-Harness]]** (arXiv 2611.31201, 업보트 52→99) — **학습 0**: 프런티어 모델을 그대로 로봇 정책으로. 프롬프트 · 계획 · 실행 · 도구 4축 절제가 하네스 설계만으로 83.3% — "층 0" 극단.
6. **[[PartAgent]]** (arXiv 2611.32554, 업보트 29) — **전 파이프라인이 교정층**: 동결 P3-SAM(제안) + 2D 전문가(단서) + VLM 검증 루프, 학습 0으로 학습형 SOTA +8.53. 검증 VLM 교체 영향 0.04–0.15점(검증층은 아무거나).
7. **[[Plan4D]]** (arXiv 2611.26516, 업보트 27→29) — **model stitching**: 동결 본체 2개(3D 재구성 + 영상 생성)를 이어 붙이고 DPT 헤드만 추가. 교과서적 "본체 동결 + 접합층".
8. **[[NightWatch]]** (arXiv 2611.28947, 업보트 34) — **외부 감시 플러그인**: 에이전트 모델 · 프롬프트 · 행동공간 3중 동결, 0.8B 감시 모델이 인터럽트 · 무효화만 담당. 성공률 동률, 대기 −33%.
9. **[[S-Mind]]** (arXiv 2611.28649, 업보트 31→32) — **LoRA r64**: Qwen3.5(4B/9B) 동결 + 공간 토큰 학습. 도구 기반 방법 대비 81배.
10. **[[pi-H3]]** (dl 32,375→57,282) — **증류 어댑터**: [[MiniMax-H3]] 동결 + 2–4스텝 증류 + DWD로 **VAE 디코더 자체를 우회** — 교정층이 파이프라인 부품을 없애는 확장.
11. **[[3AGameFactory-Motion]]** (arXiv 2611.30013, 업보트 41→59) — **텍스트/프로그램 교정층**([[gepa]] 동형): LLM은 파라메트릭 프로그램만 쓰고 리깅 · IK · 보정은 결정적 실행기. 비용 −28% · 점수 +1.9.
12. **[[vllm-ascend]]** (★3,148) — **인프라 확장**: vLLM 본체 수정 0 하드웨어 플러그인(RFC #11162). 패턴이 모델·에이전트를 넘어 서빙 스택까지.

## 경계 사례

- **[[Duopra]]** (arXiv 2611.25773, 업보트 28) — **부분 사례**: 프로토콜 SFT · 전이중 RL 앞 2단계는 학습 포함, **마지막 단계만 talker 조건 projector 만 복구**. "동결"이 스펙트럼임을 보여준다.
- **[[cmHC]]** (arXiv 2611.27193, 업보트 94) — **대조군**: 새 파라미터 없이 잔차 믹싱을 걷어내 본체 자체를 얇게 만든다(Birkhoff 다면체 수축). 교정층이 아니라 **본체 축소** — 반대 방향.
- **[[bend]]** (★25,832) — 코드 쪽 사례: 생성 이후 **proof gate** 로 PR 병합을 증명에 묶음([[검사가능성-공사]]). 파라미터 교정은 아니지만 "생성 뒤 판단 계층"이라는 축은 같다.
- **[[Loom-Attention]]** (arXiv 2611.30634, 11-25) — **대조군 추가**: 어텐션 구조 자체를 재설계(헤드 간 "세로 어텐션"). [[cmHC]] 와 같은 반대쪽 — 본체를 바꾸는 방향. 이론 FLOPs +2%지만 실측 처리량 8–16% 감소 — 본체 재설계의 비용이 실측에서 나타나는 사례.
- **[[Motion-Mamba-2.0]]** (arXiv 2611.29897, 11-25) — **대조군 추가**: PCM 메모리로 루트-바디 본체를 신설. 장기 정확도 16배 개선의 대가는 윈도 지연 4–8배 — 본체 재설계가 맞는 문제(먼 과거 유지)도 있다는 균형 표본.

> [!warning] 한계
- **명칭은 볼트가 붙인 것** — 12개 소스가 스스로를 같은 축으로 부르지 않는다. 표본 12 · 이틀 연속이라 **"패턴"이라는 판단은 가능**해졌으나, 표본이 볼트 수집 편향(HF 데일리 상위 5편 선발)을 공유할 가능성은 검증되지 않았다.
- TAISR · Inkling 은 품질 대가를 자기보고하지만, NoPeWorld · GEPA 는 "본체 손상 없음"의 독립 검증이 없다.
- [[Duopra]] 를 경계로 두면 "동결"의 정의가 스펙트럼 — 어디까지를 같은 축으로 셀지 미확정.
