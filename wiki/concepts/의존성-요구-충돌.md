# 의존성 요구 충돌

> [!insight] 정의
> **한 저장소가 "지원한다"고 선언한 대상들이 서로 양립 불가능한 의존성 버전을 요구하는 상태.** 이때 지원 목록은 **동시 가용 목록이 아니다** — 목록의 각 항목은 각자의 환경에서만 성립한다.
>
> 🎯 **"단일 인터페이스로 전부 지원"은 코드 수준의 통일이고, 실행 환경의 통일이 아니다.** 이 둘을 구분하지 않으면 실용성 판정이 과대평가된다.

## 신설 계기 — [[airllm]] (2026-10-12)

README 전문 실측. 같은 레포가 `AutoModel` 하나로 전부 지원한다고 적는다(2026/06 v3.0: *"all through a single `AutoModel`"*). 🔴 **그런데 요구 버전이 충돌한다.**

| 지원 대상 | `transformers` 요구 | 추가 제약 |
|---|---|---|
| **Kimi K3 (2.8T)** | **4.56.x** — 원문: *"its remote code **does not load on 5.x**"* | `flash-attn` 강제 · **CUDA 12** 빌드 torch(*"no prebuilt flash-attn wheel exists for CUDA 13 yet"*) |
| **Qwen3.8-27B** | **5.8+** | — |
| **Qwen3.8-Flash-Next** | **git 빌드** (*"pip install git+…/transformers.git today"*) | in-tree `qwen4_exp` · 디스크 **~360GB** |

⇒ 🔴 **K3(≤4.56.x) 와 27B(≥5.8) 는 동일 가상환경에서 공존 불가다.** 📌 레포의 지원 목록을 보고 *"이 도구 하나로 두 모델을 번갈아 쓸 수 있다"* 고 판단하면 틀린다 — **환경을 둘 만들어야 한다.**

> [!insight] 🎯 왜 이것이 별 개념인가 — [[선언된-구현체-공백]] 과의 경계
> | 개념 | 상태 |
> |---|---|
> | [[선언된-구현체-공백]] | 선언한 구현체가 **없거나 작동하지 않는다** |
> | **의존성 요구 충돌**(이 개념) | 각 구현체는 **전부 작동한다.** 🔴 **다만 동시에는 안 된다** |
>
> 📌 **후자는 "거짓 주장"이 아니다.** 레포는 요구 버전을 **정직하게 각 항목에 적었다**. 🔴 **충돌은 항목을 나란히 놓고 비교할 때만 보인다** — 각 줄만 읽으면 드러나지 않는다. ⇒ 🎯 **독자가 교차 대조를 해야 발견되는 유형이다.**

## 📌 인접 관측 — 같은 날 다른 형태 1건

[[Qwen-Image-2.1-Uncensored-Quantized]]: 카드가 *"표준 ComfyUI-GGUF"* 가 아니라 **`leejet` 포크**를 요구한다 — 원문: *"If you have the older `city96/ComfyUI-GGUF` installed and encounter an `Unknown model architecture!` error, update to the `leejet` fork."*
⇒ ⚖️ **이것은 "충돌"이 아니라 "비표준 요구"다.** 📌 충돌(상호 배타)과 비표준 요구(표준으로는 안 됨)를 **같은 개념에 넣지 않는다** — 후자는 [[선언된-구현체-공백]] 계열이다. **경계를 적어 둔다.**

## 볼트 규약

1. 🔴 **지원 목록이 3개 이상인 레포는 항목별 요구 버전을 표로 뽑아 대조한다.** 한 줄씩 읽으면 충돌이 안 보인다.
2. 📌 **실용성 판정에 "환경 개수"를 쓴다** — 목표 모델 2개가 다른 환경을 요구하면 **설치 비용이 2배**다.
3. ⚖️ **충돌을 레포 결함으로 적지 않는다.** 📌 상류(모델 제공자)의 요구가 갈린 결과일 수 있다 — K3 의 `4.56.x` 제약은 **K3 측 remote code** 가 만든 것이다(레포 원문이 그렇게 적는다).
4. 🆕 **"단일 인터페이스" 주장과 "환경 통일" 주장을 분리해 인용한다.**

> [!warning] 🔴 한계
> - **표본 1건**([[airllm]]). 2건째가 나오기 전까지 패턴으로 단정하지 않는다.
> - ⬜ **볼트가 실제로 설치해 충돌을 재현하지 않았다** — README 기재 버전의 논리적 비교다. 📌 `transformers` 5.x 가 K3 remote code 를 **정말로** 거부하는지는 **미검증**(레포 주장).
> - ⬜ 가상환경 분리·컨테이너로 우회하면 실무상 문제가 아닐 수 있다. **"불가능"이 아니라 "비용"이다.**
