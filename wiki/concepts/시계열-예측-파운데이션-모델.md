# 시계열 예측 파운데이션 모델

LLM의 "대규모 사전학습 → 제로샷 범용화" 패러다임을 시계열 예측 도메인에 적용한 모델군. 도메인별 학습 없이 다양한 시계열 데이터를 예측.

> [!update] 2026-09-03 — **TimesFM 3.0 공개** · 이 개념이 **에이전트 일색 배치에서 트렌딩 2위**를 지켰다
> [[TimesFM]] GitHub ⭐**30,397**(트렌딩 **2위**), 신모델 **`google/timesfm-3.0-pytorch`**(생성 2026-08-24 · DL **46,862** · 좋아요 315 · **331M 파라미터** · 라이선스 `other`) 확인 — 전량 HF/GitHub API 실호출.
>
> 📌 **이 개념의 위치가 이번 배치에서 선명해졌다.** 2026-09-03 자동수집 13건 중 **12건이 에이전트·LLM·생성모델**이었고, [[TimesFM]] **한 건만 다른 축**이었다. 그런데 트렌딩 2위다.
> → 시계열 파운데이션 모델은 **AI 담론의 주변부에 있으면서 사용 축에서는 살아 있다.** 볼트가 이 개념을 04-11 이후 갱신하지 않은 **약 5개월**은 담론의 편향이지 이 분야의 정체가 아니었다.
>
> 📌 **331M이라는 크기가 이 개념의 성격을 말한다.** 같은 날 배치의 [[GLM-5.3]] **753B**, [[GLM-5.3-Flash]] **321B**, [[Qwen3.8-Flash-Next]] **180B** 옆에서 TimesFM 3.0은 **2,275분의 1**이다.
> **시계열은 스케일 경쟁의 축이 다르다** — 파운데이션 모델이라는 이름을 공유하되 *"크게 만들어 범용을 얻는다"* 가 아니라 *"작게 만들어 어디에나 꽂는다"* 쪽이다. **CPU·엣지 배포가 현실적**이라는 뜻이며, 이는 [[local-llm]] 도메인의 관심사와 직접 겹친다.
>
> ⚠️ **세대 교체가 아직 안 일어났다**: `timesfm-2.5-200m-transformers` DL **55,036** > `timesfm-3.0-pytorch` DL **46,862**. 신버전이 **좋아요는 2.4배**(315 vs 134)인데 **다운로드는 0.85배**다. 공개 10일차라 판정은 다음 회차로 미룬다.
> ⚠️ **정확도 벤치는 여전히 미확인** — 3.0이 2.5보다 나은지 볼트는 **모른다**. [[Kronos]]와의 비교도 04-11 이후 갱신되지 않았다.


> [!insight] 핵심 인사이트
> "언어를 이해하는 LLM"이 등장한 것처럼, 2024~2026년에 "시간을 이해하는 파운데이션 모델"이 등장했다. TimesFM(Google)과 Kronos가 이 범주를 개척. 도메인별 모델 학습 없이 제로샷으로 비즈니스 지표·금융 데이터를 예측 가능.

## 기존 방법 대비 우위

- **Before**: Prophet, ARIMA, Informer — 데이터별 학습 필요, 도메인 전문성 필요
- **After**: 파운데이션 모델 → 즉시 추론, fine-tuning 없이 새 도메인 적용

## 실용 적용 범위

- SaaS 비즈니스 지표(MAU, 매출, 이탈률) 예측
- 재고·물류 수요 예측
- 에너지 소비 패턴
- 금융 자산 변동성 예측 ([[Kronos]])

> [!warning] 주의
> 금융 예측은 과적합·과신 위험 높음. [[TradingAgents]]와 마찬가지로 백테스트 → 실거래 갭 반드시 확인.
