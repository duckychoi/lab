# 배수-조건분산

> [!insight] 명제
> **범위로 보고된 배수는 조건 명시 없이는 인용할 수 없다.** 하한과 상한의 폭이 크면 그 배수는 단일 성능값이 아니라 **조건의 함수**이고, 조건을 모르는 상태에서 상단값을 쓰면 틀린다.

이것은 [[복합지표-분해]] 와 다른 문제다. 복합지표 분해는 **여러 지표가 서로 다른 방향을 가리키는** 경우를 다루고, 조건분산은 **하나의 지표가 조건에 따라 크게 흔들리는** 경우를 다룬다.

## 신설 계기 — [[TokenRouter]] (2026-10-10)

초록이 *"디코딩 처리량 **2.01~64.15배**"* 를 적는데 **어떤 조합에서 64.15x 가 나오는지 적지 않는다.**
- 배수 폭 = **32배**(2.01 vs 64.15)
- 변동 요인 3개가 선언됨: 라우팅 알고리즘 × 워크로드 × 모델 쌍
- ⇒ **상단값만 인용하면 틀린다.** 하단값 2.01x 가 현실적 기대값일 수 있다.

## 같은 배치 2번째 사례 — [[Qwen3.8-Flash-Next-GSQ-RCO-GGUF]]

프리필 우위가 **워크로드마다 부호를 바꾼다**:
- RAG **9.6배** · writing **6.8배** · coding **6.2배**
- **stem · math · reasoning 은 0.8~0.9배 = 역전**

⇒ *"3.4배 빠름"* 은 **55프롬프트 평균**이고, 워크로드를 지정하지 않으면 **빠른지 느린지조차 결정되지 않는다.**
🏆 **단 이 카드는 조건을 스스로 적었다** — 조건분산을 공급자가 먼저 공개한 사례다([[자기제한-명시]] 와 겹친다).

## 규약

1. 배수가 **범위**로 보고되면 하한·상한을 **둘 다** 적는다.
2. 조건(워크로드·하드웨어·모델 쌍)이 명시되지 않으면 **"조건 미확정"을 함께 적는다.**
3. 🆕 **수치가 범위면 초록에 있어도 본문을 연다** — 기존 규약(*"초록에 수치가 없을 때 본문을 연다"*)이 이 경우를 놓친다. [[TokenRouter]] 가 실제로 이 구멍으로 빠져나갔다.
4. 부호가 뒤집히는 구간이 있으면(0.8~0.9배 역전) **평균 배수를 대표값으로 쓰지 않는다.**

## 🏆 2026-10-11 — [[OuroWorld]]: 규약이 판정에서 **조사**로 넘어갔다

*"사용자 선호 **70.8%~99.0%**"*(폭 **28.2%p**)에 규약이 트리거를 걸어 **본문 §A.6 을 열게 했고 범위의 정체가 확정됐다.**
🎯 **실체는 성능 범위가 아니라 2지 택1(two-alternative forced-choice) 승률 분포다**: 39장면 × 4베이스라인 = **156쌍** · 쌍당 5명 · 참가자 30명 × 26쌍 ⇒ **총 780 시행 · 베이스라인당 195표** · 4기준(vividness / naturalness / loop seam / visual quality).
⇒ ⚖️ **즉 16개(4×4) 조합별 승률이고, 우연 수준은 50%다.** 📌 **최약 조합(70.8%)도 유의하지만 최강 베이스라인 상대값이 70.8% 쪽이므로 99.0% 를 대표값으로 인용하면 틀린다.**
🆕 **그리고 loop seam 기준 4개 조합은 설계상 유리하다** — Fourier 급수 변형 필드로 **루프를 구성상 보장**하므로 이음새가 정의상 없다 ⇒ **그 축의 높은 승률(최대 99.0%)은 모델 품질의 증거가 아니다.** 볼트는 **가중치를 낮게 본다.**

> [!insight] 🏆 규약의 투자수익 — 2배치 연속 걸렀다
> 10-10 신설([[TokenRouter]] 2.01~64.15배) → 10-10 승인 → 🎯 **10-11 에 [[OuroWorld]] 1건을 걸렀고, 이번엔 "본문을 열어라"는 행동까지 지시했다.**
> ⇒ ⚖️ **판정 규약이 조사 규약으로 작동한 첫 사례다.**

## 🆕 2026-10-11 — 하한이 기준선인 2건 추가

- **[[SimpleICL]]** OOD 과제: 2.25배 ~ **15.2배**. 🔴 **최대 15.2배는 시작값 3.3(거의 0)에서 나온 수**이므로 대표값이 아니다.
- **[[MiMo-V2.6-Tech-Report]]** Table 6: 1.96배 ~ **9.7배**. 🔴 **최대 9.7배는 시작값 2.6 에서 나왔다.**
⇒ 📌 **공통 패턴: 최대 배수는 거의 항상 시작값이 0 근처인 항목에서 나온다.** 🆕 **규약 보강: 배수를 인용할 때 분모(시작값)를 함께 적는다** — 분모가 한 자리수면 배수는 정보를 거의 담지 않는다.
