# 구조적 영값

> [!insight] 정의
> **지표가 0인 것과 현상이 0인 것은 다르다. 계수기가 작동할 전제조건이 충족되지 않으면 사용량과 무관하게 구조적으로 0이 나온다.** HF 다운로드 수가 대표 사례다 — 저장소 **루트에 라이브러리 트리거 파일이 없으면** 카운터가 애초에 발화하지 않는다.

🎯 **[[캐시된-지표-신선도]](09-27)가 "지표가 낡았다"를 다뤘다면, 이 개념은 "지표가 아예 대상을 안 본다"를 다룬다.** 낡은 값은 갱신하면 되지만 **구조적 0은 갱신해도 0이다.**

## 실측 — `convaiinnovations/laya` (2026-09-28, 볼트 HF API 직접 조회)

수집기가 이 모델을 **판단 요청**으로 남겼다: *"trendingScore 1위(2,632)인데 downloads 0. ♥4,185 에 DL 0 조합 자체가 이상값이다(미확인: 게이트 여부·출시 직후 여부)."*

**볼트가 두 미확인을 모두 해소했다:**

| 항목 | 실측값 | 판정 |
|---|---|---|

| `createdAt` | **2026-09-18** (10일 전) | ❌ 출시 직후 아님 |
| `downloads` (30일) | **0** | — |

**두 가설이 다 틀렸다. 그래서 세 번째를 찾았다 — 파일 배치다.**

## 🎯 원인: 루트에 `config.json` 이 없다

레포 파일 38개 중 **루트 파일은 7개**다:

```
.gitattributes  README.md  email_utils.py  model.safetensors
rl_agent_api.py  rl_agent_config.json  rl_common.py
```

**`config.json` 이 루트에 없다.** 실제 config 들은 전부 하위에 있다:

```
encoder/config.json
multilingual/encoder/config.json
typed-decisions/encoder/config.json
```

📌 **HF 다운로드 카운터는 라이브러리별 "트리거 파일" 요청을 세는 방식이다.** `transformers` 계열의 트리거는 루트 `config.json` 이다. 루트에 그 파일이 없으면 **누가 몇 번을 받아 가도 카운터가 0에 머문다.** `model.safetensors` 는 루트에 있지만 그건 세지 않는다.

🎯 **결론: laya 의 DL 0 은 "아무도 안 쓴다"가 아니라 "HF가 셀 수 없는 레이아웃"이다.** ♥4,187 은 사람이 직접 누르는 행위라 전제조건이 없고, 그래서 정상 집계된다. **두 숫자의 괴리는 인기의 괴리가 아니라 계측 방식의 괴리다.**

> [!warning] 볼트가 확인하지 않은 것
> ⬜ HF 카운터의 트리거 파일 목록을 **공식 문서로 대조하지 않았다.** 루트 `config.json` 부재와 DL 0 의 **동시발생은 실측**이고, 인과는 **볼트 추론**이다. 반증 방법: 루트 config.json 이 없는 다른 `transformers` 레포를 2~3건 더 찾아 전부 DL 0 인지 본다(actionable 등록).
> ⬜ laya 가 `multilingual/`·`typed-decisions/` 서브폴더 구조를 쓰는 이유(멀티 변종 배포)가 의도적 설계인지 실수인지 모른다.

## 수집기 선발에 주는 함의 — 🔴 필터가 조용히 탈락시킨다

수집기는 오늘 *"downloads 내림차순 상위 3"* 으로 HF모델을 골랐다. **그 정렬에서 laya 는 최하위로 떨어진다(DL 0).** 트렌딩 1위(score 2,632)가 **계측 아티팩트 때문에 탈락**했다.

🎯 **[[원본-파생-역전]] 이 "정렬 키가 파생을 고른다"였다면, 이건 "정렬 키가 계측 불가능한 것을 고르지 않는다"다.** 같은 뿌리의 다른 가지다 — **선발은 세상이 아니라 계측 가능한 세상만 본다.**

**볼트 판정: 수집기의 `downloads` 기준 적용은 지시문 해석으로는 옳았다. 다만 `downloads == 0` 은 이제부터 "낮은 인기"가 아니라 "계측 실패 의심"으로 분기해야 한다.** ♥ 가 높은데 DL 이 0 인 조합은 특히 그렇다.
