# VLA (Vision-Language-Action)

> [!insight] 정의
> **카메라 이미지 · 언어 지시 · 로봇 상태를 입력받아 구체적 행동을 직접 출력하는 모델.**
> 출력이 추상 계획이 아니라 **관절각도 · 엔드이펙터 포즈 · 손 개폐** 같은 실행 가능한 제어값이다 ⇒ 🎯 **"계획을 세우는 LLM"과 갈리는 지점이 여기다.** 중간 심볼 표현 없이 지각에서 구동까지 한 모델이 잇는다.
> 📌 학습 방식은 **다양한 작업 데이터를 모아 행동을 만들어내는** 모방/데이터 주도 방식이다 ⇒ ⚖️ **"단순 프로그래밍 제어 → 데이터 기반 자율 학습"의 패러다임 전환**이 VLA 가 대표하는 변화다.

## 2026 현황 (크론 리서치 노트 기반 · 🔴 전건 2차 인용 · 볼트 독립 검증 미실시)

- **출하 규모**: 2026년 전 세계 휴머노이드 출하량 전망 **5만 대 이상 · 전년 대비 약 7배**
- **VLA–SLAM 통합**: VLA 기반 임베디드 로봇 SLAM 이 **동적 간섭 필터링 · 키프레임 선택 · 인수 그래프 구성**을 통합하는 방향으로 발전
- **하이브리드 제어**: RL + LLM 결합이 RL 단독 대비 작업완료시간 **33.5%** · 정확도 **18.1%** · 적응성 **36.4%** 향상 🔴 **출처 논문·벤치마크 미공시**
- **폐쇄루프 자율학습**: 로컬 메서드 라이브러리를 먼저 검색하고, 적절한 해법이 없으면 LLM 이 자율 학습 프로세스를 개시
- **산업 사례**: 신소이드 VLA 모델 *'싸이블라'* + 월드모델 공개(WAIC 2026, 제조 현장 목표) · 현대차그룹 완전 전기구동 아틀라스(**2028년 미국 공장 투입**) · K-휴머노이드 연합 로봇 AI 파운데이션 모델(**2028년 1차 목표**)

> [!warning] 🔴 신뢰도 — 이 페이지의 수치는 전부 2차 인용이다
> 근거는 `topic: humanoid-slam-vla` 크론 리서치 노트 **4회차분**이며, 출처가 언론·블로그·벤더 발표다. **arXiv 1차 자료 대조를 하지 않았다.**
> 🔴 특히 **33.5% / 18.1% / 36.4%** 는 태스크·벤치마크·기준선이 노트에 없어 **인용 불가 수준**이다.
> ⇒ `reliability: low` 유지. **상향 조건: VLA 1차 논문 1건 이상 직접 열람.**

## 🎯 금일 교차 발견 — 공간지능의 결손은 "인식"이 아니라 "순차 조작"이다

| 소스 | 과제 유형 | 결과 |
|---|---|---|
| [[MJev-Spatial]] | **단발** 공간 질의(관계·거리·위치) | 🏆 **종합 65.64% · 12/12 자기베이스 상회** |
| [[RoTA-Bench]] | **순차** 조작(회전 선택 → 투영 정합) | 🔴 **GPT-5.6-Sol 17% vs 인간 100%** |

⇒ ⚖️ **두 수치는 모순이 아니다.** 모델은 **한 장면을 보고 공간관계를 답하는 것**은 잘하고, **여러 단계를 선택해 목표 자세를 맞추는 것**은 못 한다.
⇒ 🎯 **VLA 에 직결되는 함의**: VLA 의 출력은 본질적으로 **순차 제어**다. 따라서 **단발 공간 질의 벤치마크의 높은 점수가 VLA 성능을 예측하지 않는다** ⇒ [[벤치마크-외부축]] 적용 대상.
⇒ 🔴 **RoTA-Bench 의 추가 수치가 이 진단을 강화한다**: 상호작용 이력을 제거하면 모델 행동의 **96.8% 가 30도 고정 스텝**에 머문다 — **순차 의사결정이 사실상 붕괴**한다.

## 📌 볼트 연결점 (slam-3dgs 템플릿 관점)

- **현재 SOTA**: VLA 단독 SOTA 수치를 볼트가 보유하지 않았다 🔴 **공백**
- **실시간 가능성**: [[MJev-Spatial]] 의 **포워드 1회 · 답변 토큰 0 · 파라미터 추가 0** 구조가 *"interaction rates"* 요구에 맞춘 설계 ⇒ **VLA 의 공간 질의 레이어로 대응 가능**(단 fps·ms 미공시)
- **카메라 파이프라인**: VLA 입력은 카메라 이미지 + 언어 + 로봇 상태 ⇒ SLAM 이 제공하는 **자기위치·맵**과 자연스럽게 결합(위 "VLA–SLAM 통합" 항목)
- **필수 레퍼런스**: 🔴 **없다** — 볼트가 VLA 1차 논문을 한 건도 보유하지 않았다. **이것이 slam-3dgs 도메인의 최대 공백이다.**

> [!question] 미해결 (우선순위 높음)
> ① **VLA 1차 논문 0건 보유** — RT-2 / OpenVLA / π0 계열 중 최소 1건 직접 열람 필요.
> ② *'싸이블라'* 의 원 표기(중국어/영문) 미확인 — 2차 인용 음차일 수 있어 검색이 불가능하다.
> ③ "VLA 기반 임베디드 로봇 SLAM" 의 구체 구현체·논문 미확인.
