# 벤치마크 외부축

> [!insight] 정의
> **논문이 자기 벤치마크 점수를 보고하면서, 같은 초록에 "이 점수가 포착하지 못하는 축"을 함께 적는 현상.**
> 🎯 핵심은 **그 축이 점수와 반대 방향을 가리킨다**는 것이다. 점수는 올랐는데 외부축은 격차·실패·발산을 보여준다 ⇒ **점수만 읽으면 결론이 뒤집힌다.**
> ⚖️ 이것은 과장이 아니라 **그 반대**다 — 저자가 스스로 자기 수치의 유효 범위를 좁힌다. 따라서 **외부축을 적은 논문은 신뢰도가 높다.**

## 신설 계기 — 2026-10-17 배치에서 **3건이 동시에 나왔다**

### ① [[OpenGCUA]] — 점수는 8/8 올랐고, 실기기 비용은 19.4배 벌어졌다
- **벤치마크**: OSWorld-v2 에서 **평가 8개 모델 전부 점수 상승** · 평균 partial score **+19.6점** · 스텝 **−53.0%**
- 🔴 **외부축**: *"Across four real macOS tasks … selected **Qwen3.8-Max** runs use **19.4 times** as many reported reasoning tokens as **GPT-6 Astra**, highlighting substantial differences between models in real-device execution efficiency."*
- 저자 서술: *"The harness addresses real-device challenges **not fully captured by benchmarks**."*
- ⇒ ⚖️ **같은 점수를 내는 두 모델의 비용이 19.4배 다르면 벤치마크 점수는 모델 선택 근거가 못 된다.**

### ② [[FDE-Gym]] — 실패를 2축으로 분해하고, 더 큰 쪽이 벤치마크가 못 재는 쪽이었다
- **벤치마크**: 최고 구성 평균 **0.56** · 95건 중 **14건만** 해결
- 🔴 **외부축**: *"**information discovery alone does not account for the gap**: even on the **23 tasks where the best configuration obtains every key fact** from stakeholders, it reaches … 0.8 or above on only **10**."*
- ⇒ 🏆 **정보를 전부 얻은 상태에서도 56.5% 가 실패한다** ⇒ 병목은 "묻지 않아서"가 아니라 **"정보 → 작동하는 해법" 변환**이다. 🔴 **벤치마크 총점 0.56 은 이 분해를 숨긴다.**

### ③ [[RoTA-Bench]] — 두 지표가 같은 상태에서 서로 발산한다
- **벤치마크**: **GPT-5.6-Sol 17% vs 학부생 20명 100%**
- 🔴 **외부축**: 동일 상태에서 **실루엣 겹침은 개선하면서 자세 정합은 악화**시키는 비율 **모델 19.4% vs 인간 10.9%**
- ⇒ ⚖️ **겹침 지표만 보면 성능을 과대평가한다** — 저자가 지표 간 발산을 명시했다.

## 🎯 공통 구조 — 왜 이 3건이 같은 개념인가

```
벤치마크 점수  →  "개선됐다"
외부축        →  "그 개선이 유효한 범위는 좁다"
```

세 건 모두 **저자가 자발적으로** 후자를 적었고, 세 건 모두 **후자가 의사결정에 더 중요**하다:
- OpenGCUA → **어느 모델을 쓸지** (비용 19.4배)
- FDE-Gym → **에이전트에 무엇을 맡길지** (정보 줘도 57% 실패)
- RoTA-Bench → **어느 지표를 믿을지** (겹침 ≠ 정합)

## 📌 볼트 적용 규약

> [!action] 규약
> ① **초록에서 "not fully captured" · "does not account for" · "alone" · "yet" 류 접속을 찾는다** — 외부축은 거의 항상 이 연결어 뒤에 온다.
> ② **외부축을 발견하면 한줄요약에 점수와 **함께** 적는다.** 점수만 적으면 저자가 좁혀 놓은 범위를 볼트가 다시 넓히는 셈이다 → [[한정어-탈락]].
> ③ **외부축을 적은 논문은 `reliability` 상향 근거로 쓴다** — 자기 수치의 한계를 공시하는 것은 [[측정도구-먼저-반증]] 의 저자 자발 실행이다.

## ⚖️ 경계 — 외부축과 혼동하지 말 것

| 구분 | 차이 |
|---|---|
| [[복합지표-분해]] | **하나의 지표**를 성분으로 쪼갠다. 외부축은 **다른 종류의 축**을 추가한다. |
| [[표-부분인용]] | 표의 **유리한 칸만** 인용하는 **인용자** 결함. 외부축은 **저자**의 자발 공시. |
| [[간판-지체]] ②유통형 | 간판이 유리한 수치를 고르는 결함. 외부축은 **본문이 불리한 수치를 더하는** 미덕. |
