# 에이전트 메모리 레이어

> [!insight] 핵심 인사이트
> 2026년 4월 기준, 에이전트 인프라는 **"코어 실행 레이어 + 메모리 레이어"** 2계층 구조로 표준화되고 있다. hermes-agent·superpowers 같은 실행 프레임워크가 정착한 이후, 다음 경쟁은 **어떻게 기억하고 맥락을 유지하는가**로 이동 중.

## 주요 구현체

### 그래프 기반 메모리
- [[cognee]] (⭐15,974) — 6줄 코드 API, 엔티티 관계 그래프로 지식 저장. RAG를 넘어선 구조화된 지식 관리
- 특징: `cognee.add() → cognee.cognify() → cognee.search()` 심플 인터페이스

### 세션 연속성 메모리
- [[claude-mem]] (⭐60,473) — AI가 세션 컨텍스트를 압축해 다음 세션에 주입. Claude Code 전용
- 특징: 수동 CLAUDE.md 관리 자동화, 장기 프로젝트 컨텍스트 유지

### 독립 메모리 시스템 (오픈소스)
- [[MemPalace]] (⭐54,472) — "벤치마크 1위" 주장, 에이전트 장기 기억 특화. 클레임 검증 필요

### 파일시스템 패러다임 통합 컨텍스트 DB (2026-07-12 추가)
- [[OpenViking]] ([[ByteDance]]/Volcengine, ⭐26,604) — 메모리·리소스·**스킬**을 `viking://` 가상 파일시스템으로 통합. **L0/L1/L2 티어드 로딩**으로 토큰 절감 + 벡터·계층 재귀검색 + 관측 가능한 retrieval + 자동 메모리 진화. 평평한 벡터 저장을 "디렉터리 트리"로 대체한 접근으로, [[LLM-Wiki]](index→domain→page 계층)와 구조적 동형 — 순수 그래프([[cognee]])·세션압축([[claude-mem]])과 다른 제3의 축.

### 프레임워크 내장 메모리
- [[openai-agents-python]] — OpenAI 공식 SDK, 에이전트 상태 관리 내장
- [[hermes-agent]] — NousResearch 에이전트, 롤플레이 + 메모리 통합

## 메모리 방식 비교

| 방식 | 구현체 | 장점 | 단점 |
|------|--------|------|------|
| 그래프 DB | cognee | 관계 표현, 복잡 쿼리 | 설정 복잡 |
| 벡터 RAG | all-MiniLM | 빠른 검색 | 관계 정보 손실 |
| 파일 기반 | LLM-Wiki | 투명성, 유연성 | 자동화 부족 |
| 세션 압축 | claude-mem | 즉시 적용 | Claude Code 전용 |
| 파일시스템 패러다임 | OpenViking | 티어드 로딩·관측성·스킬 통합 | AGPLv3 코어 |

### 평가·요건 프레임 (2026-06-25 추가)
- [[Agent-Native-Memory-System]] (HF ↑55, 데일리 최다) — "에이전트 *전용* 메모리가 갖춰야 할 요건을 현재 시스템이 충족하는가"를 점검. 구현체 나열 단계를 넘어 **무엇을 저장/갱신/망각할지**의 평가 잣대를 제시. [[NatureBench]]·[[PlanBench-XL]]의 "에이전트를 *측정*하는 단계로의 이동"과 같은 맥락 — 메모리도 *구현*에서 *평가*로.

### 검색 사각지대 규명 (2026-07-29 추가)
- [[InMind]] (Keep It InMind, USTC·Metastone, 125태스크) — 메모리 레이어의 **근본 실패가 저장이 아니라 검색(retrieval)**임을 규명. 직접 물으면 **최대 100% 회상**하나 **간접 질의 적용은 14.4%**(예: 알레르기 회상 후 곧바로 아몬드 마카롱 추천), 컨텍스트 직접 삽입 시 84% 성공 → *"암묵적 연상 사각지대"*. 이 위키·봇 메모리도 wikilink/grep "직접 매칭"엔 강해도 **암묵적 연결엔 약함** — 완화책은 [[RARG]]식 **관련성 랭킹 + grep 하이브리드**와 능동적 연상 확장. "구현→평가" 프레임을 넘어 **실패 원인의 정밀 국소화** 단계.

## 왜 지금 중요한가

에이전트가 단일 작업을 넘어 **장기 프로젝트, 반복 태스크, 팀 협업**으로 확장되면서 기억 문제가 병목으로 부상. hermes-agent 61K 스타, claude-mem 60K 스타는 모두 "AI가 기억하지 못한다"는 불만에 대한 응답.
