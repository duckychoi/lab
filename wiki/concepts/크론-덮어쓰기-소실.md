# 크론 덮어쓰기 소실 (cron overwrite loss)

크론 리서치 에이전트가 같은 주제를 재생성할 때 **제목이 같으면 파일명이 같아져** 기존 페이지를 **무경고 덮어쓰고**, 그 페이지에 볼트가 누적한 판정·`topic:`·callout·wikilink 가 **조용히 사라지는** 현상.

> [!insight] 🎯 중복은 낭비지만 덮어쓰기는 파괴다
> [[주제재생성-중복]] 은 같은 내용이 여러 파일로 **늘어나는** 문제였다. 이건 반대로 **볼트가 만든 가치가 줄어드는** 문제다. 중복은 `topic:` 키로 사후 정리할 수 있지만, 덮어쓰기는 **그 `topic:` 키 자체를 지운다** ⇒ 중복 판정 장치가 덮어쓰기에 의해 무력화된다.

## 근거 — git 이력으로 확정 (2026-10-24, n=3)

10-17 에는 *"index 1509 ↔ 실측 1514, 노트 7건 배달 ⇒ ≥2건 덮어쓰기"* 라는 **산술 추론**이었다(git 대조 미실시). 금일 `git log` 로 확정했다:

- `리서치-Neural-BeamformingNeural-OperatorSpectral-Diffusion-2026.md` — 128줄(`ad3c5e5`, 볼트 판정 36줄 포함) → **80줄** · 10-18~10-23 사이 **4회 덮어쓰기**
- `리서치-2026년-온디바이스-AI엣지-추론모델-경량화-최신-동향.md` — 93줄(`7ef8844`) → **70줄** · 3회
- `리서치-2026년-AI로봇-주요-학회-CFP-일정-현황.md` — 115줄(`ad3c5e5`, 볼트 판정 32줄 — **CVPR 2027 보존 action 포함**) → **62줄** · 2회
- 배치 내부 소실: raw 항목 **49 → 파일 39** ⇒ **크론 회차 10개**가 같은 배치 안에서 덮어써졌다(볼트 주석은 없었으므로 손실은 크론 본문뿐).

🔴 **특히 3번째가 치명적이었다** — 지워진 구간에 *"CVPR 2027 은 actionable.md 에서만 생존 중"* 이라는 action 이 있었다. **볼트가 경과 마감 문제를 막으려 남긴 메모를 크론이 지웠다.**

## 복구

- ✅ 2026-10-24 세 파일 모두 git 에서 볼트 작성 구간을 원문 복원(`## 🗄️ 이전 회차 볼트 주석` 섹션).
- 📌 **자동 백업(`auto-backup` 일 1회 09:40 커밋)이 유일한 복구 경로**였다 — 커밋 사이에 두 번 덮어쓰면 중간본은 영구 소실된다.

## 규약 (2026-10-24 신설)

1. **크론 노트 인제스트 시 `git log -- <path>` 로 이전 버전 존재 여부를 먼저 본다.** 이전 버전에 `## 🔴 볼트 판정` 이 있으면 복원 후 판정한다.
2. 🔴 **근본 해결은 크론 측**: 파일명에 날짜 접미사(`-YYYYMMDD`)를 붙이거나, 존재 시 append 하도록 수정 요청 — **볼트가 고칠 수 없는 상류 결함이다.**
3. 볼트 판정은 가능하면 **소스 페이지가 아니라 개념·도메인 페이지에 적는다**(덮어쓰기 대상 밖).
