# 벤치 개조 후 재평가

> [!insight] 정의
> **벤더가 외부 벤치마크의 과제를 수정하고, 자기 환경에서 전 베이스라인을 재측정해 보고하는 것.** 이때 그 벤치는 **이름만 외부이고 외부 대조 기능을 상실한다.**
>
> 🎯 핵심은 **"자체 벤치"와 "외부 벤치"의 이분법이 무너진다**는 점이다. 중간 상태가 존재한다: **외부에서 유래했으나 벤더가 손본 벤치.** 📌 독자가 표에서 보는 것은 원래 이름이므로, 이 중간 상태는 **표 층에서 전달되지 않는다.**

## 신설 계기 — [[Qwen3.8-27B]] (2026-10-12)

볼트가 모델카드 전문(65,012 B / 582행)을 열어 각주를 읽었다. 177행 **원문**:

> *"SWE-bench Pro: **Except for Opus4.6 Max, which uses the officially reported score**, all models are evaluated with the **Claude Code harness** at temp=1.0, top_p=0.95, and a 256K context window. **Problematic tasks were corrected, and all baseline models were re-evaluated on the refined benchmark.**"*

🔴 **두 가지가 동시에 벌어졌다:**
1. **벤치 개조** — `Problematic tasks were corrected` + `re-evaluated on the refined benchmark` ⇒ 📌 **보고된 `SWE-bench Pro 61.7` 은 원본 SWE-bench Pro 점수가 아니다.**
2. **측정 주체 혼합** — Opus4.6 Max 만 **공식 보고 점수**, 나머지는 **Qwen 측정** ⇒ → [[비매칭-비교]]

🎯 **그리고 이 수치가 카드에서 가장 강한 주장 중 하나다**: 61.7 은 표 5열 중 최고값이고, 수집기 한줄요약도 *"SWE-bench Pro 61.7 — 표 내 최고값"* 으로 인용했다.

> [!insight] 🏆 개조가 "부정"이라는 뜻은 아니다 — 그러나 대조 기능은 사라진다
> ⚖️ **벤치 과제에 실제 결함이 있을 수 있다.** 📌 SWE-bench 계열은 과제 품질 문제가 공개적으로 논의되는 벤치이고, **수정 자체는 학술적으로 정당할 수 있다.**
> 🔴 **그럼에도 비교 해석은 달라진다**:
> - 수정 기준을 **벤더가 정했다** — 어떤 과제를 "problematic" 으로 볼지가 결과에 영향을 준다.
> - **수정 내역이 공개되지 않았다** — 몇 개를, 어떤 기준으로 고쳤는지 카드에 없다.
> - 외부 리더보드 점수와 **직접 비교 불가**해졌다.
> ⇒ 📌 **판정: 부정이 아니라 "독립 대조 상실"이다.** ✅ **그리고 카드는 이 사실을 각주에 명시했다** — 숨기지 않았다. 🔴 **문제는 표에 이름만 나온다는 것이다.** → [[한정어-탈락]]

## 🎯 정량적 귀결 — [[분포내-우위]] 와 결합하면 구조가 보인다

볼트가 Opus4.6 Max 열 기준으로 격차를 계산했다([[Qwen3.8-27B]] 10-12 갱신분):

| 벤치 성격 | 벤치 | Qwen3.8-27B − Opus4.6 Max |
|---|---|---:|
| **자체**(in-house) | QwenSWEBench | 🟢 **+15.2p** |
| **자체**(in-house) | CoWorkBench | 🟢 +2.5p |
| **개조된 외부** | SWE-bench Pro | 🟢 +8.3p |
| **외부(원형)** | Terminal Bench 2.1 | 🔴 **−5.2p** |
| **외부(원형)** | NL2Repo-Bench | 🔴 **−5.3p** |
| **외부(원형)** | HLE | 🔴 **−9.2p** |

🎯 ⇒ **벤치의 "벤더 통제도"가 높을수록 우위가 크고, 낮을수록 부호가 뒤집힌다.** 📌 **개조된 외부 벤치(+8.3p)가 정확히 자체(+15.2p)와 외부 원형(−5.2p) 사이에 놓인다.**
⚖️ **표본이 작아 단정하지 않는다** — 그러나 **"중간 상태"라는 개념 설정과 수치 위치가 일치하는 것은 기록할 만하다.**

## 볼트 규약

1. 🔴 **벤치 각주를 읽지 않고 표 수치를 인용하지 않는다.** 📌 금일 사례는 **각주에만** 적혀 있었다.
2. 🔴 **벤치를 3분류한다**: **자체**(in-house) / **개조된 외부**(벤더 수정·재측정) / **외부 원형**(공식 점수 또는 중립 측정).
3. 📌 **개조된 외부 벤치를 인용할 때 반드시 병기한다**: *"Qwen 정제판 · Claude Code 하네스 · Opus4.6 Max만 공식점수"*.
4. ⚖️ **모델 선택 근거에는 "외부 원형" 만 쓴다.**

> [!warning] 🔴 한계
> - **표본 1건**([[Qwen3.8-27B]] / SWE-bench Pro).
> - ⬜ **원본 SWE-bench Pro 리더보드 점수를 볼트가 조회하지 않았다** — 개조 전후 차이를 **정량화하지 못했다.** 📌 이것이 가장 큰 공백이고, 해소 경로는 **공식 리더보드 1회 조회**다.
> - ⬜ **다른 벤더 카드에도 같은 서술이 있는지 전수 확인하지 않았다.** 볼트 보유 모델카드 재검토 대상.
> - ⬜ "개조된 외부가 중간값" 관측은 **n=1** 이다. 우연일 수 있다.
