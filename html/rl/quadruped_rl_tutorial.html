읽기 전에 — 사족보행 RL 한 줄 요약

튜토리얼 본문에 들어가기 전, 이 문서 전체를 관통하는 세 가지 핵심 개념을 짚고 갑니다. 아래 개념들이 본문의 모든 방법의 "왜 그렇게 짰는지"를 설명합니다.

① Sim-to-Real & Domain Randomization

사족보행 RL의 가장 큰 난제. 시뮬레이터는 실제 지형·마찰·지연·하중을 정확히 모름. 그래서 학습 때 물리 파라미터를 무작위로 흔들(domain randomization)어, 정책이 어떤 환경에서도 견디도록 만듭니다.

본문 대부분 방법이 proprioceptive(관절·IMU만) 관측을 쓰는 이유 — 비전·외부 센서 없이도 흔들리는 환경에 robust하려면 내부 표현을 잘 배워야 하니까요.

② PPO (rsl_rl / legged_gym) — 사실상 표준

PPO가 quadruped RL의 뼈대. ETH Zurich의 rsl_rl·legged_gym 프레임워크가 사실상 표준이라, 본문 11개 중 8개가 이 위에서 돕니다. 공식: clip=0.2, γ=0.99, GAE λ=0.95, adaptive KL LR(desired KL=0.01).

actor/critic MLP [512,256,128] ELU가 기본 구성. 그룹 A·B·D가 모두 PPO 기반이고, 그룹 C도 diffusion 위에 PPO를 얹습니다.

③ Teacher-Student · 비대칭 Actor-Critic

학습할 때는 teacher(특권 정보: 지형·속도·외력)를 보는 크리틱으로 학습하고, 실행할 때는 student(proprio만) 액터로 배포하는 구조. 그룹 A(SLR·HIMLoco·TAR)의 공통 뼈대.

왜? 특권 정보로 빠르게 학습하되, 배포는 센서 없이 해야 하니까. 표현 학습은 '특권 정보를 proprio만으로 복원하는 압축'으로 해석할 수 있습니다.

이 문서의 약속. 각 방법 카드는 ① 직관(초보자용 비유) → ② RL 방법(네트워크·학습 신호) → ③ 핵심 기여 → ④ 실제 코드 네 블록으로 구성됩니다. 코드 블록의 초록 헤더는 실제 파일 경로이고, 본문은 해당 파일에서 발췌한 원문입니다(일부 라인 생략).
범위 안내. 원본 허브는 20개 방법을 다루지만, 이 튜토리얼은 공개 코드가 확보된 11개만 다룹니다. 나머지 9개(ANYmal Parkour·SET·ULT·Parkour-in-the-Wild·GPO·Neuromorphic·DreamWaQ++·PUMA·REAL)는 GitHub 코드가 비공개라 원문 코드 발췌가 불가해 제외했습니다. Bio-inspired Gait는 학습 코드 미공개지만 추론 정책·스케줄러 코드가 공개돼 포함했습니다.

표현학습 · Proprioceptive → Latent

비전·특권 센서 없이 고유감각(proprioceptive) 관측 히스토리만으로 환경을 이해하는 잠재표현 z를 학습하는 계열. sim-to-real 격차(지형·마찰·지연을 시뮬레이션처럼 정확히 모를 때)를 극복하기 위해, 자기지도·대조학습(contrastive)으로 표현을 다듬어 정책에 먹입니다. quadruped RL에서 가장 활발한 흐름입니다.

HIMLoco (Hybrid Internal Model) A

① 직관 — 한 줄로 이해하기

로봇이 proprio만으로 자기 속도와 '지금 밟고 있는 지형의 종류'를 contrastive prototype으로 배운다. 시뮬레이터가 알려주지 않아도 환경을 내부에서 모델링해 sim-to-real 격차를 극복.

② 강화학습 방법 — 어떻게 학습하나

HIMPPO + HIMEstimator. 인코더가 obs_history(6스텝)에서 base 속도(3)와 latent(16)를 동시 추정. SwAV 방식 — 32개 prototype 임베딩과 inner product로 score, sinkhorn으로 균등 할당(q)을 만들고 cross-assignment swap loss + 속도 MSE를 결합. L2 정규화된 표현.

③ 핵심 기여
  • SwAV/sinkhorn contrastive 내부모델 — 특권정보 없는 표현 학습
  • prototype 32개로 지형·상황을 이산적 클러스터로 모델링
  • 속도 추정 부수 보너스(estimation_loss)로 proprio만으로 base vel 복원

class HIMEstimator(nn.Module):
    def __init__(self,
                 temporal_steps,
                 num_one_step_obs,
                 enc_hidden_dims=[128, 64, 16],
                 tar_hidden_dims=[128, 64],
                 activation='elu',
                 learning_rate=1e-3,
                 max_grad_norm=10.0,
                 num_prototype=32,
                 temperature=3.0,
                 **kwargs):
        if kwargs:
            print("Estimator_CL.__init__ got unexpected arguments, which will be ignored: " + str(
                [key for key in kwargs.keys()]))
        super(HIMEstimator, self).__init__()
        activation = get_activation(activation)

        self.temporal_steps = temporal_steps
        self.num_one_step_obs = num_one_step_obs
        self.num_latent = enc_hidden_dims[-1]
        self.max_grad_norm = max_grad_norm
        self.temperature = temperature

        # Encoder
        enc_input_dim = self.temporal_steps * self.num_one_step_obs
        enc_layers = []
        for l in range(len(enc_hidden_dims) - 1):
            enc_layers += [nn.Linear(enc_input_dim, enc_hidden_dims[l]), activation]
            enc_input_dim = enc_hidden_dims[l]
        enc_layers += [nn.Linear(enc_input_dim, enc_hidden_dims[-1] + 3)]
        self.encoder = nn.Sequential(*enc_layers)

        # Target
        tar_input_dim = self.num_one_step_obs
        tar_layers = []
        for l in range(len(tar_hidden_dims)):
            tar_layers += [nn.Linear(tar_input_dim, tar_hidden_dims[l]), activation]
            tar_input_dim = tar_hidden_dims[l]
        tar_layers += [nn.Linear(tar_input_dim, enc_hidden_dims[-1])]
        self.target = nn.Sequential(*tar_layers)

        # Prototype
        self.proto = nn.Embedding(num_prototype, enc_hidden_dims[-1])

        # Optimizer
        self.learning_rate = learning_rate
        self.optimizer = optim.Adam(self.parameters(), lr=self.learning_rate)

    def get_latent(self, obs_history):
        vel, z = self.encode(obs_history)
        return vel.detach(), z.detach()

    def forward(self, obs_history):
        parts = self.encoder(obs_history.detach())
        vel, z = parts[..., :3], parts[..., 3:]
        z = F.normalize(z, dim=-1, p=2)
        return vel.detach(), z.detach()

    def encode(self, obs_history):
        parts = self.encoder(obs_history.detach())
        vel, z = parts[..., :3], parts[..., 3:]
        z = F.normalize(z, dim=-1, p=2)
        return vel, z

    def update(self, obs_history, next_critic_obs, lr=None):
        if lr is not None:
            self.learning_rate = lr
            for param_group in self.optimizer.param_groups:
                param_group['lr'] = self.learning_rate
                
        vel = next_critic_obs[:, self.num_one_step_obs:self.num_one_step_obs+3].detach()
        next_obs = next_critic_obs.detach()[:, 3:self.num_one_step_obs+3]

        z_s = self.encoder(obs_history)
        z_t = self.target(next_obs)
        pred_vel, z_s = z_s[..., :3], z_s[..., 3:]

        z_s = F.normalize(z_s, dim=-1, p=2)
        z_t = F.normalize(z_t, dim=-1, p=2)

        with torch.no_grad():
            w = self.proto.weight.data.clone()
            w = F.normalize(w, dim=-1, p=2)
            self.proto.weight.copy_(w)

        score_s = z_s @ self.proto.weight.T
        score_t = z_t @ self.proto.weight.T

        with torch.no_grad():
            q_s = sinkhorn(score_s)
            q_t = sinkhorn(score_t)

        log_p_s = F.log_softmax(score_s / self.temperature, dim=-1)
        log_p_t = F.log_softmax(score_t / self.temperature, dim=-1)

        swap_loss = -0.5 * (q_s * log_p_t + q_t * log_p_s).mean()
        estimation_loss = F.mse_loss(pred_vel, vel)
        losses = estimation_loss + swap_loss

        self.optimizer.zero_grad()
        losses.backward()
        nn.utils.clip_grad_norm_(self.parameters(), self.max_grad_norm)
        self.optimizer.step()

        return estimation_loss.item(), swap_loss.item()


@torch.no_grad()
def sinkhorn(out, eps=0.05, iters=3):
    Q = torch.exp(out / eps).T
    K, B = Q.shape[0], Q.shape[1]
    Q /= Q.sum()

    for it in range(iters):
        # normalize each row: total weight per prototype must be 1/K
        Q /= torch.sum(Q, dim=1, keepdim=True)
        Q /= K

        # normalize each column: total weight per sample must be 1/B
        Q /= torch.sum(Q, dim=0, keepdim=True)
        Q /= B
    return (Q * B).T

① 직관 — 한 줄로 이해하기

선생(teacher)이 특권 정보(지형·속도)로 배운 표현을, 학생(student)이 proprio 히스토리만으로 모방하도록 대조(contrastive) 정렬해 가르친다. 비전/특권 센서 없이도 견고한 sim-to-real.

제약·안전 PPO (Safe Locomotion)

PPO에 안전 제약(constraint)을 얹어, 위험한 행동(전복·과토크·충돌)을 억제하면서도 목표(속도·위치) 추종을 놓치지 않는 계열. 핵심은 제약을 보상 페널티로 다루느냐(ABS) vs 확률적 종료로 변환하느냐(CaT). 동적 보행에서 '안전'의 정의를 RL 친화적으로 재구성한 것이 차별점입니다.

17

CaT (Constraints as Terminations) B

안전·제약 · ★166
① 직관 — 한 줄로 이해하기

안전 규칙(전복 금지, 토크 한계 등)을 어기면 보상에서 점수를 깎는 대신, 그 스텝을 '확률적으로 종료'시킨다. 할인된 리턴 안에서 제약이 암묵적으로 페널티화돼, 복잡한 보상 가중치 튜닝 없이 안전을 보장한다.

② 강화학습 방법 — 어떻게 학습하나

CleanRL PPO + constraint_manager. 위반 확률 p를 running-max Polyak(τ=0.95)으로 worst-case 추적, 보상을 r·(1−p)로 클리핑. 토크·속도·action-rate·air-time 등 기존 페널티를 보상에서 제거하고 제약으로 이동 — 최종 보상은 속도 추종 항 2개만 남음. 커리큘럼으로 p 상한 점진 강화.

③ 핵심 기여
  • 제약 위반 → termination 변환(penalty-free 안전 보장)
  • running-max Polyak(τ=0.95)으로 worst-case 위반 추적
  • 보상 단순화(추종만)로 보상 해킹·가중치 튜닝 부담 제거

    def add(self, name: str, constraint: torch.Tensor, max_p: float = 0.1):
        """Add and process a constraint violation."""
        # Ensure constraint is on the correct device and properly shaped
        if constraint.device != self._device:
            constraint = constraint.to(self._device)
            
        # Convert to float if needed and ensure proper shape
        if not torch.is_floating_point(constraint):
            constraint = constraint.float()
        if constraint.ndim == 1:
            constraint = constraint.unsqueeze(1)

        # Store raw constraints
        self.raw_constraints[name] = constraint

        # Compute constraint max with clamping for numerical stability
        constraint_max = constraint.max(dim=0, keepdim=True)[0].clamp(min=1e-6)

        # Update running max using in-place operations when possible
        if name in self.running_maxes:
            self.running_maxes[name].mul_(self.tau).add_((1.0 - self.tau) * constraint_max)
        else:
            self.running_maxes[name] = constraint_max

        # Pre-allocate probability tensor
        probs = torch.zeros_like(constraint)
        
        # Compute mask of violations only once
        mask = constraint > 0.0
        if mask.any():
            # Compute normalized violations with broadcasting
            normalized = constraint / self.running_maxes[name].expand_as(constraint)
            # Compute probabilities only for violating samples
            probs[mask] = self.min_p + torch.clamp(normalized[mask], 0.0, 1.0) * (max_p - self.min_p)

        self.probs[name] = probs
        self.max_p[name] = torch.full((constraint.shape[1],), max_p,
                                    dtype=torch.float, device=self._device)

이 코드가 보여주는 것: constraint_manager — 위반 확률 p의 running-max 추적과 r·(1−p) 보상 클리핑이 CaT의 핵심.

Bio-inspired Gait D

계층·민첩 · ★22
① 직관 — 한 줄로 이해하기

동물이 속도에 따라 걸음걸이를 바꾸듯(걷기→조깅→뛰기), Froude 수로 보행 양식을 자동 선택하는 생체모방 스케줄러가 사전학습된 두 MLP 정책(이동·보행선택)을 조종한다.

② 강화학습 방법 — 어떻게 학습하나

규칙 기반 gait scheduler + 사전학습 MLP 정책(추론만). Froude 수 Fr=v²/gh로 보행 양식 결정, Fr 경계(fr_bounds, 예 TROT 0.152–0.74, RUN 0.74–1.5)를 넘으면 보행 인덱스 ±1. 전이 길이 B=round((L+L_next)/2·e^(−2Fr))로 블렌딩. 두 정책 모두 MLP [512,256,128] LeakyReLU. 학습 코드는 미공개(가중치만 배포).

③ 핵심 기여
  • Froude 수 기반 생체모방 보행 자동 전환(걷기/트롯/런)
  • 규칙 기반 스케줄러로 RL 정책 위계 제어(계층적)
  • proprioceptive 전용 — 외부 지각 센서 불필요

// src/learning_to_adapt/gait_scheduler.cpp (lines 832-854)
void GaitScheduler::calcTransParams() {
    float trans_coeff = 0.2;
    
    // Shift up gait transition parameters
    // linear
    if (trans_mode_ == "SYNC"){
        data_.B = ((data_.L + dataNext_.L)/2)*trans_coeff;
    }
    // bio
    if (trans_mode_ == "BIOSYNC"){
        data_.C = abs(1 - (fr/1.)) * data_.Cmax;
        data_.B = round(((data_.L + dataNext_.L)/2) * data_.C);
        
    }
    // bio static
    if (trans_mode_ == "BIOSYNCSTATIC"){
        data_.C = exp(-2*fr);
        data_.B = round(((data_.L + dataNext_.L)/2) * data_.C);
    }
    if (data_.gait_name == "STAND" or dataNext_.gait_name == "STAND") {
        data_.B = 1;
    }
}

특권 정보 없이 robust 보행

→ SLR(15)(triplet 자기지도) · HIMLoco(03)(SwAV contrastive) · TAR(07)(teacher 정렬). 비전·특권 센서 없이 proprio만으로 지형 적응. sim-to-real이 핵심일 때.

안전 제약이 중요한 환경

→ CaT(17)(제약→종료 변환) 또는 ABS(02)(Lagrangian cost). 전복·충돌·과토크를 절대 피해야 하는 실기체 배포.

멀티모달·다중 스킬 보행

→ DiffuseLoco(04)(오프라인 BC) · locodiff(13)(return조건) · Multi-Loco(10)(EDM+PPO imitation) · DMLoco(14)(UNet+DPPO). 같은 상태에서 여러合理적 행동이 필요할 때.

도전적 지형 · parkour

→ SoloParkour(05)(gap/jump/hurdle/crawl). 평지를 넘어선 장애물 통과가 목표일 때. 2-stage(privileged→vision) distillation.

속도별 보행 자동 전환

→ Bio-inspired Gait(16)(Froude 수 스케줄러). 걷기/트롯/런을 동물처럼 자동 전환. 규칙 기반 위계 제어가 학습보다 효율적일 때.

오프라인 데이터로만 학습

→ DiffuseLoco(04) 또는 locodiff(13). 시뮬레이터 없이 기존 궤적 로그만으로 정책 학습. 실로봇 안전 학습에 유리.
