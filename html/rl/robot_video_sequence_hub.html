OpenGVL을 LeWM PushT에 붙이는 최소 실험 설계

구현 코드는 원본 le-wm/ baseline을 직접 수정하지 않고, 별도 sibling 디렉터리 le-wm-opengvl/에서 관리한다.

1. PushT frame exportLeWM dataset에서 episode/window를 뽑아 ordered context frames와 shuffled eval frames를 저장한다.
2. OpenGVL teacherVLM에 task instruction과 shuffled frames를 넣고 frame별 completion %를 얻는다.
3. Temporal head distillLeWM의 emb 위에 작은 Transformer/MLP head를 붙여 progress, order, reject를 학습한다.
4. Policy/world-model 사용progress는 reward/value, reject는 bad trajectory filtering, order는 latent temporal consistency loss로 사용한다.

첫 구현 단위

loss = lewm_pred_loss + lambda_sigreg * sigreg
if temporal_aux.enabled:
    progress_loss = mse(progress_head(emb_t), opengvl_completion_t)
    reject_loss = bce(reject_head(emb_t), is_out_of_sequence_t)
    order_loss = pairwise_ranking(progress_i, progress_j, sign(t_i - t_j))
    loss += w_progress * progress_loss + w_reject * reject_loss + w_order * order_loss

실험 우선순위

1순위: OpenGVL teacher distillation

질문한 shuffled frame ordering과 completion scoring이 정확히 들어 있고, 코드/HF Space가 공개되어 있다. LeWM PushT에 붙일 때도 기존 JEPA loss를 유지하고 auxiliary만 추가하면 된다.

2순위: V-JEPA 2/2.1 encoder teacher

order matching은 아니지만 dense temporal/predictive representation이 강하다. PushT frame embedding teacher 또는 surprise detector로 쓸 수 있다.

3순위: policy에 직접 결합

OpenVLA/Octo/SmolVLA 같은 정책에 바로 넣기보다, 먼저 dataset filtering/reward head로 검증한 뒤 policy fine-tuning에 반영하는 편이 안전하다.
