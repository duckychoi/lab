1. AI-native 빔포밍 재발명 — 6단계 사다리

빔포밍은 1960~70년대(MVDR·WMMSE) 사람이 손으로 유도한 모델 기반 알고리즘. "AI가 얼마나 깊이 침투하느냐"로 재발명 단계를 사다리로:

  1. 솔버만 교체 — CNN/LSTM이 CSI→가중치 매핑. 목적함수 그대로.
  2. 알고리즘 언폴딩 — WMMSE를 신경망 레이어로 펼침(+GNN).
  3. 엔드투엔드 재정의 — Neural Beamforming Transformer(NBT, 2026), 안테나 전압→가중치 직접, 보편근사 증명.
  4. 목적함수 재발명 ⭐ — SINR 대신 task/semantic/ISAC 성능 직접 최적화.
  5. 하드웨어 공동설계 — 배열 기하·sparse array·RIS/메타표면 역설계.
  6. AI 알고리즘 발견 🔥 — AlphaEvolve/FunSearch가 무선 알고리즘 자율 발견(2026).

레버리지: (1) 사람이 그은 블록 경계(채널추정→빔포밍→스케줄링→센싱)를 녹여 joint 설계, (2) "무엇을 최적화하나"를 SINR→과제가치로. 물리(Maxwell)는 하드 제약 → physics-informed가 스윗스팟.

2. 플래그십 A — VF-MoNBT (아키텍처 융합)

Volumetric-Focusing Mixture-of-experts Neural Beamforming Transformer

NBT + CAT-MoEformer + 멀티빔 동시조준 + Volumetric Beam Focusing. 네 조각이 직교 축이라 스택 가능:

  • NBT = 엔진(How) — 가중치 계산
  • MoE = 선택기(Which) — "전문가=초점" 몇 개 켤까(가변 K)
  • 멀티빔 = 출력 구조(What) — K개 빔 + 빔간 널링
  • Volumetric = 출력 기하(Where) — 근거리장 3D 점 집속(진짜 "점 조준")

신규성: DETR/TAPNet식 포커스 쿼리 토큰으로 멀티빔 set-prediction + MoE 전문가=초점. 넷 동시 융합은 미발표. 블루오션: 통신학회가 아니라 로봇-센싱·온디바이스.

3. 플래그십 B — 공간 슈퍼트위스팅 개구 (이론 융합)

SMC/슈퍼트위스팅의 이론 구조 자체를 빔합성 수식에 내재. (응용 아님: 빔의 정적 공간장이 SMC 구조법칙으로 합성)

통일 원리 — "설계된 불연속/특이점 = 강인성"
SMC는 시간축의 sign(s) 스위칭으로, 빔은 공간축의 1-bit 코딩 = sign(cosΦ)·OAM 위상특이점·급격자동집속(유한거리)으로 — 같은 수학.

1-bit 양자화 로브 유도

ULA, 이상 가중치 $a(n)=e^{j\Phi(n)},\ \Phi(n)=\omega_0 n$. 순진 1-bit $c(n)=\mathrm{sign}(\cos\Phi(n))$. 사각파 푸리에:

$$\mathrm{sign}(\cos\psi)=\frac{4}{\pi}\sum_{m\ge0}\frac{(-1)^m}{2m+1}\cos((2m+1)\psi)$$

3차 고조파 로브 진폭비 $=1/3$ → $L_\text{quant}=20\log_{10}\tfrac13\approx-9.5$ dB. 원인: 메모리 없는 sign의 양자화 오차가 메인빔 근방에서 셰이핑되지 않음 = SMC의 채터링.

rev2 확인:

  • 이 오차는 백색이 아니라 고조파 톤이다.
  • 일반 각도에서 −8.9~−9.4 dB 가 재현된다.
  • θ0=30°(d=λ/2)는 $4\omega_0\in2\pi\mathbb{Z}$ 라 3차 로브가 미러빔에 겹치는 퇴화 각도다.
  • 실수 ±1 출력은 임계값과 무관하게 $AF(-\omega)=AF(\omega)^*$ 이므로 미러빔을 없애려면 복소 출력 코드가 필요하다.

슈퍼트위스팅 = 2차 슬라이딩 변조기 (가설)

연속 STA: $\dot\sigma=-k_1|\sigma|^{1/2}\mathrm{sign}(\sigma)+z,\ \dot z=-k_2\mathrm{sign}(\sigma)$. 개구를 "시간"으로 보고 명시적으로 갱신한다(실수 목표 $x=\mathrm{amp}\cdot\mathrm{Re}\,a$):

u(n)=x(n)-k1|σ(n-1)|^{1/2}sign(σ(n-1))+z(n-1)   # rev2 정정: rev1 의 -z 는 양의 피드백
c(n)=sign(u(n))
σ(n)=σ(n-1)+(c(n)-x(n))
z(n)=z(n-1)-k2·sign(σ(n))                        # "NTF ≈ (1-z⁻¹)²" 주장은 미검증

왜 슈퍼트위스팅인가(rev1 논거): 선형 2차 ΔΣ는 불안정·톤 위험이 있다. 분수멱 $|\sigma|^{1/2}$이 유한스텝 수렴 + 리야프노프 안정을 준다(게인 $k_1=1.5\sqrt L,\ k_2=1.1L$).
rev2: 이것은 연속시간 성질이며 1-bit·조향빔 루프에서는 미검증이다. 부호를 고친 루프도 문서 게인에서는 메인보다 큰 로브(조향점 대비 +3~+14 dB)를 낸다.

노이즈 셰이핑 (정량)

$$P_\text{in}(p)\approx\frac{\sigma_e^2}{\pi}\,K^{2p}\,\frac{\Omega_b^{\,2p+1}}{2p+1}\quad\Rightarrow\quad p{=}0:\Omega_b,\ p{=}1:\Omega_b^3,\ p{=}2:\Omega_b^5\ (\text{점근})$$

정정(rev2):

  • $(1-z^{-1})^p$ 의 영점은 broadside($\omega=0$)이며 $K=1$ 이다.
  • 조향빔에는 영점을 $\pm\omega_0$ 에 둔 대역통과 NTF 가 필요하다: $$H_p(z)=\left(\frac{1-2\cos\omega_0 z^{-1}+z^{-2}}{1-2r\cos\omega_0 z^{-1}+r^2z^{-2}}\right)^p$$ ($r=0$ 이면 극점 없는 다항식). 이때 $\Omega=\omega-\omega_0$, $K=2|\sin\omega_0|/[(1-r)|1-re^{-2j\omega_0}|]$ 이다. 예: θ0=23.7°, p=2, r=0.7 이면 $K^4\approx235$ 이고, 대역 $\Omega_b\in[0.02,0.16]$ 에서의 정확한 기울기는 4.88 이다(r=0 이면 5.00).
  • 저역형은 $\sin\theta_0>1/3$ 이면 같은 내부 오차에 대한 메인빔 노이즈 이득이 1 을 넘는다. p=0 대비 실측은 오차 분산 차이까지 넣어야 한다(25° 는 −2.7 dB, 45° 는 +1.6 dB).
  • 전제: 백색 오차(디더를 넣었을 때의 조건부 근사)와 $\Omega_b\gg2\pi/N$. 실제 대역에서의 기울기는 NTF 를 정확히 적분한 값(p=2 → 4.88)이다.
  • 균일 개구에서는 누설 때문에 고차 기울기가 깎인다(N 의존).

앵커: 1-bit 개구 ≡ 디지털 하프토닝, ΔΣ ≡ 오차확산, 슈퍼트위스팅 ≡ 강인 2차 오차확산(가설).

⚠️ rev2(2026-10-19) 시뮬 결과(note/sim/NOTES.md, codex 교차검증 반영):
· 확인: −9.5 dB 로브. 대역통과 1차는 메인 근방 잔차가 명목 목표 톤 전력 대비 −44~−50 dB, 2차(r=0.7) 기울기는 4.82~4.90 으로 예측 4.88 과 일치(Hann).
· 정정: 저역 NTF 영점 위치, rev1 dsm2 선형 모델의 불안정 극점(−1.618), STA 의 z 부호, 0 dB 에서 잘리던 피크 지표.
· 한계: d=λ/2 에서 보호대역 밖 피크 로브는 거의 개선되지 않음(N=64 악화, N=256 약 2.1~2.3 dB).
· 미검증: 슈퍼트위스팅의 우위(대역통과형 미정식화).

4. 물리적으로 꼬인/미끄러지는 빔

  • TWIST = OAM 보텍스 — 나선 위상 $e^{j\ell\varphi}$, 토폴로지 전하 $\ell$, 모드분할다중화. ISAC×OAM(2026.9).
  • SLIDE = Airy/FDA — Airy 자기가속·자가치유, 급격자동집속(유한거리), FDA 거리-시간 의존 초점.

갱신식 vs loss: 다른 객체지만 슬라이딩 변수 $s:=\nabla_w J$로 두면 슈퍼트위스팅이 유한시간·강인 최적화기 자체("SMC as optimization").
정직한 한계: OAM은 원거리 P2P 용량에서 MIMO를 못 이김 → "강인성·ISAC·다중화 단순화"로 포지셔닝.

5. 스펙트럴 편향 × 디퓨전 × 빔스페이스

코디네이트 MLP의 스펙트럴 편향(F-principle): 저주파 먼저 학습(NTK 고유값이 주파수로 감소). Fourier features가 이를 깸(Tancik 2020).

디퓨전 = 스펙트럴 자기회귀(Dieleman): 백색노이즈+1/f² 통계로 고주파가 먼저 묻히고 저→고 복원. 릴스의 "저주파 먼저"와 같은 골격.

미개척 블루오션 — 빔스페이스 생성 사전확률: 어레이=공간 푸리에 도메인. 채널/CSI 생성·초해상, RIS/메타표면 패턴 생성, 근거리장 집속 필드 생성. 플래그십 B(1-bit 로브 셰이핑)에 스펙트럴 제약 디퓨전 사전확률 결합 → 신규.
