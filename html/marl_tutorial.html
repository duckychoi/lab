읽기 전에 — 멀티에이전트 RL 한 줄 요약

튜토리얼 본문에 들어가기 전, 이 문서 전체를 관통하는 세 가지 핵심 개념을 짚고 갑니다. 아래 개념들이 본문의 모든 방법의 "왜 그렇게 짰는지"를 설명합니다.

① CTDE — 중앙 학습, 분산 실행

멀티에이전트 RL의 가장 흔한 구조. 학습할 때는 전체 정보(다른 에이전트 관측·전역 상태)를 다 보는 크리틱/가이더를 쓰고, 실행할 때는 각 에이전트가 자기 관측만 보고 혼자 결정합니다.

왜? 협력의 신용(credit)을 나누려면 전체를 봐야 하지만, 실제 배포는 각자 독립적으로 해야 효율적이니까요. 본문 거의 모든 방법이 CTDE입니다.

② PPO vs QMIX — 두 갈래 학습 신호

PPO(정책경사): 정책(행동 확률)을 직접 학습. "더 좋은 보상을 낸 행동의 확률을 올리자." on-policy(현재 정책이 만든 데이터로만 학습). 그룹 A·C·D의 뼈대.

QMIX(가치분해): 행동의 가치(Q)를 학습. "가장 가치 높은 행동을 고르자." off-policy라 replay buffer로 과거 경험 재사용. 그룹 B의 뼈대.

③ 단조성(monotonicity) — 가치를 쪼개는 규칙

가치분해(B 그룹)의 핵심 제약. 개별 에이전트 가치 Qi가 오르면 팀 가치 Qtot도 무조건 오르게 만듭니다. 그래야 각자 따로 학습해도 팀 목표와 싸우지 않습니다.

QMIX는 믹서의 가중치를 양수로 제약해 이를 보장합니다(∂Qtot/∂Qi≥0, IGM 조건).

QMIX 단조 믹서
\[ Q_{tot}=f\!\left(\sum_i w_i(s)\,Q_i\,;\ b(s)\right),\quad w_i(s)\ge 0 \]
가중치 wi를 abs()로 양수화해 단조성 보장. Qtot가 Qi에 대해 단조증가 → 개별·팀 학습 정렬.
이 문서의 약속. 각 방법 카드는 ① 직관(초보자용 비유) → ② RL 방법(네트워크·학습 신호) → ③ 핵심 기여 → ④ 실제 코드 네 블록으로 구성됩니다. 코드 블록의 초록 헤더는 실제 GitHub 파일 경로이고, 본문은 해당 파일에서 발췌한 원문입니다(일부 라인 생략, 한국어 주석은 이해를 돕기 위한 보조 설명).
그룹 A

Actor-Critic · 정책경사 (PPO 계열)

각 에이전트가 직접 정책(행동 확률)을 학습하는 on-policy 계열. PPO를 뼈대로 삼아, 트랜스포머/순환망으로 에이전트 간 순서를 모델링하거나 중앙 크리틱으로 신용을 분배하는 식으로 멀티에이전트를 다룹니다. 이 그룹의 공식: 각 에이전트가 자기 관측만 보고 행동하되(분산 실행), 학습 때는 더 많은 정보를 보는 크리틱/가이더가 돕습니다(중앙 학습).

MAGPO A

arXiv 2025 · ★9
① 직관 — 한 줄로 이해하기

'코치(guider)'가 연습 때 전체 상황을 보며 선수(분산 정책)에게 좋은 행동을 시범 보이고, 선수는 코치를 따라가며 배운다. 시합(실행) 땐 선수 혼자 뛴다.

② 강화학습 방법 — 어떻게 학습하나

PPO를 뼈대로 한 Guided Policy Optimization. 중앙집중 Sable 가이더(전체 에이전트 obs를 시퀀스로 보는 RetNet 트랜스포머)와 분산 RNN 액터 두 정책을 함께 학습. 가이더 손실에 double-clipped ratio(log-ratio를 ±log(clip_gpo)로 제한)를, 액터 손실에 표준 PPO + guider KL 정렬 항을 넣어 중앙↔분산 표현 격차를 좁힘.

③ 핵심 기여
  • double-clipped GPO 손실 — 가이더와 액터의 log-ratio 폭주를 막아 안정적 정렬
  • KL 마스크로 클립 범위를 넘은 표본에만 페널티
  • CTDE를 양방향 KL로 명시적 연결(중앙 학습↔분산 실행)

# Double clip: 가이더와 액터의 log-ratio를 [1/clip_gpo, clip_gpo]로 제한
clipped_ratio = jnp.exp(
    jnp.clip(
        guider_log_prob - actor_log_prob,
        jnp.log(1 / config.system.clip_gpo),
        jnp.log(config.system.clip_gpo),
    )
    + actor_log_prob
    - traj_batch.log_prob
)
# 가이더-액터 괴리가 클립 범위를 넘은 표본만 KL로 페널티
mask = jnp.select(
    [guider_log_prob - actor_log_prob < jnp.log(1 / config.system.clip_gpo),
     guider_log_prob - actor_log_prob > jnp.log(config.system.clip_gpo)],
    [1, 1], 0)
kl_loss = (kl_loss * mask).mean()
gae = (gae - gae.mean()) / (gae.std() + 1e-8)
guider_loss1 = ratio * gae
guider_loss2 = jnp.clip(clipped_ratio, 1.0 - config.system.clip_eps,
                        1.0 + config.system.clip_eps) * gae
guider_loss = -jnp.minimum(guider_loss1, guider_loss2).mean()
total_loss = (guider_loss + kl_loss
              - config.system.ent_coef * guider_entropy
              + config.system.vf_coef * value_loss)

Sable A

① 직관 — 한 줄로 이해하기

에이전트들을 한 명씩 차례로(자기회귀) 처리하는 트랜스포머. 단, 일반 attention 대신 Retention(RetNet)을 써서 에이전트 수·시간이 길어져도 비용이 선형으로 든다.

② 강화학습 방법 — 어떻게 학습하나

인코더(전체 관츰 처리) + 디코더(행동을 에이전트 순서대로 자기회귀 생성) 구조. PPO의 MAT식 어드밴티지 분해를 그대로 쓰되, attention 대신 MultiScaleRetention(masked 디코더)으로 교체. chunkwise 메모리가 시간축까지 이어붙여 수백 에이전트·장기 기억을 선형 비용으로 처리.

③ 핵심 기여
  • Retention(RetNet) 기반 MARL 백본 — attention의 O(n²)를 선형으로
  • chunkwise 메모리로 시간×에이전트 시퀀스를 선형 비용 처리
  • 학습=병렬/청크, 실행=recurrent 모드 전환(분산 배포 효율)

# mava/networks/sable_network.py (lines 188-217, DecodeBlock.__call__)
def __call__(self, x, obs_rep, hstates, dones, step_count):
    """Chunkwise MultiScaleRetention 적용 (디코더 블록)."""
    hs1, hs2 = hstates
    # (1) action 시퀀스에 대한 masked self-retention
    ret, hs1_new = self.retn1(
        key=x, query=x, value=x, hstate=hs1, dones=dones, step_count=step_count)
    ret = self.ln1(x + ret)
    # (2) obs_rep(query) x action(key,value) 교차 retention
    ret2, hs2_new = self.retn2(
        key=ret, query=obs_rep, value=ret,
        hstate=hs2, dones=dones, step_count=step_count)
    y = self.ln2(obs_rep + ret2)
    output = self.ln3(y + self.ffn(y))   # SwiGLU FFN
    return output, (hs1_new, hs2_new)
# 인코더(EncodeBlock)는 masked=False 전체 retention,
# 디코더는 masked=True 인과 마스크로 자기회귀 행동 생성을 보장.

이 코드가 보여주는 것: DecodeBlock의 순방향 — 두 개의 masked MultiScaleRetention과 SwiGLU가 에이전트를 자기회귀로 디코딩. attention이 아니라 retention이라는 점이 핵심.

② 강화학습 방법 — 어떻게 학습하나

③ 핵심 기여
  • Sequential Value(seq_v = A·v_loc) — attention 행렬으로 가치를 순차 재분배
  • 순서 의존 협력(선행/후행 에이전트)의 명시적 신용 할당
  • 가변 에이전트 수(N)에 대한 일반화(Random SC2 맵)

# srsv/algorithms/srsv/algorithm/srsv.py (lines 205-229, Decoder.forward)
def forward(self, action, obs_rep, obs):
    action_embeddings = self.action_encoder(action)
    x = self.ln(action_embeddings)
    for block in self.blocks:           # DecodeBlock: masked self-attn + cross-attn
        x, att = block(x, obs_rep)      # att: [batch, n_agents, n_agents]
    # 지역 가치: (obs_rep, x)를 결합해 에이전트별 v_loc 산출
    loc_v = self.loc_v_mlp(torch.cat((obs_rep, x), axis=-1))  # [B, n_agents, 1]
    # ★ Sequential Value: attention 행렬로 지역 가치를 에이전트 시퀀스 간 재분배
    seq_v = torch.bmm(att, loc_v)       # [B, n_agents, 1]
    logit = self.head(x)
    return logit, seq_v, att
# 두 번째 디코더 attn(attn2)은 masked=True, return_att=True 로
# 선행 에이전트→후행 에이전트 의존 가중치를 그대로 가치 분배에 사용.

이 코드가 보여주는 것: 디코더 순방향 — attn2(cross attention)이 return_att=True로 attention 가중치를 반환하고, 이걸 loc_v에 곱해 seq_v(순차 가치)를 만드는 부분.

ACAC A

ICML 2025 · ★9
① 직관 — 한 줄로 이해하기

에이전트마다 행동이 걸리는 시간(매크로 행동 길이)이 달라 결정 시점이 엇갈리는 환경에서, PPO의 신용 할당이 어긋나는 문제를 시간 임베딩과 마스크로 정렬한다.

② 강화학습 방법 — 어떻게 학습하나

매크로 행동 기반 PPO. 에이전트별 GRU actor(분산 실행) + attention 중앙 joint critic(PopArt 가치 정규화). 시간 임베딩(sinusoidal)과 매크로-행동 유효 마스크로 의사결정 빈도가 다른 에이전트의 GAE를 정렬. 중앙 GAE를 각 에이전트 매크로 시점으로 정렬해 PPO clip으로 갱신.

③ 핵심 기여
  • 비동기(asynchronous) MARL을 위한 agent-centric 정렬 — 매크로 행동 길이 차이 처리
  • 시간 임베딩 + 유효 마스크로 어긋난 행동 시점 보정
  • attention 중앙 joint critic + PopArt로 신용 할당

                    states = th.cat((states[:, 0:agent_id*cut], states[:, (agent_id*cut+cut):]), dim=-1)

                        aux_inputs = th.cat((z_others, z_others_next), dim=-1)
                        predicted_actions_logits = self.aux_models[agent_id].forward(aux_inputs)
                        aux_loss = self.args.lambda_aux_loss * self.aux_criterion(predicted_actions_logits, actions[:, agent_id])

    def hyper_forward(self, in_dim, out_dim, target_in, hyper_in, time_steps, batch_size):
        # y = xW + b 를 계산, 단 W/b는 하이퍼네트가 hyper_in(=obs+cap)으로부터 생성
        num_weights = (in_dim * out_dim)
        weight_hypernet = HyperNetwork(hidden_dim=self.hypernet_kwargs["HIDDEN_DIM"],
                                       output_dim=num_weights,
                                       init_scale=self.hypernet_kwargs["INIT_SCALE"],
                                       num_layers=self.hypernet_kwargs["NUM_LAYERS"],
                                       use_layer_norm=self.hypernet_kwargs["USE_LAYER_NORM"])
        weights = weight_hypernet(hyper_in).reshape(time_steps, batch_size, in_dim, out_dim)
        bias_hypernet = HyperNetwork(..., output_dim=out_dim, init_scale=0, ...)
        biases = bias_hypernet(hyper_in).reshape(time_steps, batch_size, 1, out_dim)
        target_out = jnp.matmul(target_in[:, :, None, :], weights) + biases
        return target_out.squeeze(axis=2)

    @nn.compact
    def __call__(self, hidden, x, train=True):
        orig_obs, dones = x
        cap = orig_obs[:, :, -self.dim_capabilities:]   # 마지막 dim_cap 원소 = capability
        obs = orig_obs[:, :, :-self.dim_capabilities]
        time_steps, batch_size, obs_dim = obs.shape
        embedding = nn.relu(nn.Dense(self.hidden_dim, ...)(obs))   # 인코더 MLP
        hidden, embedding = ScannedRNN()(hidden, (embedding, dones))  # GRU 순차처리

def format_reward(predict_str: str) -> float:
    # <think>...</think><answer>...</answer> 구조 검사
    structure_pattern = re.compile(r'<think>.*</think>.*<answer>.*</answer>.*', re.DOTALL)
    if not re.fullmatch(structure_pattern, predict_str):
        return 0.0
    answer_match = re.search(re.compile(r'<answer>(.*?)</answer>', re.DOTALL), predict_str)
    if not answer_match:
        return 0.0
    answer_content = answer_match.group(1).strip()
    # {{...}} 이중 중괄호 정규화
    if re.search(re.compile(r'\{\{.*\}\}', re.DOTALL), answer_content):
        answer_content = answer_content.replace('{{', '{').replace('}}', '}')
    try:
        parsed = ast.literal_eval(answer_content)   # list/dict 파싱 가능 시 1.0
        return 1.0 if isinstance(parsed, (list, dict)) else 0.0
    except (ValueError, SyntaxError, TypeError):
        return 0.0

                Q = np.mean(raw_rewards[:, :t]) if turn_ids is None else np.mean(raw_rewards[m][:t])
                R_final = raw_rewards[m][t]
                if "quality" in self.name:  # 품질 가중: Q·R - (1-Q)(1-R)
                    dynamic_term = Q * R_final - (1 - Q) * (1 - R_final)
                    shaped_reward = R_final + self.alpha * dynamic_term
                elif "margin" in self.name: # 마진: 현재 턴 보상 - 과거 평균(우위)
                    baseline_term = R_final - Q
                    shaped_reward = R_final + self.alpha * baseline_term
                local_rewards[m][t] = shaped_reward
        if "outcome" in self.name:          # 최종 결과 보상을 beta로 가산
            for m in range(M):
                for t in range(T):
                    local_rewards[m][t] += self.beta * raw_rewards[m][-1]
    return local_rewards

이 코드가 보여주는 것: 핵심 크레딧 할당 — 턴별 보상을 margin/quality로 셰이핑하고 결과 보상을 가산하는 auto_reward_alloc.

# AT-GRPO 환경 보상 계산: 턴 인덱스 기반 가중/할인으로 턴별 크레딧 부여.
def calculate_reward(data_proto, algorithm="default", **kwargs):
    # env_final_reward(환경 최종 보상)를 turn_idx에 따라 재분배
    env_final_reward = data_proto.non_tensor_batch["env_final_reward"]
    if algorithm == "turn_weighted":
        # 후반 턴일수록 높은 가중: r = env_final_reward * (turn_idx+1)/max_turns
        turn_idx = data_proto.non_tensor_batch.get("turn_idx", np.zeros_like(env_final_reward))
        max_turns = kwargs.get("max_turns", 8)
        weights = (turn_idx + 1) / max_turns
        data_proto.non_tensor_batch["reward"] = env_final_reward * weights
    elif algorithm == "discount":
        # 초반 턴을 더 할인: r = env_final_reward * gamma^(max_turns - turn_idx)
        turn_idx = data_proto.non_tensor_batch.get("turn_idx", np.zeros_like(env_final_reward))
        max_turns = kwargs.get("max_turns", 8)
        gamma = kwargs.get("discount_factor", 0.99)
        discount = np.power(gamma, np.maximum(0, max_turns - turn_idx))
        data_proto.non_tensor_batch["reward"] = env_final_reward * discount
    # ...(hop_weighted/hop_discount: 그래프 MAS의 hop_idx 기반, default 등)
    return data_proto

    bsz = scores.shape[0]
    for i in range(bsz):
        id2score[index[i]].append(scores[i])      # 같은 프롬프트 index로 그룹화

        if len(id2score[idx]) == 1:

            id2std[idx] = torch.tensor(1.0)

            scores[i] = scores[i] - id2mean[index[i]]   # Dr.GRPO (std 정규화 생략)
