1. TL;DR

관측 가능한 에피소드 수준 교란 Z(예: 페이로드 질량, 제어 유효성)를 critic/baseline이 조건화하면 policy gradient 추정량의 점근 분산 하한이 정확한 등식으로 주어진 만큼 감소한다 (Theorem 4). 1D toy에서 등식을 수치 검증했고(0.5% 오차), oracle 조건화 시 12.7%, 유한 feature family 중첩 시 8.5% 분산 감소를 실측했다. 단, Z-feature를 단순 곱(gᵢⱼ(s)·ψ(Z))으로 붙이면 상수항이 중심화 과정에서 소멸해 family가 비중첩이 되고 오히려 분산이 1.2~1.7배 악화된다(negative control로 입증). 교훈: "Z를 조건화하라"는 처방은 family 중첩을 명시적으로 구현해야 효과가 보장된다. 아직 하지 않은 것: 신경망 PPO에서의 실증. §7이 그 구현 명세다.

2. 배경과 문제 정의

Policy gradient 계열(TRPO/PPO/A2C 공통)의 병목 중 하나는 gradient 추정량의 분산이다. 추정량은 ĝ = (1/N) Σi Σt Xt(Gt − bt) 형태이고(X = score function), baseline/critic b가 좋을수록 분산이 준다.

이 연구의 질문: 환경에 "관측 가능하고 에피소드 내내 유지되는 교란 구조"가 있을 때, 이것을 조건화하는 것이 추정량의 효율 하한(= tangent space 위 대표원의 L² 노름)을 얼마나, 어떤 등식으로 줄이는가? 이는 §5 연구 프로그램 3번 "도메인 특화 조건부 독립 구조 → tangent space 축소 → 효율 하한 감소"의 실행이다.

novelty 위치 (솔직하게): "조건화로 분산을 줄인다"는 패턴 자체는 POMDP / context-augmentation 선례가 있는 고전이다. 증명도 표준 세미파라메트릭 체계(tangent space 투영)의 즉시 따름정리 수준이다. 기여는 (i) 도메인 구조의 명세와 검증 체크리스트, (ii) 하한 감소의 정확한 등식화, (iii) family 중첩성 함정의 발견과 교정이다.

3. 실험 환경 명세 (1D toy, 검증 완료)

# 에피소드 수준 교란 Z: 제어 유효성 (페이로드/마찰 스토리)
Z ~ U[0.5, 1.5]        # 에피소드당 1회 표본, 관측 가능, s0과 독립, 시간 불변(persistent)
s' = 0.5·s + Z·a + w,  w ~ N(0, 0.2²)     # 폐루프 계수 0.5+0.2Z ∈ [0.6, 0.8] → 안정
r = −(s² + a²),  π(a|s) = N(θ·s, 0.5²),  T = 20,  γ = 1,  θ* = 0.2
X_t = (a_t − θ·s_t)·s_t / 0.25            # score function
ψ0(trajectory) = Σ_t X_t·G_t              # 추정 대상 양 (ĝ = mean(ψ0) − baseline 보정)

두 모형: M_A = s-Markov(Z 무시), M_B = (s,Z)-Markov(Z 조건화). Z가 환경 동역학에 실제로 들어가 있으므로 M_B가 참 모형이고, M_A는 misspecified하나 추정량은 두 경우 모두 불편(Lemma 1).

도메인 적용 체크리스트 (C1–C3) — 실제 문제에 적용하기 전 확인:

  • C1: Z ⊥ s₀ (초기상태와 독립) — 상관검정으로 확인
  • C2: 동역학이 실제로 Z에 의존 (Markov 결정변수로 필요) — 모형잔차 검정
  • C3: Z가 관측 가능 + 에피소드 내 지속(persistent) + 시간 불변

실제 후보: 로봇 페이로드 질량(측정 가능), 마찰 계수, 바람, 초기화 편차.

4. 완료된 이론 증명 완료

전체 증명은 pg_estimator_efficiency_theory.md §10. 여기에는 statement만 둔다.

Lemma 1 (불편성의 기초)

E[Xt | st, Z] = 0

따라서 (s,Z)-측정 가능한 임의 보정항 bt(st,Z)를 빼도 불편성 유지.

Lemma 2 (tangent space 축소)

TB ⊆ TA

증명은 tower property 2줄: E[h − E[h|s,a,Z] | s,a] = 0. 독립 가정 불필요.

Theorem 4 (하한 감소의 정확한 등식) 핵심

repB = ΠTB repA, E[repB²] = E[repA²] − E[(repA − ΠTB repA)²]

  • repA, repB: 각 tangent space 위 대표원(Riesz), Π: 정사영
  • 감소분 = 대표원의 "구조에 직교하는 성분"의 노름, 피타고라스로 등식
  • 감소 = 0 ⟺ repA ∈ TB (구조가 정보를 추가하지 않을 때)
  • 단조성은 family 중첩이 전제 — §6의 함정 3이 이 전제를 깨뜨리는 사례

Corollary 4.1 (per-step 등식)

E[X²(G − b*s)² | s,Z] = E[X²(G − b*Z)² | s,Z] + E[X² | s,Z]·(b*Z − b*s)²

즉 per-step 감소 = E[X²(b*Z(s,Z) − b*s(s))²] ≥ 0. 최적 baseline: b* = E[X²G|·] / E[X²|·].

6. 구현 함정 4가지 다음 agent 필독

이 4개는 실제로 겪고 해결한 문제다. 같은 실수를 반복하지 말 것.

함정 1 — 비율 피팅의 꼬리 폭발

b* = E[X²G|·]/E[X²|·]를 분자·분모를 각각 다항회귀로 피팅해 나누면 외삽 영역(Z가 먼 단면)에서 1.5×10⁸ 수준의 폭발이 관측됐다.

해결: 비율을 직접 피팅하지 말고 X²-가중 최소제곱으로 E[X²G|·] 형태의 가중 조건부평균을 한 번에 피팅한다 (미분가능성 문제 없음, 검증됨).

함정 2 — 곱열 중심화가 β를 타고 편향 주입

control variate 열을 X·φ − ĉ로 중심화하면 ĉ의 추정 오차가 −Σβ·ĉ로 편향을 만든다 (+1.9~2.3 관측).

해결: X-family는 feature 수준 중심화 X·(φ−μ) — Lemma 1에 의해 정확히 영평균 (300k에서 열평균 ≤ 5.3×10⁻³ = 표본노이즈 수준). X가 없는 열(Phi-family)은 곱열 평균 중심화 외에 방법이 없어 O(1/√N) 오차가 남음 — 이 경우 편향을 분리 보고할 것.

함정 3 — 상수-ψ 소멸 → 비중첩 family → 분산 역전 이번 윈도우의 핵심 발견

feature 수준 중심화 X·(φ−μ)(ψ−ν)에서 상수 기저 ψ₀≡1은 1 − mean(1) ≡ 0으로 정확히 소멸한다. 그러면 Z-product family X·φ̃(s)ψ̃(Z)는 s-only family X·φ̃(s)를 포함하지 않는 비중첩 family가 되고, Lemma 2의 단조 논리(TB ⊆ TA)가 적용되지 않는다. 실측: zfam_Z 1.169배, union_Z 1.749배 악화.

해결: 비상수-ψ 열(j≥1)만 남기고 s-only 열을 명시적으로 결합해 진짜 중첩 family를 만든다(union_Zn). 그러자 예측대로 0.915배 감소가 실측됐다.

신경망 버전 번역: value network가 V(s,z) 하나로 z를 흡수하면 중첩이 보장되지 않는다. 아래처럼 s-only 경로를 명시적으로 두어 중첩을 구조적으로 강제하라: V(s,z) = Vs(s) + Δ(s,z), Δ 초기화 ≈ 0. 이렇게 하면 z 정보가 없을 때 정확히 baseline PPO와 동일해진다.

함정 4 — 대형 공선 Gram 행렬 + ridge의 조건수 실패

480열 Gram + 아주 작은 ridge는 공선 열에서 불안정했다(population적으로 불가능한 회귀 계수가 관측됨).

해결: 고유값 절단 최소노름 해 (eigh → λ > rel·λmax 방향만 사용). 참고: 상수-φ(=1) 열도 중심화로 정확히 0이 되므로 죽은 열(零 고유값)이 생기는데, 절단이 자동으로 처리한다.

7. 다음 단계 구현 명세 여기부터가 할 일

목표: 이 이론의 신경망 PPO 실증. 이론이 내는 검증 가능한 예측은 "같은 샘플 수에서 Z-조건화 critic이 더 낮은 gradient 추정 분산 → 더 빠른 초기 수렴". 의존성 최소화를 위해 3단계로 나눈다.

Phase 1 — numpy 오프라인 재검증 (의존성: numpy만, ~30분)

pg-efficiency/thm4_experiment_v4.py가 이미 전체 파이프라인의 작동하는 참조 구현이다. 다음 확장을 하라:

  • 1D → d-차원 LQR로 확장 (s ∈ Rd, payload가 스칼라 곱 → 행렬 Z로). 각 step의 score는 로그-가우시안 정책 미분으로 일반화.
  • Z의 "정보량" 스윕: ZLO/ZHI 폭을 [0.9,1.1], [0.7,1.3], [0.5,1.5]로 바꿔가며 감소분이 Z 분산에 어떻게 스케일되는지 측정 (Theorem 4의 등식이 매번 0.5~1% 오차로 성립하는지 확인 — 이것이 이론의 가장 강한 검증).
  • 결과 저장 스키마: {pred_per_step_sum, gap_direct_sum, estimators:{name:{var, ratio}}} (기존 thm4_results.json 참고).

Phase 2 — 최소 PPO 두 팔 (의존성: + torch, ~2시간)

실험 설계의 핵심 규칙: policy는 두 팔 모두 동일하게 s만 입력으로 받는다. Z는 critic에만 들어간다. policy가 Z까지 보면 적응적 행동이라는 교란 변수가 생겨 "추정 효율" 효과를 분리할 수 없다. (적응적 policy는 별도 3번째 팔로 나중에.)

# ---- 환경: payload-randomized 1D LQR (의존성 없음, MuJoCo 대기 없이 즉시 가능) ----
class PayloadLQR:
    """obs = (s, z). baseline agent는 obs[0]만 쓴다(아래 제어 규칙 참고)."""
    def reset(self):
        self.s = self.rng.normal()
        self.z = self.rng.uniform(0.5, 1.5)          # C1: s와 독립 / C3: 관측+지속
        return np.array([self.s, self.z])
    def step(self, a):                                # C2: 동역학이 z에 의존
        w = self.rng.normal(0, 0.2)
        self.s = 0.5*self.s + self.z*a + w
        r = -(self.s**2 + a**2)
        return np.array([self.s, self.z]), r, False, {}   # T=20에서 done

# ---- Nested value net (함정 3의 신경망 번역 — 이 구조를 반드시 쓸 것) ----
class NestedValueNet(nn.Module):
    """V(s,z) = V_s(s) + Δ(s,z). Δ를 0으로 초기화하면 시작 상태가 baseline과 동일."""
    def __init__(self, s_dim, z_dim, h=64):
        super().__init__()
        self.v_s  = nn.Sequential(nn.Linear(s_dim, h), nn.Tanh(),
                                  nn.Linear(h, h), nn.Tanh(), nn.Linear(h, 1))
        self.delta= nn.Sequential(nn.Linear(s_dim+z_dim, h), nn.Tanh(),
                                  nn.Linear(h, h), nn.Tanh(), nn.Linear(h, 1))
        nn.init.zeros_(self.delta[-1].weight); nn.init.zeros_(self.delta[-1].bias)
    def forward(self, s, z):
        return (self.v_s(s) + self.delta(torch.cat([s, z], -1))).squeeze(-1)

# ---- baseline 팔은 같은 코드에서 delta를 영구 0으로 고정 (단일 코드베이스, 공정 비교) ----

최소 PPO 스켈레톤 (GAE λ=0.95, clip ε=0.2, γ=0.99 또는 toy와 맞춤 γ=1, policy = 가우시안 N(μθ(s), σ 고정), rollout 2048 step / update 4 epoch, Adam 3×10⁻⁴ — 정확한 값보다 두 팔 동일이 중요):

for iter in range(N_ITER):
    traj = collect(rollout_steps)                 # policy: s만 입력 (두 팔 동일)
    adv, ret = gae(traj, value_fn)                # baseline: V(s) / Z-팔: V(s,z)
    for e in range(EPOCHS):
        ratio = exp(logp_new - logp_old)
        loss_pi = -min(ratio*adv, clamp(ratio,1-ε,1+ε)*adv).mean()
        loss_v  = (V - ret)**2 .mean()            # Z-팔: (V(s,z) - ret)²
        update(loss_pi + c_v*loss_v + ent)

측정 프로토콜과 acceptance criteria

  • 오프라인 분산 테스트 (Phase 2 안에서도 수행): 학습 중 policy로 10k 궤적 수집 → 고정된 평가 배치(재사용)에서 ψ̂의 배치 분산 비교. 예상: Z-팔 ratio 0.85~0.95 (toy의 union 참고). 역전되면 §6 함정 3부터 의심할 것.
  • 온라인 학습 곡선: 5 seeds × {baseline, Z-PPO}. metric = (a) 초기 100k step 리턴 AUC, (b) 최종 리턴의 90% 도달 step 수. 통과 기준: 초기 AUC가 ≥4/5 seed에서 Z-팔 우위, 평균 10% 이상 향상.
  • 음성 대조(필수): z를 obs에 넣었지만 critic이 안 쓰는 팔(delta 상수 0) 또는 z를 무작위 노이즈로 갈아끼운 팔을 하나 추가 — 효과가 "정보"에서 왔는지 "입력 차원"에서 왔는지 구별.
  • 모든 결과는 seeds·하이퍼파라미터·환경 시드와 함께 JSON으로 남길 것.

Phase 3 — MuJoCo 실제 도메인 (의존성: + gymnasium, mujoco)

  • 대상: HalfCheetah-v5류에 페이로드 질량 랜덤화 wrapper (에피소드당 torso mass × U[0.5,1.5]), Z = log(질량비)를 obs에 append.
  • 같은 NestedValueNet 구조, 같은 프로토콜. policy는 계속 s만 입력 (adaptive policy는 이후 별도 비교).
  • 예상 위험: 관측이 이미 질량을 간접 노출 → C1 위반 가능. 이 경우 초기 N step만의 관측에서 질량을 추정한 ẑ을 Z로 사용하는 variant로 우회.

8. 한계·정직성 노트

  • cross-time 항 미분해: 실측 단일-궤적 감소(2924.9)는 per-step 예측(1558.1)의 1.9배. Corollary 4.1은 per-step 항만 기술하고, 궤적합 추정량에는 시간 간 공분산 항이 추가 이득을 만든다. 정리와 모순은 아니나(보수적 하한) 분해는 미검증.
  • 절대 편향: 모든 estimator가 FD truth(−58.005) 대비 +1.1~+2.3. 주장은 분산 비교 기준이며 편향 메커니즘(함정 2)은 식별해 둠.
  • 환경 규모: 신경망/고차원에서 같은 이득이 나는 것은 검증된 사실이 아니라 이론이 내는 예측이다. §7이 바로 그 검증 계획이다.
  • 이론 수준: 증명은 표준 체계의 따름정리. 새로운 것은 명세·등식·함정 발견·검증.
